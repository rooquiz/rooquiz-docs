이 섹션은 **개발자**를 위한 내용으로, 직접 작성한 코드나 AI 클라이언트에서 RooQuiz에 접근하는 방법을 다룹니다.

<Cards>
  <Card title="REST API" href="/ko/integrations/rest-api" />
  <Card title="MCP 연동" href="/ko/integrations/mcp" />
</Cards>

- **REST API** — 계정 단위 API 키로 퀴즈와 제출 내역을 가져옵니다. 자체 대시보드를 만들거나 데이터 웨어하우스로 동기화할 때 적합합니다.
- **MCP 연동** — Claude 같은 AI 클라이언트를 팀에 연결해 퀴즈를 직접 만들고 조회하고 수정하게 합니다.

## 코드 없이 연동하기

"리드가 들어오면 알려 줘"나 "리드를 이메일 도구로 동기화해 줘" 정도만 필요하다면 **API는 필요 없습니다.** [커넥터 및 자동화](/ko/connectors)의 다섯 채널(이메일, Webhook, Slack, Zapier, Kit) 중 하나를 사용하세요.

<Callout type="info">
  차이는 **푸시와 풀**입니다. 커넥터는 이벤트가 발생하면 데이터를 보내 주고, REST API는 원하는 일정에 맞춰 직접 가져오게 합니다.
</Callout>
