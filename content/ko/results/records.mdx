응답 기록은 퀴즈가 받은 **모든 개별 제출**이며, 퀴즈의 **응답 기록** 탭에 있습니다. 이것은 원본 데이터입니다. 전체 추세는 [인사이트](/ko/results/insights)에서 확인하세요.

![The RooQuiz response records list with the filter builder and table](/img/en/results/records-list.webp)

## 필터

**필터**를 클릭해 빌더를 열고 조건을 쌓습니다(조건은 AND로 결합됩니다).

| 필드 | 설명 |
| --- | --- |
| **문항별** | 특정 문항의 답변으로 필터링합니다. 선택형 문항은 "다음 중 하나 / 다음 중 아님 / 비어 있음 / 비어 있지 않음"을 지원합니다 |
| **응답자** | 특정 한 사람의 제출 내역 |
| **UTM 소스** | 어느 채널에서 왔는지. [UTM 추적](/ko/publish/tracking)과 함께 사용 |
| **점수** | 숫자 범위(최솟값과 최댓값 **범위 내**) |
| **레벨** | 어느 리포트 레벨에 해당하는지 |
| **언어** | 어느 [언어 버전](/ko/editor/translations)으로 응답했는지 |
| **리드 상태 / 담당자** | [리드](/ko/leads)의 후속 관리 상태나 담당자로 필터링 |
| **제출 일시** | 시작 날짜와 종료 날짜 |

조건을 설정했으면 **적용**을 누르고, 처음부터 다시 하려면 **모두 지우기**를 누릅니다.

<Callout type="info">
  여기에는 보드 보기가 없습니다. 보드는 [리드](/ko/leads/list-board) 페이지에 있습니다. 두 기능은 서로 다른 질문에 답합니다. 응답 기록은 **제출**, 리드는 **사람**입니다.
</Callout>

## 단일 기록

아무 행이나 열면 상세 화면이 둘로 나뉩니다.

- **왼쪽** — 문항별 답변과 점수, 그리고 리포트
- **오른쪽** — 이 사람을 [리드](/ko/leads)로 관리하는 후속 관리 사이드바. 상태를 바꾸고, **댓글**을 작성하고, 통합 활동 타임라인을 확인합니다.

즉, 리드 페이지로 이동하지 않고도 응답을 읽으면서 후속 조치를 할 수 있습니다.

<Callout type="info">
  댓글은 **답글**을 지원하며, 내가 쓴 댓글은 삭제할 수 있습니다. [리드 상세 페이지](/ko/leads/detail)의 댓글과 같은 댓글이므로 두 곳 모두 하나의 공유 스레드를 보여 줍니다.
</Callout>

## 기록에 포함되는 내용

답변 외에도 기록에는 보통 다음 정보가 담깁니다.

- **기록 번호** — 퀴즈 안에서 증가하는 번호
- **응답자** — 로그인한 경우에만 표시되며, 익명 제출은 비어 있습니다.
- **유입 경로** — [UTM 링크](/ko/publish/tracking)로 들어온 경우 기록됩니다.
- **제출 일시**, **언어 버전**, **점수와 레벨**

## 내보내기

도구 모음의 **내보내기**는 선택한 행 또는 현재 필터와 일치하는 모든 행을 내보냅니다. 전체 내보내기는 주간 할당량을 사용합니다. [데이터 내보내기](/ko/results/export)를 참고하세요.

<Callout type="warning">
  내보낸 데이터에는 응답자가 제공한 개인정보가 포함될 수 있습니다. 조직의 개인정보 보호 및 규정 준수 정책에 따라 취급하세요.
</Callout>
