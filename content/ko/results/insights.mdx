인사이트는 흩어진 응답을 **통계와 차트**로 집계해, 기록을 하나씩 넘겨 보지 않고도 전체 그림을 파악하도록 도와줍니다.

## 핵심 지표

상단에는 **오늘 제출 수**(어제 대비), **전체 제출 수**, **순 응답자 수**(로그인한 응답자만), **평균 점수**, **리포트 완료율**(완료 / 실패 / 대기 중 리포트), 그리고 공유율과 함께 **공유 수**가 표시됩니다.

## 주요 차트

- **최근 N일 제출 수**: 시간에 따른 응답량입니다.
- **답변 분포**: 단일 선택, 드롭다운, 참/거짓, 평점 문항(최대 10개)에서 각 선택지의 비율입니다.
- **트래픽 소스**: [UTM 유입 경로 추적](/ko/publish/tracking)과 함께 사용해 채널별 응답량을 비교합니다.
- **로그인 방식**과 **기기 유형**: 익명 응답자와 등록된 응답자의 비율, 그리고 iOS / Android / 데스크톱 비율입니다.

## 전환 퍼널

**전환 퍼널**은 **한 번의 방문(세션)** 을 **조회 → 시작 → 제출 → 리포트 조회 → CTA 클릭** 단계로 추적합니다. 두 단계는 해당될 때만 표시됩니다. **리드 확보**(제출 다음)는 **리포트를 보려면 이메일 필요**로 설정된 퀴즈나 이전 리드 데이터가 있는 퀴즈에서, **공유**(마지막)는 결과가 공유된 뒤에 표시됩니다. 각 단계를 집계하는 기준은 다음과 같습니다.

| 단계 | 집계 시점 |
| --- | --- |
| 조회 | 브라우저에서 퀴즈 페이지가 실제로 열렸을 때(크롤러와 관리자 미리보기 제외) |
| 시작 | 응답자가 처음으로 아무 문항에나 답했을 때("시작" 클릭만으로는 집계되지 않음) |
| 제출 | 제출에 성공했을 때 |
| 리드 확보 | 제출이 응답자와 연결되었을 때(이메일을 남겼거나 로그인함) |
| 리포트 조회 | 응답자가 결과 페이지에 있는 동안 리포트 생성이 완료되었을 때 |
| CTA 클릭 | 응답자가 리포트 하단의 [CTA 버튼](/ko/results/reports)을 클릭했을 때 |
| 공유 | 응답자가 결과 페이지의 공유 버튼을 클릭했을 때(처음 한 번, 채널 무관) |

각 단계 옆의 백분율은 **이전 단계 대비** 전환율이므로, 정확히 어디에서 이탈이 일어나는지 알 수 있습니다.

### 이탈 지점 상위 10개

**제출하지 않았지만** 한 문항 이상 답한 세션을 **마지막으로 답한 문항**별로 묶은 것입니다. 건수가 많은 문항은 사람들이 포기하는 지점으로, 너무 어렵거나, 너무 민감하거나, 다음 문항이 겁을 주었을 가능성이 있습니다. 아무 문항에도 답하지 않고 떠난 방문자는 여기에 표시되지 않으며, 조회 → 시작 단계의 감소로 나타납니다.

### 소스별 전환

링크의 `utm_source`([배포 계획](/ko/publish/promotion), [UTM 유입 경로 추적](/ko/publish/tracking) 또는 [임베드](/ko/publish/embed)의 UTM 속성으로 설정)별로 묶어 소스마다 조회/시작/제출 수와 완료율을 비교합니다. 웹사이트 임베드에서 들어온 소스에는 **임베드** 태그가 붙습니다.

<Callout type="info">
  퍼널은 이 기능이 출시된 이후의 세션을 집계하며, 그 이전의 제출은 소급 반영되지 않습니다. 따라서 처음에는 "전체 제출 수"가 퍼널의 제출 수보다 많을 수 있으며, 시간이 지나면 두 값이 가까워집니다.
</Callout>

## 활용 팁

- **전환 퍼널**로 이탈 지점을 찾으세요. 조회는 많은데 시작이 적다면 시작 페이지나 첫 문항이 문제이고, 시작은 많은데 제출이 적다면 이탈 지점 상위 문항을 확인하세요.
- **답변 분포**로 응답자의 전반적인 경향을 파악하세요.
- 시간 추세와 **소스별 전환**을 함께 보며 채널별 캠페인을 평가하세요.

<Callout type="info">
  인사이트는 "집단의 추세"를 보여 줍니다. 특정 응답을 자세히 보려면 [응답 기록](/ko/results/records)으로, 개인별 평가 결론은 [리포트](/ko/results/reports)로 이동하세요.
</Callout>
