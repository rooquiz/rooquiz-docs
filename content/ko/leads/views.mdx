---

리드가 수백 명이 되면 매일 실제로 처리하는 리드는 그중 일부에 불과합니다. **필터**는 그 일부를 골라내고, **저장된 뷰**는 내일 다시 골라낼 필요가 없게 해 줍니다.

## 사용할 수 있는 필터

**필터**를 클릭해 필터 빌더를 열고 다음 항목을 조합합니다.

| 항목 | 설명 |
| --- | --- |
| **검색** | 응답자 이름 또는 이메일로 유사 검색 |
| **생성일** | 전체 기간 / 오늘 / 이번 주 / 이번 달 / 사용자 지정 범위 |
| **상태** | 하나 이상의 후속 관리 상태 |
| **태그** | 선택한 태그 중 **하나라도** 붙어 있는 리드와 일치 |
| **담당자** | 특정 구성원이 담당하는 리드 |
| **예약** | 예정된 예약 있음 / 예정된 예약 없음 |

<Callout type="info">
  "이번 주"는 **월요일**부터 시작하며, 오늘 / 이번 주 / 이번 달은 모두 팀 시간대가 아니라 **브라우저의 시간대**를 기준으로 판단합니다.
</Callout>

적용 중인 필터는 페이지 상단에 작은 칩으로 표시됩니다. 칩의 ×를 클릭하면 해당 조건 하나만 제거됩니다.

## 뷰로 저장하기

자주 쓰는 필터 조합을 저장해 두고 클릭 한 번으로 다시 불러올 수 있습니다.

<Steps>
### 먼저 필터 설정

상태, 태그, 담당자 등을 선택하고 목록에 원하는 사람들이 표시되는지 확인합니다.

### "새 뷰" 클릭

한눈에 알아볼 수 있는 이름을 붙입니다. 예: "이번 주 후속 연락할 유망 리드". 이름은 최대 50자까지 입력할 수 있습니다.

### 페이지 상단에서 전환

저장된 뷰는 페이지 상단의 **전체**, **내 리드**와 나란히 표시됩니다. 클릭 한 번으로 전환됩니다.
</Steps>

두 가지 뷰는 기본으로 제공되므로 따로 만들 필요가 없습니다.

- **전체** — 필터가 전혀 없습니다.
- **내 리드** — 나에게 배정된 리드입니다.

<Callout type="info">
  뷰는 **개인용**입니다. 내 뷰는 나만 볼 수 있으며 동료에게 영향을 주지 않습니다. 뷰는 리드의 스냅샷이 아니라 필터를 저장하므로, 데이터가 바뀌면 뷰의 내용도 함께 바뀝니다.
</Callout>

<Callout type="warning">
  뷰를 삭제하면 저장된 필터만 삭제되며 **리드에는 영향이 없습니다.** 저장할 수 있는 뷰 수에는 상한이 있으며, 상한에 도달하면 안내가 표시됩니다.
</Callout>
