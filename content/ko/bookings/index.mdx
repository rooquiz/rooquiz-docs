퀴즈를 마치고 결과를 읽는 순간은 응답자가 가장 대화하고 싶어 하는 순간입니다. **1:1 예약**을 사용하면 응답자가 결과 페이지에서 바로 나와의 세션을 예약할 수 있습니다. 서드파티 캘린더 도구도, 시간을 맞추기 위한 이메일 왕복도 필요 없습니다.

<Callout type="info">
  예약 가능 시간은 **팀 단위** 리소스입니다. 한 번 구성하면 모든 퀴즈가 공유하므로 퀴즈마다 일주일 일정을 다시 잡을 필요가 없습니다.
</Callout>

## 3단계로 시작하기

<Steps>
### 예약 가능 시간 설정

**1:1 예약** 페이지에서 **예약 가능 시간**을 열고 시간대, 세션 길이, 주간 예약 시간을 설정합니다. [예약 가능 시간](/ko/bookings/availability)을 참고하세요.

### 퀴즈에서 예약 섹션 켜기

해당 퀴즈의 **공유 → 예약**으로 이동해 **결과 페이지에 예약 섹션 표시**를 켭니다. [응답자 화면](/ko/bookings/respondent)을 참고하세요.

### 예약 페이지에서 예약 처리

새 예약은 **1:1 예약** 페이지에 들어옵니다. [예약 관리](/ko/bookings/manage)를 참고하세요.
</Steps>

<Callout type="warning">
  예약 가능 시간을 구성하기 전에는 스위치를 켜도 결과 페이지에 예약 섹션이 **표시되지 않습니다.** 설정 페이지에도 이 사실이 명시되어 있습니다.
</Callout>

## 목록의 세 가지 섹션

**1:1 예약** 페이지는 주의가 필요한 순서대로 정렬됩니다.

- **확인이 필요합니다** — 승인 기능이 켜져 있으면 대기 중인 신청이 맨 위에 표시됩니다. 다른 사람이 기다리고 있기 때문입니다.
- **예정** — 확정되었지만 아직 진행되지 않은 세션입니다. 바로 다음 세션은 카운트다운과 함께 큰 카드로 표시됩니다.
- **지난 예약** — 이력이며 기본적으로 접혀 있습니다.

사이드바의 **1:1 예약** 항목에는 대기 중인 건수가 배지로 표시됩니다.

## 상태 한눈에 보기

| 상태 | 의미 |
| --- | --- |
| **확인 대기** | 리드 담당자의 확인을 기다리는 신청(승인 기능이 켜진 경우에만) |
| **예약됨** | 확정됨. 참석자가 회의 정보를 받음 |
| **완료됨** | 세션이 진행됨 — 직접 표시 |
| **불참** | 참석하지 않음 — 직접 표시 |
| **취소됨** | 어느 한쪽이 취소함 |
| **거절됨** | 신청을 거절함 |
