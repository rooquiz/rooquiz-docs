퀴즈를 마치고 결과를 읽는 순간은 응답자가 가장 대화하고 싶어 하는 순간입니다. **예약 섹션**은 [Cal.com](https://cal.com) 예약 페이지를 결과 페이지에 바로 넣어 주므로, 응답자는 페이지를 떠나지 않고 이름과 이메일이 미리 채워진 상태로 통화를 예약할 수 있습니다.

RooQuiz는 자체 캘린더를 운영하지 않습니다. 예약 가능 시간, 이벤트 유형, 회의 링크, 알림, 일정 변경은 모두 Cal.com에서 관리합니다. RooQuiz는 결과 페이지에 진입점을 추가하고, 커넥터가 있으면 각 예약을 리드로 다시 가져옵니다.

## 두 가지 단계

| | 제공되는 기능 | 요금제 |
| --- | --- | --- |
| **예약 섹션** | 결과 페이지의 Cal.com 예약 버튼. 이름과 이메일이 미리 채워짐 | Free |
| **Cal.com 커넥터** | 예약이 RooQuiz로 다시 동기화됨: 리드와 제출 내역, 리드의 활동, 알림, 다른 커넥터에 반영 | Pro |

커넥터가 없어도 예약 섹션은 작동하지만, 예약은 Cal.com에만 존재하며 RooQuiz는 예약이 있었다는 사실을 알지 못합니다.

## 시작하기

<Steps>
### Cal.com 이벤트 유형 준비

응답자가 예약할 이벤트 유형(예: 30분 소개 통화)을 Cal.com에서 만들고 `cal.com/your-name/intro-call` 같은 링크를 복사합니다.

### 퀴즈에서 예약 섹션 켜기

퀴즈의 **설정 → 결과 페이지 후속 조치**를 열고 **예약 섹션**을 켠 다음 **Cal.com 예약 링크**를 붙여 넣습니다. [응답자 화면](/ko/bookings/respondent)을 참고하세요.

### Cal.com 연결 (Pro)

**커넥터 → 통화 예약**에서 Cal.com 계정을 연결하면 예약이 다시 들어옵니다. [Cal.com 연결](/ko/bookings/calcom)을 참고하세요.
</Steps>

## 다시 동기화되는 내용

커넥터가 있으면 **결과 페이지에서** 잡힌 모든 예약이 RooQuiz에 반영됩니다.

- [리드 상세 페이지](/ko/leads/detail)와 예약이 나온 제출 내역에 표시되고, 리드 목록의 **다음 예약** 열이 채워집니다.
- 예약, 일정 변경, 취소된 통화가 리드의 활동에 기록됩니다.
- 새 예약이 생길 때마다 리드 담당자(없으면 퀴즈 소유자, 그다음 팀 소유자)가 **앱 내 알림**을 받습니다.
- 예약 생성, 취소, 일정 변경은 각각 [커넥터를 실행](/ko/connectors/events)할 수 있으므로, 캘린더가 바뀔 때 Slack에 게시하거나 Zapier로 보낼 수 있습니다.

<Callout type="info">
  사람들이 퀴즈 **밖에서** Cal.com 페이지로 잡은 예약은 무시됩니다. RooQuiz 결과 페이지에서 잡힌 통화만 동기화되므로 리드 목록이 캘린더 전체로 넘쳐나지 않습니다.
</Callout>

<Callout type="info">
  RooQuiz는 **예약 이메일을 보내지 않습니다.** 확정, 알림, 일정 변경 안내는 Cal.com이 나와 참석자에게 보냅니다.
</Callout>

## 상태 한눈에 보기

| 상태 | 의미 |
| --- | --- |
| **확인 대기** | 이벤트 유형에 확인이 필요한데 아직 Cal.com에서 확인하지 않음 |
| **예약됨** | 통화가 확정됨 |
| **거절됨** | Cal.com에서 신청을 거절함 |
| **취소됨** | 어느 한쪽이 취소함 |
| **불참** | Cal.com에서 불참으로 표시됨 |
