기본적으로 공개 퀴즈 링크는 플랫폼 도메인을 사용합니다. **사용자 지정 도메인**을 설정하면 응답자에게 자체 도메인이 표시되어 브랜드 일관성과 신뢰도가 높아집니다.

**설정 → 사용자 지정 도메인**에서 찾을 수 있습니다.

<Callout type="warning">
  사용자 지정 도메인은 **Pro 플랜 기능**입니다.
</Callout>

## 설정 방법

<Steps>
### 도메인 입력

사용할 도메인을 입력합니다. 예: `quiz.yourbrand.com`. 루트 도메인보다 하위 도메인을 권장합니다.

### DNS 레코드 추가

페이지의 **DNS 구성 가이드**에 **유형 / 이름 / 값** 세 열로 된 레코드 하나가 표시됩니다. DNS 제공업체에 그대로 추가하세요.

### 인증 대기

다시 돌아와 **상태 새로고침**을 클릭합니다. 상태가 **인증 중**에서 **인증됨**으로 바뀌거나, **인증 실패**가 표시됩니다.
</Steps>

<Callout type="info">
  DNS 레코드 전파에는 제공업체에 따라 **몇 분에서 최대 48시간**이 걸립니다. 설정 직후 바로 인증되지 않는 것은 정상이니 나중에 다시 새로 고쳐 보세요.
</Callout>

## 상태 값

| 상태 | 의미 |
| --- | --- |
| **인증 중** | 레코드가 제출되었으며 DNS 전파와 확인을 기다리는 중 |
| **인증됨** | 도메인이 활성화되어 공개 링크에 사용됨 |
| **인증 실패** | 올바른 레코드를 찾지 못함. 가이드와 비교해 유형 / 이름 / 값을 다시 확인하세요 |
| **일시 중지됨** | Pro 플랜이 만료됨 |

<Callout type="warning">
  Pro가 만료되면 도메인이 **일시 중지됨** 상태가 됩니다. **7일의 유예 기간**이 있으며, 그 이후에는 사용자 지정 도메인이 더 이상 연결되지 않습니다. 갱신하면 복구되며 DNS 설정을 다시 할 필요는 없습니다.
</Callout>
