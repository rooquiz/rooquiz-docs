**감사 로그**는 팀에서 일어난 주요 작업을 기록합니다. 누가 어떤 대상에 무엇을 언제 했는지, 그리고 성공했는지를 남깁니다. **설정 → 감사 로그**에서 찾을 수 있습니다.

<Callout type="warning">
  **감사 로그는 팀 소유자와 관리자만 볼 수 있습니다.** 구성원과 뷰어에게는 대신 안내가 표시됩니다.
</Callout>

## 열 구성

| 열 | 설명 |
| --- | --- |
| **작업** | 일어난 일. 예: "멤버 초대", "퀴즈 삭제", "데이터 내보내기" |
| **상태** | 성공 또는 실패 |
| **실행자** | 작업을 한 사람. 플랫폼이 직접 시작한 작업(보존 기간에 따른 정리, 검토에 따른 차단)은 **시스템**으로 표시됩니다 |
| **대상** | 작업 대상 객체. ID 접두사가 함께 표시됩니다 |
| **시간** | 작업이 일어난 시점 |

행을 클릭하면 **상세**가 펼쳐집니다. 작업마다 기록되는 필드가 다르며, 예를 들어 내보내기는 데이터 유형(응답 / 리드 / 응답자)과 행 수도 함께 기록합니다.

## 기록 범위

크게 다음과 같습니다.

- **팀** — 팀 삭제, 소유권 이전, 요금제 변경
- **구성원** — 초대, 제거, 탈퇴, 역할 변경, 비활성화 / 활성화
- **퀴즈** — 생성, 수정, 휴지통 이동, 복원, 영구 삭제, 차단 / 차단 해제
- **리드 및 응답자** — 휴지통 이동, 복원, 영구 삭제
- **커넥터** — 생성, 수정, 삭제
- **자격 증명** — API 키와 MCP 토큰의 생성, 폐기, 복원, 삭제
- **사용량** — AI 사용량, 이메일 사용량, [데이터 내보내기](/ko/results/export)

상단에서 **작업**과 **상태**로 필터링하면 "지난주에 누가 데이터를 내보냈나" 같은 질문에 답할 수 있습니다.

<Callout type="info">
  로그는 **읽기 전용**이며 편집하거나 삭제할 수 없습니다. 수정할 수 있는 감사 로그는 가치가 없기 때문입니다.
</Callout>
