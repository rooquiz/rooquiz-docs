로그인하면 **대시보드**로 이동합니다. 대시보드에는 나와 팀의 모든 퀴즈가 모여 있으며, 일상적인 관리 작업의 출발점입니다.

![The RooQuiz dashboard: sidebar navigation and quiz list](/img/en/getting-started/dashboard.webp)

## 메인 영역

- **생성 카드** — 상단의 세 카드는 각각 [지식 퀴즈 만들기 / 점수 퀴즈 만들기 / 결과 유형 퀴즈 만들기](/ko/getting-started/create-quiz)에 대응합니다.
- **그룹 탭** — **전체**, **즐겨찾기**, 그리고 직접 만든 그룹이 표시되며, 옆에 **그룹 만들기**가 있습니다. [워크스페이스](/ko/getting-started/workspace)를 참고하세요.
- **퀴즈 카드** — 각 카드에는 유형 배지, 표지, 제목, 생성일, 응답 수가 표시되고, 하단에 편집, 응답 기록, 기타 작업 버튼이 있습니다.

## 왼쪽 사이드바

| 항목 | 용도 |
| --- | --- |
| **내 퀴즈** | 이 페이지 |
| **[문제 은행](/ko/library/question-banks)** | 재사용 가능한 문항 모음 |
| **[응답자](/ko/respondents)** | 퀴즈에 응답한 사람들의 프로필 |
| **[리드](/ko/leads)** | 연락처를 남긴 사람들에 대한 후속 관리 파이프라인 |
| **[커넥터](/ko/connectors)** | 팀 단위 푸시 채널. **소유자와 관리자에게만 표시됨** |

상단의 검색창은 퀴즈, 문제 은행, 응답자, 리드를 모두 검색합니다. 하단에서는 **사이드바 접기**를 할 수 있습니다.

<Callout type="info">
  **리드**는 팀의 선택형 **모듈**입니다. 팀 소유자는 팀 설정의 **기본 정보**에서 이 모듈을 끌 수 있습니다. 끄면 모든 구성원에게서 사이드바와 관련 페이지가 모두 사라지고 새 데이터도 생성되지 않습니다. 기존 데이터는 보존되며 모듈을 다시 켜면 복원됩니다.
</Callout>

## 첫 리드를 확보하세요

새 팀의 대시보드에는 **첫 리드를 확보하세요** 체크리스트가 표시됩니다. 0에서 첫 제출까지 이어지는 4단계입니다.

1. **첫 퀴즈 만들기** — 템플릿에서 시작하세요. 채점, 결과 페이지, 리드 수집 화면이 미리 연결되어 있습니다.
2. **게시하기** — 퀴즈를 열고 공개로 전환합니다.
3. **링크 공유하기** — **공유**에서 링크나 임베드 코드를 가져옵니다. 프로필 링크, 내 웹사이트, 커뮤니티 게시물 어디든 좋습니다.
4. **첫 제출 받기** — 누군가 퀴즈를 완료하면 그 답변과 연락처가 **응답 기록**에 들어옵니다.

첫 제출을 받으면 체크리스트가 **순조롭게 진행 중입니다!**로 바뀝니다. 체크리스트는 언제든지 **숨기기**로 감출 수 있습니다.

## 퀴즈 안의 탭

퀴즈를 열면 네 개의 탭이 있습니다.

| 탭 | 용도 |
| --- | --- |
| **[편집](/ko/editor)** | 문항, 논리, 채점, 디자인 구성 |
| **[설정](/ko/editor/settings)** | 공개 및 권한, 기본 정보, 응답 환경, 결과 페이지 후속 조치, 언어, 시스템 문구, 분석 |
| **[응답 기록](/ko/results/records)** | 모든 제출 내역 |
| **[인사이트](/ko/results/insights)** | 완료율, 이탈 지점, 유입 경로별 전환 |

**[공유](/ko/publish)**는 별도의 탭이 아니라 탭 옆에 있는 버튼입니다. 클릭하면 **퀴즈 공유** 창이 열리며 **공유 링크**(QR 코드 포함), **공유 카드**, **임베드**, **배포 계획**(채널별 링크와 문구, 직접 만든 유입 경로를 위한 **채널 추가**)의 네 섹션으로 구성됩니다.

<Callout type="info">
  예전에는 퀴즈마다 별도의 "연결" 탭이 있었습니다. 이 기능은 팀 단위 [커넥터](/ko/connectors)로 옮겨졌습니다. 퀴즈마다 설정을 반복할 필요 없이 한 번 구성하면 모든 퀴즈에 적용됩니다.
</Callout>

<Callout type="info">
  대시보드에는 **현재 팀**의 퀴즈가 표시됩니다. 여러 팀에 속해 있다면 왼쪽 상단의 팀 전환기로 팀을 바꾸면 목록도 함께 바뀝니다.
</Callout>
