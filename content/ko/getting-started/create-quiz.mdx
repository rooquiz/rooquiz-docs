## 단계

<Steps>
### 만들고 싶은 것 선택

대시보드는 **무엇을 만들고 싶으신가요?**로 시작합니다. 목표에 따라 고르면 RooQuiz가 해당하는 [퀴즈 유형](/ko/getting-started/quiz-types)의 생성 서랍을 엽니다.

| 카드 | 용도 | 퀴즈 유형 |
| --- | --- | --- |
| **성격 퀴즈** | "나는 어떤 유형일까?" — 공유하기 좋게 만들어졌습니다 | 결과 유형 퀴즈 |
| **제품·강좌 찾기** | 각자에게 맞는 것을 매칭합니다 | 결과 유형 퀴즈 |
| **진단** | 준비도, 건강 점검, 성숙도 점수 | 점수 퀴즈 |
| **레벨 테스트** | 배치 및 실력 점검 | 지식 퀴즈 또는 점수 퀴즈 |
| **상식 챌린지** | 함께 겨루는 재미있는 지식 퀴즈 | 지식 퀴즈 |
| **AI 맞춤 리포트** | AI가 사람마다 리포트를 작성합니다 | AI 퀴즈 |

**레벨 테스트**는 **문제에 정답이 있나요?**라는 질문을 하나 더 합니다. 문법, 어휘, 수학처럼 정답과 오답으로 채점하는 문항이라면 지식 퀴즈가 되고, "영어로 대화할 수 있어요"처럼 각 선택지에 점수가 있는 자기 평가라면 점수 퀴즈가 됩니다.

### 템플릿 또는 빈 퀴즈

생성 서랍은 의도적으로 **템플릿** 화면부터 열립니다. 아무것도 없는 상태에서 작성하는 것보다 템플릿을 편집하는 편이 훨씬 빠르고, 문항 구조와 리포트 구성도 이미 다듬어져 있기 때문입니다.

- **템플릿에서 시작** — 카테고리별로 템플릿을 둘러보고 **사용량순** 또는 **최신순**으로 정렬한 뒤, 퀴즈(AI 퀴즈라면 **샘플 리포트**도)를 미리 보고 **이 템플릿 사용**을 클릭합니다. [템플릿 센터](/ko/library/templates)를 참고하세요.
- **빈 퀴즈에서 시작** — 모든 것을 직접 만듭니다.

### 편집기로 이동

생성하면 바로 [편집기](/ko/editor)로 이동해 문항을 추가할 수 있습니다.
</Steps>

<Callout type="warning">
  **퀴즈 유형은 한 번 선택하면 변경할 수 없습니다.** UI 어딘가에 숨겨져 있는 것이 아니라 생성 후 데이터 계층에서 해당 필드가 읽기 전용이 됩니다. 잘못 선택하면 다시 만들어야 하므로 점수, 차원별 프로필, 유형 결과 중 무엇을 원하는지 미리 정하세요.
</Callout>

전체 비교와 선택 가이드는 [네 가지 퀴즈 유형](/ko/getting-started/quiz-types)에 있습니다.

## 템플릿

템플릿은 문항, 채점, 리포트 설정을 포함한 퀴즈 전체 구조입니다. 복제한 뒤 자유롭게 편집할 수 있으며, **변경 사항은 원본 템플릿에 영향을 주지 않습니다**.

[템플릿](/ko/library)을 참고하세요.
