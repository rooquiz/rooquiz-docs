**응답자**는 퀴즈에 응답한 사람의 계정 프로필입니다. 이름, 이메일, 아바타, 직접 정의한 확장 필드, 그리고 제출 내역을 담고 있습니다.

<Callout type="info">
  응답자와 [리드](/ko/leads)는 서로 다른 두 계층입니다. **응답자는 사람이고, 리드는 그 사람의 후속 관리 기록입니다.** 응답자는 리드 없이도 존재할 수 있지만(익명으로 응답하고 떠난 사람), 리드는 항상 응답자에 속합니다.
</Callout>

![The RooQuiz respondents list with ID, name, email, source and status](/img/en/respondents/respondents-list.webp)

## 목록 구성

| 열 | 설명 |
| --- | --- |
| **응답자 ID** | 시스템이 생성한 비즈니스 ID. 복사할 수 있으며 외부에서 사람을 지칭할 때 사용 |
| **이름 / 이메일** | 클릭하면 상세 패널이 열림 |
| **유입 경로** | 이 사람이 어떻게 들어왔는지(아래 참고) |
| **상태** | 활성 또는 비활성 |
| **이메일 인증** | 이메일 주소를 인증했는지 여부 |
| **생성일** | 프로필이 만들어진 시점 |

[확장 필드](/ko/respondents/fields)를 구성했다면 추가 열로도 표시됩니다.

## 세 가지 유입 경로

**유입 경로**는 프로필이 **생성될 때** 기록되며 이후에는 바뀌지 않습니다. "이 사람이 어떻게 여기에 왔나"에 답합니다.

- **셀프 등록** — 응답 페이지에서 직접 로그인하거나 가입했습니다.
- **리드에서** — [리드를 직접 추가](/ko/leads/detail)할 때 함께 만들어졌습니다.
- **수동 추가** — **응답자 추가**로 직접 만들었습니다.

## 추가 및 비활성화

- **응답자 추가** — 이름과 이메일을 입력합니다. 비밀번호는 선택 사항입니다. 명단을 먼저 가져오고 나중에 각자 비밀번호를 설정하게 할 때 유용합니다.
- **비활성화 / 활성화** — 비활성화된 사람은 [포털](/ko/respondents/portal)에 로그인할 수 없지만, 과거 제출 내역은 모두 유지됩니다. 이전 고객이나 환불한 고객에게 적합합니다.

## 휴지통으로 이동

응답자를 삭제하면 휴지통으로 이동하며 **5일 이내에 복원**할 수 있습니다.

<Callout type="warning">
  응답자 삭제는 리드 삭제보다 영향이 큽니다. 해당 응답자의 **리드, 제출 내역, 예약도 함께 숨겨집니다.** 후속 관리 기록만 지우고 응답은 유지하고 싶다면 [리드를 휴지통으로 이동](/ko/leads/list-board)하세요.
</Callout>

일괄 삭제도 같은 방식으로 동작합니다. 여러 행을 선택하면 모두 휴지통으로 이동합니다.
