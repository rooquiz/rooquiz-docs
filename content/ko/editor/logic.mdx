조건부 논리는 응답자의 답변에 따라 **이후 문항을 표시하거나 숨겨** 고정된 설문을 적응형 설문으로 바꿉니다.

<Callout type="warning">
  조건부 논리는 **점수 퀴즈**와 **결과 유형 퀴즈**에서만 사용할 수 있습니다. 지식 퀴즈와 랜덤 지식 퀴즈에서는 편집기 오른쪽 패널에 **규칙** 탭이 없습니다.
</Callout>

## 규칙의 구성

규칙은 하나의 문장처럼 읽힙니다. **만약 … 그러면 문항을 표시 / 숨기기.**

편집기 오른쪽 패널의 **규칙** 탭에서 **+ 규칙 추가**를 클릭하고 다음 항목을 채웁니다.

| 구성 요소 | 설명 |
| --- | --- |
| **만약** | **앞에 있는 문항**, 연산자, 값을 선택합니다 |
| **그리고** | **조건 추가**로 조건을 이어 갑니다. 한 규칙 안의 조건은 AND로 결합되므로 모두 충족되어야 합니다 |
| **그러면** | **표시** 또는 **숨기기**를 고른 뒤 **대상 문항**을 선택합니다 |

퀴즈에는 여러 규칙을 둘 수 있으며 **규칙 1 / 규칙 2** 등으로 나열됩니다.

## 사용할 수 있는 연산자

| 연산자 | 사용 대상 |
| --- | --- |
| **같음** | 단일 선택, 참/거짓 |
| **다음 중 하나 포함 / 다음 중 어느 것도 포함하지 않음** | 다중 선택 — 지정한 선택지 중 하나라도 선택되면 일치 |
| **초과 / 이상 / 미만 / 이하 / 범위 내** | 숫자 답변 |

참/거짓 문항에서는 **✓ 참**과 **✗ 거짓**을 선택할 수 있습니다.

<Callout type="info">
  **조건**은 값이 확정되는 문항(선택형, 참/거짓, 평점, 숫자)만 참조할 수 있습니다. **대상**은 범위가 더 넓어 빈칸 채우기, 설명문, 이미지 캐러셀 문항도 표시하거나 숨길 수 있습니다. 이를 이용하면 "기타를 선택한 경우에만 설명을 요청"하는 후속 문항을 만들 수 있습니다.
</Callout>

## 설정 방법

<Steps>
### 문항부터 만들기

규칙은 특정 문항을 참조하므로 트리거 문항과 대상 문항이 모두 먼저 존재해야 합니다.

### 규칙 추가

문항 → 연산자 → 값 → 표시 또는 숨기기 → 대상 문항 순으로 선택합니다. 미완성 규칙을 저장하면 **규칙을 모두 입력해 주세요**라는 안내가 표시됩니다.

### 미리보기로 확인

각 답변 경로를 직접 시도해 보세요. 규칙이 두어 개를 넘어가면 머릿속으로만 따져서는 반드시 빠뜨리는 경우가 생깁니다.
</Steps>

## 주의할 점

- 대상 문항보다 **앞에** 있는 문항을 참조하세요. 뒤에 있는 문항을 가리키면 조건을 평가하는 시점에 아직 답변이 존재하지 않습니다.
- 숨겨진 문항은 표시되지 않으며 **필수 검사도 하지 않으므로** 제출을 막지 않습니다.
- 규칙을 삭제할 때는 확인을 요청하며, 삭제 후 대상 문항은 기본값인 표시 상태로 돌아갑니다.

<Callout type="info">
  문항을 숨기면 채점에도 영향을 줍니다. 표시되지 않은 문항에는 답변이 없으므로 점수에 기여하지 않습니다. 적응형 설문을 설계할 때는 [채점 규칙](/ko/editor/scoring)이 숨겨질 수 있는 문항과 맞는지 확인하세요.
</Callout>
