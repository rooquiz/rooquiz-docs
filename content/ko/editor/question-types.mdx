RooQuiz는 14가지 이상의 문항 유형을 제공합니다. 각 문항에 맞는 형식을 고를 수 있도록 아래에서 용도별로 묶어 소개합니다.

## 선택

| 유형 | 설명 | 주요 용도 |
| --- | --- | --- |
| **단일 선택** | 선택지 하나만 고름 | 정답이 하나인 지식 문항, 만족도 |
| **다중 선택** | 여러 선택지를 고름 | 정답이 여러 개인 문항, 관심사/선호도 |
| **드롭다운** | 드롭다운 형태의 단일 선택 | 선택지가 많을 때 공간 절약 |
| **캐스케이드** | 여러 단계가 연결된 선택(예: 시/도–시/군/구–동) | 지역 또는 계층형 카테고리 선택 |
| **참 / 거짓** | 참 또는 거짓 선택 | 예/아니요 문항 |
| **이미지 캐러셀** | 이미지 캐러셀로 선택 | 이미지 선호도, 시각적 선택지 |

## 입력

| 유형 | 설명 | 주요 용도 |
| --- | --- | --- |
| **빈칸 채우기** | 텍스트 입력 | 단답형, 서술형 응답, "기타, 직접 입력" |
| **숫자** | 숫자 입력(유효성 검사 포함) | 나이, 금액, 수량 |
| **날짜** | 날짜 선택기 | 생년월일, 예약 날짜 |
| **시간** | 시간 선택기 | 시간대, 특정 시각 |

## 평점 및 정렬

| 유형 | 설명 | 주요 용도 |
| --- | --- | --- |
| **평점** | 척도로 점수 매기기(예: 1–5 / 1–10) | 만족도, 중요도 |
| **순서 정렬** | 항목을 끌어서 순서 지정 | 우선순위, 선호도 순위 |

## 콘텐츠 및 특수

| 유형 | 설명 | 주요 용도 |
| --- | --- | --- |
| **설명문** | 텍스트만 표시하며 응답은 수집하지 않음 | 섹션 안내, 지시 사항, 고지 문구 |
| **랜덤 문항** | 문제 은행에서 문항을 뽑음 | "랜덤 지식 퀴즈" 유형과 함께 사용 |

## 퀴즈 유형별로 사용할 수 있는 문항 유형

문항 유형을 모든 퀴즈 유형에서 똑같이 쓸 수 있는 것은 아닙니다. 어떤 유형은 자연스러운 "정답"이 없고, 어떤 유형은 결과 유형에 투표할 수 없습니다. 왼쪽 패널에는 현재 퀴즈 유형에서 사용할 수 있는 유형만 표시됩니다.

| 유형 | 지식 퀴즈 | 점수 퀴즈 | 결과 유형 퀴즈 |
| --- | --- | --- | --- |
| 단일 / 다중 선택 / 드롭다운 / 참-거짓 | ✅ | ✅ | ✅ |
| 빈칸 채우기 | ✅ 정답과 비교해 채점 가능 | ✅ **수집만 하며 채점하지 않음** | ❌ |
| 숫자 | ✅ 정답과 비교해 채점 가능 | ✅ 제출된 숫자를 수식에 사용 | ❌ |
| 캐스케이드 / 평점 | ❌ | ✅ | ❌ |
| 날짜 / 시간 | ❌ | ✅ 수집만 함 | ❌ |
| 순서 정렬 | ✅ | ❌ | ❌ |
| 설명문 / 이미지 캐러셀 / 페이지 나누기 | ✅ | ✅ | ✅ |

**랜덤 지식 퀴즈**는 랜덤 문항과 표시용 유형만 사용하며, 실제 문항은 연결된 문제 은행에서 가져옵니다.

<Callout type="info">
  점수 퀴즈에서 **빈칸 채우기 문항은 텍스트만 수집합니다.** 점수를 만들지 않으며 채점 수식에서 참조할 수도 없습니다. 채점 문항 뒤에 "그 밖에 알려 주실 내용이 있나요?" 같은 마무리 질문으로 넣기에 알맞으며, 서술형 리드 정보를 다른 응답과 함께 받을 수 있습니다.
</Callout>

<Callout type="info">
  각 유형에는 오른쪽 패널에 고유한 설정이 있습니다. 대표적으로 제목과 설명, 필수 토글, 선택지 내용, 유효성 검사 규칙이 있습니다. 채점을 지원하는 유형은 배점도 설정할 수 있습니다([채점 및 평가 규칙](/ko/editor/scoring) 참고).
</Callout>

<Callout type="warning">
  **랜덤 문항**은 주로 "랜덤 지식 퀴즈" 유형과 함께 사용하며 연결된 문제 은행이 필요합니다. 다른 유형에서는 적용되지 않을 수 있습니다.
</Callout>
