하나의 퀴즈에 여러 **언어 버전**을 둘 수 있습니다. 모든 버전이 하나의 문항 구조와 채점 구성을 공유하고 문구만 다르기 때문에, 문항을 한 번 수정하면 모든 언어에 반영됩니다. "중국어 버전에는 문항을 추가하고 영어 버전은 깜빡했다" 같은 일은 더 이상 없습니다.

<Callout type="info">
  이 모델은 **하나의 원본, 여러 번역** 구조입니다. 퀴즈 자체가 **기본 언어**를 가진 **원본**이며, 다른 언어는 각각 문항 코드를 기준으로 원본 구조 위에 얹히는 **번역**입니다.
</Callout>

## 언어 버전 추가

퀴즈의 **설정 → 언어 버전**에서 진행합니다.

<Steps>
### 기본 언어 확인

**기본 언어**는 원본 콘텐츠의 언어입니다. 이미 번역으로 사용 중인 언어는 기본 언어로 선택할 수 없습니다.

### 언어 추가

**언어 추가**를 클릭하고 대상 언어를 선택합니다. 원본 문구가 복제되어 시작 초안이 됩니다.

### 번역 편집

**번역 편집**을 클릭해 번역 편집기를 열고 문구를 차례로 번역합니다.
</Steps>

![The RooQuiz translation editor with source copy on the left and translations on the right](/img/en/editor/translations.webp)

*번역 편집기는 좌우 나란히 배치됩니다. 왼쪽에는 원본 문구(읽기 전용), 오른쪽에는 대상 언어가 표시됩니다. 상단의 토글로 이 언어 버전의 공개 여부를 제어합니다.*

## 번역에서 바꿀 수 있는 것

**사람이 읽는 문구**만 바꿀 수 있습니다. 제목, 설명, 문항 질문, 선택지 라벨, 리포트 레벨 이름과 설명, 결과 유형 이름, 응답 페이지 시스템 텍스트가 해당됩니다.

번역에서는 구조를 바꿀 수 **없습니다**. 문항 추가·삭제, 채점 조정, 조건부 논리 편집은 모두 원본 퀴즈에서 하며, 모든 언어가 변경 사항을 자동으로 반영합니다.

<Callout type="info">
  부분 번역도 허용됩니다. 번역하지 않은 문항은 비어 있거나 오류가 나는 대신 원본 문구로 표시되므로, 먼저 공개하고 나중에 마무리할 수 있습니다.
</Callout>

## 응답자에게 보이는 버전

각 언어 버전에는 고유한 공개 링크(`?lang=` 매개변수가 붙은 공유 URL)가 있으며, 설정에서 **공개 페이지 열기**로 바로 미리 볼 수 있습니다.

## 일시 중지와 삭제

- **일시 중지** — 언어 버전마다 따로 **일시 중지됨**으로 표시할 수 있습니다. 공개적으로는 이용할 수 없게 되지만 콘텐츠는 유지되며, 퀴즈 전체의 공개/중지 스위치와는 별개로 동작합니다.
- **삭제** — 언어 버전을 삭제해도 **제출 내역은 유지됩니다**. 응답은 번역이 아니라 원본 퀴즈에 속하기 때문입니다.

<Callout type="warning">
  기본 언어를 바꾸면 원본 콘텐츠의 언어 **표시만 바뀌며** 아무것도 번역되지 않습니다. 다른 언어를 제공하려면 번역을 추가하세요.
</Callout>
