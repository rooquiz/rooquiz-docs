퀴즈의 모양은 세 계층으로 이루어지며, 모두 편집기 오른쪽의 **개인화** 탭에 있습니다.

| 계층 | 제어하는 내용 |
| --- | --- |
| **디자인** | 시작 페이지, 문항 페이지, 결과 페이지의 레이아웃, 즉 전체적인 분위기 |
| **테마** | 그 레이아웃 위에 적용되는 색상, 모서리 둥글기, 밀도 |
| **모듈** | 시작 페이지와 결과 페이지에 추가하는 콘텐츠 블록(갤러리의 디자인에서만 사용 가능) |

변경 사항은 미리 보기에 실시간으로 반영됩니다. 미리 보기에서 아무 요소나 클릭하면 오른쪽 패널에 해당 설정이 열립니다.

## 디자인 선택

**디자인** 카드에 현재 디자인이 표시됩니다. 썸네일이나 **변경**을 클릭하면 갤러리가 열립니다.

- **기본**은 대부분의 퀴즈에 어울리는 깔끔하고 중립적인 레이아웃입니다.
- 다른 디자인은 코칭, 강좌, 금융, 피트니스, 웰니스 등 특정 용도에 맞춰 만들어졌으며, 각각 고유한 시작 페이지, 결과 페이지, 기본 모듈을 갖추고 있습니다. [Quiz themes](https://rooquiz.com/explore/themes) 페이지에서 실제 샘플 퀴즈로 둘러볼 수 있습니다.
- 우리 팀만을 위해 만든 디자인은 **전용** 태그와 함께 맨 앞에 나열됩니다.
- 디자인을 선택하면 설명과 미리 보기 이미지를 볼 수 있습니다. **내 퀴즈에 적용해 보기**를 누르면 아무것도 바꾸지 않고 내 문항으로 미리 볼 수 있습니다.
- 전환하려면 **선택 확인**을 클릭합니다.

<Callout type="warning">
  디자인을 전환하면 **현재 개인화 설정이 초기화됩니다**. 디자인마다 레이아웃 매개변수, 문구, 기본 모듈이 다르기 때문에 이전 조정 값을 그대로 가져갈 수 없습니다. 기존 설정을 유지하고 싶다면 먼저 퀴즈를 복제하세요.
</Callout>

### Pro 디자인

**Pro** 표시가 있는 디자인은 모든 팀이 사용해 보고 편집할 수 있지만, **Pro 디자인을 적용한 퀴즈를 저장하려면 Pro 요금제가 필요합니다**. Free 요금제에서는 "이 디자인은 Pro가 필요합니다. 업그레이드하여 저장하거나 무료 디자인으로 바꾸세요."라는 안내가 표시됩니다.

팀이 Pro를 해지하면 이미 Pro 디자인을 사용 중인 퀴즈의 설정은 그대로 유지되지만, 다시 업그레이드할 때까지 공개 페이지에는 기본 디자인이 표시됩니다.

<Callout type="info">
  마음에 드는 모양을 찾지 못했나요? RooQuiz 팀이 브랜드에 맞춰 우리 팀에서만 보이는 테마를 디자인해 드립니다. [Custom quiz design](https://rooquiz.com/custom-quiz-design)을 참고하세요(Pro 요금제 필요).
</Callout>

## 테마

**테마** 카드에서 색상 팔레트를 정합니다.

- 그리드에서 테마를 고릅니다. **색상** 행에 팔레트가 표시됩니다. 기본, 주 색상, 보조, 강조, 중립 색상과 정보 / 성공 / 경고 / 오류 색상이며, **모두 보기**를 누르면 펼쳐집니다.
- **이미지에서 색상 추출** — 브랜드 이미지를 업로드하면 그 이미지에서 팔레트가 생성됩니다. 16진수 코드를 직접 입력하는 것보다 편리합니다.
- **다크 테마 추가**(또는 **라이트 테마 추가**) — 방문자의 기기가 다크(또는 라이트) 모드일 때 퀴즈가 자동으로 전환됩니다. 추가 테마는 색상만 바꾸며, 모양은 항상 주 테마를 따릅니다. 일부 디자인에는 라이트/다크 조합이 고정되어 있습니다.

**스타일** 카드에서는 모양을 세밀하게 조정합니다.

| 컨트롤 | 설명 |
| --- | --- |
| **모서리 둥글기** | 박스, 입력 필드, 선택기에 각각 다른 값 지정 |
| **효과** | **깊이**와 **노이즈** 질감 토글 |
| **크기** | 입력 필드와 선택기 크기, 테두리 두께 |

## 문구와 이미지

갤러리의 디자인에는 태그라인, 시작 버튼 옆 문구, 결과 페이지의 "다음 단계" 상자 같은 고유한 문구가 들어 있습니다. 시작 페이지와 결과 페이지 설정의 **테마 문구**에서 편집하며, 표시되는 위치에 따라 **헤더**, **시작 버튼 옆**, **"다음 단계" 상자**, **기타**로 묶여 있습니다.

이미지 필드는 업로드, 교체, 삭제할 수 있고 **Unsplash에서 선택**으로 고를 수도 있습니다. **표시 영역 조정**을 사용하면 디자인이 쓰는 비율에 맞춰 자르기 영역을 끌어서 옮기고 크기를 바꿀 수 있습니다.

## 모듈

갤러리의 디자인에서는 소개, 후기, FAQ, 가격, 프로필 같은 콘텐츠 블록인 **모듈**을 **시작 페이지**와 **결과 페이지**에 추가할 수 있습니다. 기본 디자인에는 모듈이 없습니다.

- **추가** — 기존 모듈 아래의 **+ 모듈 추가**를 클릭하고 갤러리에서 하나를 고릅니다. 일부 디자인에는 고유한 모듈이 있으며 **이 테마 전용** 아래에 나열됩니다.
- **편집** — 모듈을 클릭한 뒤 **편집**을 누릅니다. 편집 화면 왼쪽에는 실시간 미리 보기가(아무 텍스트나 클릭해 그 자리에서 편집), 오른쪽에는 모듈의 필드가 표시됩니다. **저장**하면 변경 사항이 적용되고, **취소**하면 버려집니다.
- **순서 변경 또는 삭제** — 모듈 작업 표시줄의 **위로 이동**, **아래로 이동**, **삭제**를 사용합니다.
- **시작 버튼** — 시작 페이지에서는 시작 버튼도 모듈 사이에서 위아래로 옮길 수 있습니다.
- **결과 페이지 섹션** — 기본 제공되는 **차원 분석**, **예약 섹션**, **응답자 피드백** 블록이 모듈과 같은 목록에 있으므로, 예를 들어 예약을 후기보다 위에 둘 수 있습니다. 기본 제공 섹션은 여기서 옮길 수는 있지만 편집하거나 삭제할 수는 없습니다.

<Callout type="info">
  한 퀴즈에는 시작 페이지와 결과 페이지를 합쳐 **최대 20개의 모듈**을 둘 수 있습니다. 시작 버튼과 기본 제공 결과 섹션은 개수에 포함되지 않습니다.
</Callout>

## 헤더와 진행 표시

편집기 왼쪽 목록에서 **헤더**를 클릭하면 **헤더 제목**(**제목 표시** 토글 포함), **헤더 설명**, **헤더 정렬**(왼쪽 / 가운데 / 오른쪽)을 설정할 수 있습니다.

**진행 표시 스타일**은 여러 페이지로 된 퀴즈에서 진행 상황을 보여 주는 방식으로, **없음**, **배지**, **막대**, **구간** 중에서 고릅니다. 디자인마다 기본값이 정해져 있습니다.

평점 문항에는 문항 설정에 별도의 **표시 스타일**(**별** 또는 **숫자**)이 있습니다.

## 결과 페이지 점수 스타일

결과 페이지에서 종합 점수를 그리는 방식(**눈금 막대**, **링**, **게이지**, **계단**)은 **리포트** 섹션의 **종합 분석**에서 설정합니다. 디자인을 전환하면 해당 디자인의 기본값으로 바뀌며, 이후에 다시 변경할 수 있습니다. [레벨과 결과 페이지 동작](/ko/editor/scoring#레벨과-결과-페이지-동작)을 참고하세요.

## 랜딩 페이지

랜딩 페이지(시작 페이지)는 응답자가 처음 보는 화면입니다. 랜딩 페이지 설정에서 다음을 제어합니다.

- **랜딩 페이지 사용** — 끄면 바로 문항으로 시작합니다.
- **표지 이미지**(**헤더 이미지 업로드**), 퀴즈 제목과 설명
- 갤러리의 디자인에서는 **테마 문구**와 모듈

시작 버튼의 문구는 **설정 → 시스템 문구**에 있습니다.

<Callout type="info">
  랜딩 페이지는 [검색엔진 색인](/ko/publish/promotion#검색엔진-색인)에도 영향을 줍니다. 랜딩 페이지를 끄면 퀴즈가 바로 문항으로 시작되어 검색엔진이 읽을 내용이 거의 없습니다. 검색으로 발견되길 원한다면 랜딩 페이지를 켜 두고 실제 설명을 작성하세요.
</Callout>
