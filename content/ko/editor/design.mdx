디자인은 두 단계로 나뉩니다. **테마**는 색상과 모서리 둥글기를, **개인화 템플릿**은 페이지 레이아웃 자체를 결정합니다. 대부분의 경우 테마만으로 충분합니다.

## 테마

편집기의 **테마 선택**에서 조정하며, 변경 사항은 미리보기에 실시간으로 반영됩니다.

| 컨트롤 | 설명 |
| --- | --- |
| **테마 색상** | 기본, 보조, 강조, 중립 색상과 정보 / 성공 / 경고 / 오류 색상 |
| **모서리 둥글기** | 박스, 입력 필드, 선택기에 각각 다른 값 지정 |
| **효과** | 깊이감, 노이즈 등 질감 관련 토글 |
| **크기 및 테두리** | 전체 밀도와 테두리 두께 |

<Callout type="info">
  브랜드 이미지가 있다면 **이미지에서 색상 추출**을 사용하세요. 이미지를 업로드하면 팔레트가 추출되어 테마 색상에 적용되므로, 16진수 코드를 직접 입력하는 것보다 편리합니다.
</Callout>

## 개인화 템플릿

개인화 템플릿은 색상만이 아니라 **레이아웃**을 바꿉니다. 두 가지 템플릿을 사용할 수 있습니다.

| 템플릿 | 설명 |
| --- | --- |
| **기본** | 표준 레이아웃. 깔끔하고 중립적이어서 대부분의 퀴즈에 적합합니다 |
| **키네틱** | 디자인 중심 레이아웃. 시작 페이지와 결과 페이지에 더 강한 시각적 연출을 적용합니다 |

<Callout type="warning">
  키네틱으로 전환하려면 **Pro가 필요합니다**. 제한은 *전환하는* 동작에만 적용됩니다. 이미 키네틱을 사용 중인 퀴즈는 무료 팀에서도 정상적으로 표시·편집·복제되며, 아무것도 다운그레이드되지 않습니다.
</Callout>

템플릿을 전환하면 **현재 개인화 설정이 초기화된다**는 경고가 표시됩니다. 레이아웃이 다르면 레이아웃 매개변수도 다르기 때문에 이전 조정 값을 그대로 가져갈 수 없습니다. 기존 설정을 유지하고 싶다면 먼저 퀴즈를 복제하세요.

## 시작 페이지

시작 페이지는 응답자가 처음 보는 화면입니다. 편집기에서 다음을 제어할 수 있습니다.

- **제목**과 **설명**의 표시 여부와 정렬 방식
- **표지 이미지**
- 시작 버튼의 문구

<Callout type="info">
  시작 페이지는 [검색엔진 색인](/ko/publish/promotion)에도 영향을 줍니다. 시작 페이지를 끄면 퀴즈가 바로 문항으로 시작되어 검색엔진이 읽을 내용이 거의 없습니다. 검색으로 발견되길 원한다면 시작 페이지를 켜 두고 실제 설명을 작성하세요.
</Callout>
