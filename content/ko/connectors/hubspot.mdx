---

**HubSpot 커넥터**는 퀴즈로 수집한 모든 리드에 대해 HubSpot 연락처를 만들거나 업데이트하고, 가장 최근 퀴즈 결과를 연락처 속성에 기록하며, 연락처 타임라인에 결과 메모를 추가할 수도 있습니다. 이 속성을 HubSpot 목록, 워크플로, 리드 스코어링에 활용하면 응답 내용에 맞춰 후속 조치를 할 수 있습니다.

<Callout type="info">
  HubSpot은 **Pro 요금제 전용**이며, **팀 소유자 또는 관리자**만 설정할 수 있습니다. 팀마다 HubSpot 계정을 **하나**만 연결할 수 있습니다. 무료 CRM을 포함한 모든 HubSpot 에디션에서 사용할 수 있습니다.
</Callout>

## 연결하기

<Steps>
### HubSpot 카드 열기

**커넥터**로 이동해 **오디언스 동기화** 아래의 **HubSpot**을 찾고 **HubSpot 연결**을 클릭합니다.

![RooQuiz의 HubSpot 커넥터 페이지: HubSpot 연결 버튼과 HubSpot의 미확인 앱 경고에 대한 안내](/img/en/connectors/hubspot-connect.webp)

### 로그인하고 계정 선택

요청이 표시되면 HubSpot에 로그인합니다. 로그인한 사용자가 여러 HubSpot 계정에 접근할 수 있다면 연락처를 보낼 계정을 선택합니다.

### 접근 승인

HubSpot에 RooQuiz가 접근할 수 있는 항목이 표시됩니다([권한](#권한) 참고). **Connect app**을 클릭합니다.

RooQuiz가 HubSpot App Marketplace에 등록되기 전까지는 HubSpot에 **확인되지 않은 앱** 경고가 표시되고, 계속하려면 `I accept the risk`를 입력하라는 요청이 나타납니다. 정상적인 동작이니 입력한 뒤 **Connect**를 클릭하세요.

### RooQuiz에서 설정 마치기

RooQuiz 커넥터 페이지로 돌아오면 **HubSpot 연동 설정** 대화 상자가 열립니다. 아래 옵션을 선택하고 **저장**을 클릭하면 저장하는 즉시 커넥터가 전송을 시작합니다.
</Steps>

<Callout type="warning">
  **HubSpot 연결**을 클릭한 뒤 **10분 이내**에 HubSpot 단계를 마쳐야 합니다. 시간이 지나면 승인 링크가 만료되고 RooQuiz에 "승인 링크가 만료되었습니다"라는 메시지가 표시됩니다. 이때는 **HubSpot 연결**을 다시 클릭하면 됩니다.
</Callout>

## 설정

![HubSpot 설정 대화상자: 이름, 트리거 이벤트, 트리거 범위, 결과 메모 스위치, HubSpot에 기록되는 필드](/img/en/connectors/hubspot-settings.webp)

- **이름** — 목록에 표시되는 커넥터 이름이며, 기본값은 `HubSpot • <계정 이름>`입니다.
- **트리거 이벤트** — **새 응답**(퀴즈를 완료할 때마다) 및/또는 **새 리드**(처음으로 연락처 정보를 남겼을 때). 기본적으로 둘 다 켜져 있습니다. [트리거 이벤트 및 범위](/ko/connectors/events)를 참고하세요.
- **트리거 범위** — 모든 퀴즈 또는 선택한 퀴즈만.
- **연락처 타임라인에 결과 메모 추가** — 기본적으로 켜져 있습니다. 새 응답마다 퀴즈 이름, 점수, 레벨 또는 결과 유형, RooQuiz의 리포트와 리드 링크가 담긴 메모가 추가됩니다.

나중에 변경하려면 커넥터 카드의 **편집**을 여세요.

## RooQuiz가 HubSpot에 기록하는 내용

연락처는 **이메일로 매칭**됩니다. 같은 이메일의 연락처가 있으면 업데이트하고, 없으면 새로 만듭니다. 이메일 주소가 없는 응답은 건너뜁니다.

처음 전송할 때 RooQuiz는 HubSpot 계정에 **RooQuiz** 속성 그룹을 만들고 다음 연락처 속성을 추가합니다.

| 속성 | 내용 |
| --- | --- |
| `rooquiz_last_quiz` | 가장 최근 퀴즈의 이름 |
| `rooquiz_last_score` / `rooquiz_last_max_score` | 점수와 최고 점수 |
| `rooquiz_last_level` | 결과 레벨(점수 퀴즈와 지식 퀴즈) |
| `rooquiz_last_outcome` | 결과 유형(결과 유형 퀴즈) |
| `rooquiz_last_report_url` | 응답자 리포트 링크 |
| `rooquiz_last_submitted_at` | 응답을 제출한 시각 |
| `rooquiz_lead_url` | RooQuiz의 리드 링크 |
| `rooquiz_utm_source`, `_medium`, `_campaign`, `_term`, `_content` | 퀴즈 링크의 UTM 매개변수 |

표준 **이메일**, **이름**, **성**, **전화번호** 속성도 채웁니다. 전체 이름은 첫 번째 공백을 기준으로 이름과 성으로 나뉩니다.

- 응답이 들어올 때마다 이 값들을 **덮어쓰므로**, 항상 그 사람의 가장 최근 퀴즈를 나타냅니다.
- 빈 값은 기록하지 않으므로 RooQuiz가 기존 데이터를 지우지 않습니다. 예를 들어 점수가 없는 퀴즈를 다시 응시해도 이전에 점수가 있던 퀴즈의 점수는 그대로 유지됩니다.
- RooQuiz는 라이프사이클 단계, 리드 상태, 이메일 구독 설정을 **변경하지 않습니다**. 이 항목들은 CRM 자체 규칙을 따릅니다.

<Callout type="info">
  결과에 따라 리드를 분류하려면 RooQuiz 속성으로 필터링하는 HubSpot 목록이나 워크플로를 만드세요. 예를 들어 `rooquiz_last_level`이 `Advanced`인 연락처를 그에 맞는 시퀀스에 등록할 수 있습니다.
</Callout>

## 권한

RooQuiz는 HubSpot에 다음 범위를 요청합니다.

| 범위 | 이유 |
| --- | --- |
| `crm.objects.contacts.read` / `.write` | 이메일로 연락처를 찾고, 만들거나 업데이트하고, 결과 메모를 추가합니다 |
| `crm.schemas.contacts.read` / `.write` | RooQuiz 속성 그룹과 속성을 확인하고 만듭니다 |
| `oauth` | HubSpot 표준 로그인 |

RooQuiz는 연락처를 삭제하지 않으며, HubSpot 계정의 다른 데이터를 읽거나 내보내지 않습니다.

## 연결 해제

동기화를 중단하려면 RooQuiz에서 HubSpot 커넥터 카드를 삭제합니다. HubSpot 쪽에서도 RooQuiz의 접근 권한을 제거하려면 HubSpot의 **Settings → Integrations → Connected apps**에서 RooQuiz를 제거하세요. 이미 기록된 연락처, 속성, 메모는 HubSpot에 그대로 남습니다.

팀이 무료 요금제로 전환되면 커넥터는 설정을 유지한 채 일시 중지되며, 다시 업그레이드하면 재개됩니다.

## 문제 해결

- **"승인 링크가 만료되었습니다"** — HubSpot 단계가 10분을 넘었습니다. **HubSpot 연결**을 다시 클릭하세요.
- **"HubSpot 승인이 취소되었습니다"** — HubSpot 화면에서 **Cancel**을 클릭했습니다. 준비되면 다시 시작하세요.
- **"이 팀은 이미 HubSpot에 연결되어 있습니다"** — 기존 HubSpot 커넥터를 먼저 삭제하세요.
- **리드가 HubSpot에 나타나지 않음** — 응답에 이메일 주소가 있는지, 해당 퀴즈가 커넥터의 트리거 범위에 포함되는지 확인하세요. 전송 오류가 있었다면 커넥터 카드에 마지막 오류가 표시됩니다.
