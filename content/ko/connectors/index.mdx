**커넥터**는 퀴즈에서 생성된 리드와 예약을 이메일, 자체 백엔드, Slack, 이메일 마케팅 서비스 등 이미 사용 중인 도구로 보내 줍니다. 왼쪽 사이드바의 **커넥터**에서 찾을 수 있습니다.

<Callout type="info">
  커넥터는 **팀 단위**입니다. 하나를 구성하면 모든 퀴즈가 사용합니다. 특정 퀴즈만 커넥터를 실행하게 하려면 [트리거 범위](/ko/connectors/events)로 좁히세요.
</Callout>

![RooQuiz 커넥터 페이지: 커넥터 카드가 알림, 시스템으로 전송, 오디언스 동기화 세 그룹으로 정리되어 있습니다](/img/en/connectors/connectors-list.webp)

이 페이지는 모든 항목을 용도별로 묶어 보여 줍니다.

| 그룹 | 포함 항목 |
| --- | --- |
| **발신 계정** | **Gmail** — **Gmail 연결**로 Gmail 계정을 발송 서비스로 연결합니다. [메일 발송 서비스](/ko/connectors/email-smtp)를 참고하세요 |
| **팀에 알리기** | 이메일, Slack |
| **시스템으로 전송** | Webhook, Zapier |
| **오디언스 동기화** | Kit |

## 다섯 가지 채널

| 채널 | 용도 |
| --- | --- |
| **이메일** | 이벤트가 발생하면 지정한 수신자에게 맞춤 알림을 보냅니다. 팀당 최대 3개 |
| **Webhook** | HMAC 서명과 함께 자체 URL로 POST 요청을 보냅니다 |
| **Slack** | Slack 앱을 승인하고 새 리드를 채널에 게시합니다 |
| **Zapier** | Catch Hook URL을 붙여 넣어 수천 개의 앱과 연결합니다 |
| **Kit** | 새 리드를 Kit(ConvertKit) 구독자로 추가하고 태그를 지정합니다 |

각 커넥터는 선택한 이벤트(새 응답, 새 리드, 예약 생성·취소·변경)에 따라 실행됩니다. 자세한 내용은 [트리거 이벤트 및 범위](/ko/connectors/events)를 참고하세요. 각 커넥터는 독립적으로 실행되며 **하나를 비활성화해도 다른 커넥터에는 영향이 없습니다.** 채널별 설정 방법은 [다섯 가지 채널](/ko/connectors/channels)에서 다룹니다.

## 권한과 요금제

<Callout type="warning">
  커넥터는 **팀 소유자 또는 관리자**만 관리할 수 있습니다. 다른 구성원에게는 권한 없음 안내가 표시되며, 사이드바 항목도 보이지 않습니다.
</Callout>

**이메일**과 **Slack**은 모든 요금제에서 사용할 수 있으며, **Webhook**, **Zapier**, **Kit**는 **Pro 전용**입니다. 무료 팀에서 Pro 채널을 선택하면 구성 영역이 회색으로 비활성화되고 업그레이드 링크가 표시됩니다.

## 커넥터 카드가 알려 주는 정보

구성된 각 커넥터에는 다음이 표시됩니다.

- **사용 중 / 사용 안 함** — 동작 중인지 여부
- **설정 미완료** — OAuth는 끝났지만 채널 선택이나 마지막 단계가 아직 남아 있습니다. 이 상태에서는 전송되지 않습니다.
- **마지막 전송** — 마지막으로 실행된 시점과 결과(성공 / 실패)

<Callout type="info">
  설정을 마친 후 **테스트 전송**을 눌러 상대편에서 실제로 받는지 확인하세요. 첫 실제 리드가 들어왔을 때 문제를 발견하는 것보다 낫습니다.
</Callout>
