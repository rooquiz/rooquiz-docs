문제 은행은 **반복해서 뽑아 쓸 수 있는 문항** 모음입니다. 왼쪽 사이드바의 **문제 은행**에서 찾을 수 있습니다.

<Callout type="warning">
  문제 은행의 모든 문항에는 **반드시 정답이 있어야 합니다.** 문제 은행은 채점용 문항 모음이지 데이터 수집 항목을 보관하는 곳이 아닙니다.
</Callout>

![RooQuiz question banks list with question counts and difficulty](/img/en/library/question-banks.webp)

## 문제 은행 만들기

<Steps>
### "문제 은행 만들기" 클릭

부제목에 "지식 퀴즈 또는 점수 퀴즈"라고 표시됩니다. 문제 은행은 이 두 가지 채점형 시나리오에 사용됩니다.

### 기본 정보 입력

**은행 이름**(최대 50자), **설명**(최대 200자), **난이도**를 입력합니다.

### 문항 추가

문제 은행을 열고 **문제 추가**를 클릭합니다. 편집기에서 작성하는 것과 같은 방식으로 유형을 고르고 질문과 선택지를 작성한 뒤 정답을 설정합니다.
</Steps>

## 공개 문제 은행 복사하기

RooQuiz는 [rooquiz.com/explore/question-banks](https://rooquiz.com/explore/question-banks)에서 무료 **공개 문제 은행**도 제공합니다. 공개 문제 은행은 미리 보기 전용이며, 사용하려면 **내 문제 은행으로 복사**를 클릭하세요. 그러면 팀 안에 편집 가능한 사본이 만들어지고, 여기에 문항을 추가하거나 편집하고 퀴즈에서 뽑아 쓸 수 있습니다.

- **팀 소유자나 관리자**만 문제 은행을 복사할 수 있습니다.
- 이미 복사한 문제 은행이라면 두 번째 사본을 만드는 대신 "이미 이 문제 은행의 사본이 있습니다"라는 메시지가 표시됩니다.
- 아주 큰 문제 은행은 일부만 복사됩니다: "문제 은행이 너무 커서 처음 N개 문항만 복사되었습니다".

## 문항 관리

- **끌어서 순서 변경** — 문항 순서를 바로 바꿀 수 있습니다.
- **일괄 삭제** — 여러 문항을 선택해 한 번에 삭제합니다. **되돌릴 수 없습니다**.
- **정보 편집** — 문제 은행의 이름, 설명, 난이도를 바꿉니다.

<Callout type="warning">
  문제 은행은 **비워야 삭제할 수 있습니다.** 그렇지 않으면 "이 문제 은행을 삭제하기 전에 모든 문제를 삭제해 주세요"라는 메시지가 표시됩니다. 실수로 문제 은행 전체를 지우지 않도록 하기 위한 안전장치입니다.
</Callout>

## 퀴즈에서 문제 은행 사용하기

대시보드에서 **지식 퀴즈 만들기**를 클릭하고 **랜덤 지식 퀴즈 만들기** 탭으로 전환합니다. 문제 은행을 고른 뒤 **추첨 규칙**을 설정합니다. 문항 유형마다 뽑을 문항 수와 문항당 점수를 정합니다. 응답자마다 독립적으로 무작위 추첨이 이루어집니다.

**문항 고정 시간**은 응답자가 같은 문항 세트를 얼마나 오래 유지할지 정합니다. 고정되어 있는 동안에는 새로고침하거나 다시 들어와도 같은 문항이 표시되고, 시간이 지나면 새 세트를 뽑습니다. **고정 안 함(새로고침마다 재추첨)** 또는 30분부터 24시간 사이의 시간을 선택하세요.

<Callout type="warning">
  이렇게 만든 퀴즈는 **랜덤 지식 퀴즈**로, 지식 퀴즈와는 다른 유형입니다. **유형은 생성 후 변경할 수 없으므로** 고정 문항과 무작위 문항 사이를 오가려면 퀴즈를 다시 만들어야 합니다. [네 가지 퀴즈 유형](/ko/getting-started/quiz-types)을 참고하세요.
</Callout>
