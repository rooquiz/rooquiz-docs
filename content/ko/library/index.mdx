둘 다 재사용 방식이지만 재사용하는 대상이 다릅니다.

| | 문제 은행 | 템플릿 |
| --- | --- | --- |
| 재사용 대상 | **반복해서 뽑아 쓰는 문항** 모음 | **완성된 퀴즈 구조** |
| 사용 방법 | 퀴즈를 만들 때 무작위로 문항을 뽑음 | 새 퀴즈로 복제한 뒤 편집 |
| 적합한 용도 | 같은 내용을 반복해서 테스트 | 같은 평가를 여러 고객에게 진행 |

<Callout type="info">
  헷갈린다면 이렇게 판단하세요. **매번 문항이 달라야 한다 → 문제 은행, 퀴즈는 같고 대상만 바뀐다 → 템플릿.**
</Callout>

## 문제 은행

문제 은행은 팀이 직접 관리하는 문항 모음으로, 모든 문항에 정답이 있습니다. 퀴즈를 만들 때 무작위 추출을 선택하면 시스템이 매번 다른 문항 세트를 뽑아 주므로, 연습 퀴즈와 지식 점검에 적합합니다.

[문제 은행](/ko/library/question-banks)을 참고하세요.

## 템플릿

템플릿 센터에는 복제할 수 있는 완성된 퀴즈가 모여 있습니다. 공식 템플릿으로 빠르게 시작하거나, 잘 만든 퀴즈를 템플릿으로 게시해 팀이 재사용하게 할 수 있습니다.

[템플릿 센터](/ko/library/templates)를 참고하세요.
