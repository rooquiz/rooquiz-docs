RooQuiz bietet vier Quiztypen (Szenarien), die jeweils auf ein anderes Ziel ausgerichtet sind.

<Callout type="warning">
  **Der Typ wird beim Erstellen gewählt und kann danach nicht mehr geändert werden.** Das ist eine Einschränkung auf Datenebene, kein fehlendes Bedienelement. Eine falsche Wahl bedeutet Neuaufbau.
</Callout>

## Wissensquiz

Für Wissenstests, Online-Prüfungen und bewertete Übungen – Szenarien, die eine **Richtig/Falsch-Beurteilung und Punktevergabe** benötigen.

- **Feste Reihenfolge**: Alle Teilnehmer sehen die Fragen in derselben Reihenfolge.
- **Bewertung**: Vergeben Sie Punkte für Fragen oder richtige Optionen; die Gesamtpunktzahl wird automatisch addiert.
- **Beurteilung & Feedback**: Markieren Sie richtige Antworten, legen Sie eine Bestehensgrenze fest und zeigen Sie den Teilnehmern ihre Punktzahl und Feedback.

## Bewertetes Quiz

Für Persönlichkeitstests, Kompetenzbewertungen und Umfragen – Szenarien, die eine **mehrdimensionale Analyse** statt eines einfachen Richtig/Falsch erfordern.

- **Mehrdimensionale Bewertung**: Ordnen Sie Fragen mehreren Dimensionen zu und erzeugen Sie mehrdimensionale Ergebnisse, oft als **Netzdiagramm** dargestellt.
- **Bedingte Logik**: Blenden Sie spätere Fragen abhängig von früheren Antworten ein oder aus und ermöglichen Sie so adaptive Umfragen.
- **KI-Auswertung**: Lassen Sie Textantworten von der KI auswerten und umfassendere Analysen erstellen (abhängig vom KI-Kontingent).
- **Berichtszustellung**: Ergebnisse können auf dem Bildschirm angezeigt, als PDF exportiert oder per E-Mail versendet werden (E-Mail ist eine Pro-Funktion).

## Ergebnisquiz

Für Persönlichkeitsquizze, unterhaltsame „Welcher X bist du?“-Quizze und diagnostische Lead-Magneten – Szenarien, die statt einer Punktzahl einen **Ergebnistyp** liefern.

- **Ergebnistypen**: Legen Sie vorab eine Reihe von Ergebnistypen fest (z. B. Löwe / Eule); jeder Typ hat einen eigenen Namen, eine Themenfarbe, ein Bild und einen Ergebnisinhalt in Rich Text.
- **Abstimmung über Auswahl**: Jede Auswahl stimmt für einen oder mehrere Typen; nach dem Absenden **gewinnt der Typ mit den meisten Stimmen** (bei Gleichstand entscheidet die Listenreihenfolge).
- **CTAs auf der Ergebnisseite**: Jeder Typ kann einen eigenen CTA-Button tragen (Beratung buchen, Plan ansehen …) und macht aus einem unterhaltsamen Ergebnis eine Aktion und geteilte Inhalte.
- **Fragetypen**: Abstimmungsfragen sind Einfachauswahl, Mehrfachauswahl, Dropdown und Richtig/Falsch, ergänzt durch Anzeigeelemente wie Textblöcke und Seitenumbrüche.

## Zufälliges Wissensquiz

Für Übungsdrills und zufallsbasierte Tests – Szenarien, in denen **jeder Teilnehmer andere Fragen sehen soll**.

- **Zufallsauswahl**: Zieht bei jeder Teilnahme regelbasiert Fragen aus einem verknüpften Fragenpool.
- **Pool-Filterung**: Steuern Sie den Auswahlbereich über Schwierigkeitsgrad, Tags und mehr.
- **Gespeicherte Auswahl**: Das System speichert jeweils die tatsächlich gezogenen Fragen, damit die Bewertung konsistent bleibt.

## Die richtige Wahl treffen

| Ihr Ziel | Empfohlener Typ |
| --- | --- |
| Teilnehmer bewerten und richtig/falsch beurteilen | **Wissensquiz** |
| Einen Persönlichkeits-/Kompetenztest oder eine Umfrage mit mehrdimensionaler Analyse durchführen | **Bewertetes Quiz** |
| Jedem Teilnehmer ein „Welcher Typ bist du?“-Ergebnis geben | **Ergebnisquiz** |
| Jeder Person eine andere Auswahl zufälliger Fragen zeigen | **Zufälliges Wissensquiz** |

<Callout type="warning">
  Die verfügbaren Einstellungen unterscheiden sich je nach Typ (zum Beispiel gibt es die Punktevergabe nur im Wissensquiz, bedingte Logik und mehrdimensionale Analyse richten sich hauptsächlich an das Bewertete Quiz, und die Abstimmung über Auswahl gibt es nur im Ergebnisquiz). Prüfen Sie vor der Wahl, welche Funktionen Sie benötigen.
</Callout>
