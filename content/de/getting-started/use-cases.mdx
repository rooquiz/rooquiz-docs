Jedes Rezept unten nennt den passenden Quiztyp und die wenigen Einstellungen, auf die es ankommt. Starten Sie über die Karten unter **Was möchtest du erstellen?** im Dashboard mit einer Vorlage, wann immer eine nah genug dran ist – siehe [Ein Quiz erstellen](/de/getting-started/create-quiz).

## Lead-Magnet-Assessment

*„Wie bereit ist Ihr Unternehmen für X?“ – eine Punktzahl, die sich ein Verkaufsgespräch verdient.*

1. Karte: **Assessment** (Bewertetes Quiz). Geben Sie jeder Antwortoption eine Punktzahl; die Gesamtpunktzahl ist ihre Summe. Fügen Sie [Dimensionen](/de/editor/scoring#bewertetes-quiz-dimensionsanalyse) hinzu, wenn Sie ein Netzdiagramm über mehrere Bereiche möchten.
2. Teilen Sie die Gesamtpunktzahl in [Stufen](/de/editor/scoring#stufen-und-aktionen-auf-der-ergebnisseite) auf und geben Sie den unteren und mittleren Stufen einen **CTA-Button** wie „Gespräch buchen“.
3. **Einstellungen → Zugang & Sichtbarkeit → E-Mail nötig, um den Bericht zu sehen**, damit jedes abgeschlossene Quiz zu einem [Lead](/de/leads) wird.
4. Fügen Sie der Ergebnisseite einen [Buchungsbereich](/de/bookings) hinzu und richten Sie für jede Stufe eine [E-Mail nach Ergebnis](/de/editor/settings#follow-up-der-ergebnisseite) ein.
5. Beobachten Sie den Funnel unter [Insights](/de/results/insights) – wo Personen abspringen und wie viele auf den CTA klicken.

## Produkt- oder Kurs-Finder

*„Welcher Kurs passt zu Ihnen?“ – jede Person wird einem Angebot zugeordnet.*

1. Karte: **Produkt- oder Kurs-Finder** (Ergebnisquiz). Legen Sie pro Produkt oder Kurs ein Ergebnis an.
2. Lassen Sie jede Antwortoption für die Ergebnisse stimmen, auf die sie hindeutet; das Ergebnis mit den meisten Stimmen gewinnt. Mit [bedingter Logik](/de/editor/logic) überspringen Sie Fragen, die nicht zutreffen.
3. Geben Sie jedem Ergebnis einen CTA zu seiner Produktseite – oder [leiten Sie](/de/editor/scoring#weiterleitung-nach-dem-absenden-pro) mit Pro direkt dorthin weiter, mit dem Ergebnis im Link.
4. Versehen Sie Abonnenten in [Kit](/de/connectors/channels#kit) mit Tags nach Ergebnis, sodass jedes Ergebnis seine eigene E-Mail-Sequenz startet.

<Callout type="info">
  Lassen Sie den **Gruppenvergleich** bei Findern und Einstufungsquizzen ausgeschaltet: Zu sehen, was die meisten gewählt haben, lenkt spätere Teilnehmer zur selben Option.
</Callout>

## Einstufungstest

*Ein Einstufungstest für eine Sprachschule oder einen Kurs.*

1. Karte: **Einstufungstest**. Beantworten Sie **Haben die Fragen richtige Antworten?** – **Ja** für bewertete Fragen (Wissensquiz), **Nein** für Selbsteinschätzungen (Bewertetes Quiz).
2. Legen Sie [Stufen](/de/editor/scoring#stufen-und-aktionen-auf-der-ergebnisseite) wie A1–C2 fest und geben Sie jeder einen CTA zum passenden Kurs oder zu einer Probestunde. **Reihenfolge der Stufen → High → Low** zeigt die höchste Stufe zuerst.
3. Lassen Sie [Instant feedback](/de/editor/settings#beantwortung) ausgeschaltet – es verrät die Antworten Seite für Seite.
4. Senden Sie eine Follow-up-[E-Mail nach Ergebnis](/de/editor/settings#follow-up-der-ergebnisseite), die den passenden Kurs empfiehlt.

## Teilbares Persönlichkeitsquiz

*„Welcher X bist du?“ – gemacht, um sich zu verbreiten.*

1. Karte: **Persönlichkeitsquiz** (Ergebnisquiz). Geben Sie jedem Ergebnis einen starken Namen, ein Bild und eine Beschreibung.
2. Lassen Sie **Ergebnis teilen** eingeschaltet und prüfen Sie die [Share-Karte](/de/publish/og) – sie ist das, was andere sehen, wenn das Ergebnis gepostet wird.
3. Aktivieren Sie den [Gruppenvergleich](/de/editor/settings#beantwortung), damit Teilnehmer sehen: „62 % haben dasselbe gewählt wie du“.
4. Wählen Sie ein [Design](/de/editor/design) mit einer starken Startseite; nutzen Sie den Zugang **Offen für alle**, um die Hürde niedrig zu halten.

## Wissens-Challenge

*Ein unterhaltsames Wissensquiz zum Wetteifern.*

1. Karte: **Wissens-Challenge** (Wissensquiz). Markieren Sie die richtigen Antworten und legen Sie die Punkte fest.
2. Fügen Sie ein [Zeitlimit](/de/editor/settings#beantwortung) hinzu und aktivieren Sie **Sofortiges Feedback** für ein Lernen nebenbei.
3. Geben Sie mit Stufen jeder Punktespanne einen witzigen Titel, den man gern teilt.

## KI-Diagnose

*Ein Lebenslauf-Check, eine Sprechprüfung, ein Business-Audit – ein persönlicher Bericht pro Teilnehmer.*

1. Karte: **Persönlicher KI-Bericht** (KI-Quiz). Fügen Sie die Fragen hinzu, dazu eine Datei-Upload-Frage, wenn die KI echte Arbeiten prüfen soll.
2. Schreiben Sie die [Anweisungen zur Erstellung](/de/editor/ai-report#die-anweisungen-zur-erstellung-schreiben) und wählen Sie eine Berichtslänge.
3. Fügen Sie [Ergebnis-Tags](/de/editor/ai-report#ergebnis-tags) wie *Kaufbereit* / *Weiter pflegen* / *Zu früh* hinzu, jeweils mit einem CTA, und leiten Sie sie an Ihre Connectors weiter.
4. Nutzen Sie **E-Mail nötig, um den Bericht zu sehen**: Berichte werden nur für Personen erstellt – und KI-Credits nur für sie verbraucht –, die ihre E-Mail-Adresse hinterlassen.
