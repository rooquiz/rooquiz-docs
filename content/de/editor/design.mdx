Das Erscheinungsbild hat zwei Ebenen: Das **Theme** steuert Farben und Eckenradien, eine **personalisierte Vorlage** das Seitenlayout selbst. Meist ist das Theme alles, was Sie brauchen.

## Theme

Passen Sie es im Editor unter **Theme-Auswahl** an; Änderungen erscheinen sofort in der Vorschau:

| Einstellung | Hinweise |
| --- | --- |
| **Theme-Farben** | Primär-, Sekundär-, Akzent- und Neutralfarbe sowie Info / Erfolg / Warnung / Fehler |
| **Eckenradius** | Separate Werte für Boxen, Felder und Auswahlelemente |
| **Effekte** | Tiefe, Rauschen und ähnliche Textur-Schalter |
| **Größen & Rahmen** | Gesamtdichte und Rahmenstärke |

<Callout type="info">
  Wenn Sie Markenbilder haben, nutzen Sie **Farben aus Bild übernehmen** – laden Sie ein Bild hoch, und die Palette wird in Ihre Theme-Farben übernommen. Das ist bequemer, als Hex-Codes von Hand einzugeben.
</Callout>

## Personalisierte Vorlagen

Eine personalisierte Vorlage ändert das **Layout**, nicht nur die Farbpalette. Zwei stehen zur Verfügung:

| Vorlage | Hinweise |
| --- | --- |
| **Standard** | Das Standardlayout – klar und neutral, passend für die meisten Quizze |
| **Kinetik** | Ein designorientiertes Layout mit stärkerer visueller Gestaltung auf Start- und Ergebnisseite |

<Callout type="warning">
  Der Wechsel zu Kinetik **erfordert Pro**. Die Einschränkung gilt nur für den *Wechsel* selbst: Ein Quiz, das die Vorlage bereits verwendet, wird in einem kostenlosen Team weiterhin normal dargestellt, bearbeitet und dupliziert – nichts wird herabgestuft.
</Callout>

Beim Wechsel der Vorlage erhalten Sie den Hinweis, dass **Ihre aktuellen Personalisierungseinstellungen zurückgesetzt werden** – ein anderes Layout bedeutet andere Layoutparameter, und die bisherigen Anpassungen lassen sich nicht übertragen. Duplizieren Sie das Quiz vorher, wenn Sie sie behalten möchten.

## Die Startseite

Die Startseite ist der erste Bildschirm, den Teilnehmer sehen. Im Editor steuern Sie:

- Ob **Titel** und **Beschreibung** angezeigt werden und wie sie ausgerichtet sind.
- Das **Titelbild**.
- Die Beschriftung des Start-Buttons.

<Callout type="info">
  Die Startseite wirkt sich auch auf die [Suchindexierung](/de/publish/promotion) aus: Ist sie deaktiviert, startet das Quiz direkt mit den Fragen, und Suchmaschinen finden kaum etwas zum Lesen. Wenn Sie gefunden werden möchten, lassen Sie die Startseite aktiviert und schreiben Sie eine aussagekräftige Beschreibung.
</Callout>
