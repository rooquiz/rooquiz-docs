Bedingte Logik **blendet spätere Fragen ein oder aus**, je nachdem, wie jemand antwortet, und macht so aus einem starren Fragebogen einen adaptiven.

<Callout type="info">
  Bedingte Logik ist im **Bewerteten Quiz** und im **Ergebnisquiz** verfügbar. Für ein Wissensquiz oder ein KI-Quiz gibt es im rechten Bereich des Editors keinen Tab **Regeln** – ausgeblendete Fragen würden die Höchstpunktzahl und Trefferquote eines Wissensquiz verändern.
</Callout>

## So sieht eine Regel aus

Eine Regel liest sich wie ein Satz: **Wenn … dann eine Frage anzeigen / ausblenden.**

Klicken Sie im Tab **Regeln** im rechten Bereich des Editors auf **Regel hinzufügen** und füllen Sie Folgendes aus:

| Teil | Hinweise |
| --- | --- |
| **Wenn** | Wählen Sie eine **frühere Frage**, einen Operator und einen Wert |
| **und** | Mit **Bedingung hinzufügen** können Sie weitere Bedingungen ergänzen; Bedingungen innerhalb einer Regel werden UND-verknüpft, alle müssen also zutreffen |
| **dann** | Wählen Sie **Anzeigen** oder **Ausblenden** und dann die **Zielfrage** |

Ein Quiz kann mehrere Regeln enthalten, die als **Regel 1 / Regel 2** usw. aufgeführt werden.

## Verfügbare Operatoren

| Operator | Verwendung mit |
| --- | --- |
| **ist gleich** | Einfachauswahl, Richtig/Falsch |
| **enthält eines von / enthält keines von** | Mehrfachauswahl – trifft zu, wenn eine der gewählten Optionen ausgewählt ist |
| **größer als / größer oder gleich / kleiner als / kleiner oder gleich / zwischen** | Numerische Antworten |

Richtig/Falsch-Fragen bieten **✓ Richtig** und **✗ Falsch**.

<Callout type="info">
  Eine **Bedingung** kann nur auf eine Frage mit eindeutigem Wert verweisen (Einfachauswahl, Mehrfachauswahl, Dropdown, Richtig/Falsch, Bewertung, Zahl). Ein **Ziel** ist breiter gefasst – auch Lückentext-Fragen sowie Rich-Text- und Bildkarussell-Blöcke lassen sich ein- und ausblenden. So bauen Sie etwa eine Nachfrage „Bitte erläutern“, die nur erscheint, wenn „Sonstiges“ gewählt wurde.
</Callout>

## Eine Regel einrichten

<Steps>
### Zuerst die Fragen anlegen

Regeln verweisen auf bestimmte Fragen, daher müssen sowohl die auslösende Frage als auch die Zielfrage bereits existieren.

### Die Regel hinzufügen

Wählen Sie die Frage → den Operator → den Wert → anzeigen oder ausblenden → die Zielfrage. Wenn Sie eine unvollständige Regel speichern, werden Sie aufgefordert, **die Regel vollständig auszufüllen**.

### In der Vorschau durchspielen

Probieren Sie jeden Antwortpfad aus. Sobald Sie mehr als ein paar Regeln haben, übersieht man beim reinen Durchdenken zuverlässig einen Fall.
</Steps>

## Worauf Sie achten sollten

- Verweisen Sie auf Fragen, die **vor** der Zielfrage stehen. Zeigt eine Bedingung auf eine spätere Frage, existiert deren Antwort bei der Auswertung der Bedingung noch nicht.
- Ausgeblendete Fragen werden nicht angezeigt und **auch nicht auf Pflichtangaben geprüft**, sie blockieren das Absenden also nie.
- Das Löschen einer Regel erfordert eine Bestätigung; danach wird die Zielfrage wieder standardmäßig angezeigt.

<Callout type="info">
  Das Ausblenden von Fragen wirkt sich auf das Ergebnis aus. Im **Bewerteten Quiz** hat eine nie angezeigte Frage keine Antwort und trägt keine Punkte bei – achten Sie darauf, dass Ihre [Bewertungsregeln](/de/editor/scoring) zu den möglicherweise ausgeblendeten Fragen passen. Im **Ergebnisquiz** gibt eine ausgeblendete Frage keine Stimmen ab, daher ermittelt ein Quiz mit Regeln den Gewinner über den **Stimmenanteil** statt über die reine Stimmenzahl – siehe unten.
</Callout>

## Ergebnisquiz: Stimmenanteil

Ohne Regeln gewinnt im Ergebnisquiz der Typ mit den meisten Stimmen. Sobald ein Quiz Regeln hat, sehen Teilnehmende unterschiedliche Fragen, und ein Typ mit einem langen Zweig an Folgefragen könnte allein dadurch gewinnen, dass er mehr Stimmen sammelt. Deshalb vergleicht ein Quiz mit Regeln für jeden Typ den **Anteil der Stimmen, die er bei den tatsächlich gesehenen Fragen hätte erhalten können**:

- Anteil = (erhaltene Stimmen + 0,5) ÷ (mögliche Stimmen + 1). Die kleine Glättung verhindert, dass ein Typ, für den nur eine Frage stimmt, mit 1 von 1 gewinnt.
- Ein Typ, für den keine sichtbare Frage stimmt, erhält 0.
- Bei Gleichstand entscheiden die reinen Stimmen, danach die Reihenfolge Ihrer Ergebnisliste.

Unter Ihren Ergebnistypen führt der Editor eine **Prüfung der Ergebnisabdeckung** über alle Antwortpfade durch. Sie markiert Typen, die nie das Ergebnis sein können, und listet die Pfade auf, auf denen ein Typ keine Stimmen bekommen kann. Sie warnt nur – Speichern funktioniert weiterhin –, aber ein markierter Typ bedeutet meist, dass ein Zweig eine Frage braucht, die für ihn stimmt.
