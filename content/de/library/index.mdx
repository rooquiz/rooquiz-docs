Beides sind Mechanismen zur Wiederverwendung, aber sie verwenden Unterschiedliches wieder:

| | Fragenpool | Vorlage |
| --- | --- | --- |
| Wiederverwendet | Einen Bestand an **Fragen, aus dem wiederholt gezogen wird** | Eine **komplette Quizstruktur** |
| So nutzen Sie ihn/sie | Beim Erstellen eines Quiz zufällige Fragen ziehen | In ein neues Quiz klonen und dann bearbeiten |
| Geeignet für | Denselben Stoff immer wieder abfragen | Dieselbe Bewertung für verschiedene Kunden durchführen |

<Callout type="info">
  Im Zweifel gilt: **Die Fragen sollen jedes Mal anders sein → Fragenpool; das Quiz bleibt gleich und nur das Publikum ändert sich → Vorlage.**
</Callout>

## Fragenpools

Ein Fragenpool ist der eigene Fragenbestand Ihres Teams, jede Frage mit einer richtigen Antwort. Wählen Sie beim Erstellen eines Quiz die Zufallsauswahl, und das System zieht jedes Mal eine andere Zusammenstellung – ideal für Übungsquizze und Wissensabfragen.

Siehe [Fragenpools](/de/library/question-banks).

## Vorlagen

Das Vorlagen-Center enthält komplette Quizze, die Sie klonen können. Starten Sie schnell mit einer offiziellen Vorlage oder veröffentlichen Sie ein gelungenes Quiz als Vorlage, damit Ihr Team es wiederverwenden kann.

Siehe [Vorlagen-Center](/de/library/templates).
