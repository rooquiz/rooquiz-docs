Wenn Sie einen Quiz-Link auf Plattformen wie WeChat, X/Weibo oder Slack teilen, ruft die Plattform automatisch die **Social-Share-Card** (Open-Graph-Informationen) ab, um eine Vorschau zu erzeugen. Eine angepasste Karte verbessert die Klickrate spürbar.

## Was Sie anpassen können

- **Titel**: Die Hauptüberschrift auf der Karte.
- **Beschreibung**: Ein kurzer Text unter dem Titel.
- **Vorschaubild**: Das Bild der Karte. Wenn Sie keines hochladen, wird eine **automatisch erzeugte Markenkarte** verwendet, sodass Vorschauen nie leer sind.

## So richten Sie sie ein

Öffnen Sie im gewünschten Quiz **Teilen** → **Social Card / OG**, geben Sie Titel und Beschreibung ein, laden Sie ein Vorschaubild hoch und speichern Sie.

## Tipps

- Halten Sie den Titel kurz und ansprechend, sodass er Thema und Nutzen des Quiz vermittelt.
- Fügen Sie der Beschreibung eine Handlungsaufforderung hinzu (z. B. „Finden Sie in 3 Minuten heraus, …").
- Achten Sie darauf, dass Seitenverhältnis und Schärfe des Vorschaubilds für die gängigen Plattformen geeignet sind.

<Callout type="info">
  Manche Plattformen **speichern** die abgerufene Karte **im Cache**. Ändert sich die Vorschau nach einer Aktualisierung nicht, liegt das meist am Cache – versuchen Sie es später erneut oder aktualisieren Sie sie mit dem Debugging-Tool der Plattform.
</Callout>
