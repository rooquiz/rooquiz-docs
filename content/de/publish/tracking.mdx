Wenn Sie dasselbe Quiz über mehrere Kanäle verbreiten, hilft Ihnen **UTM-Quellen-Tracking** zu erkennen, woher jede Antwort stammt, sodass Sie die Wirksamkeit jedes Kanals bewerten können.

## Was ist UTM?

UTM ist eine Reihe von Parametern, die an einen Link angehängt werden, um seine Traffic-Quelle zu kennzeichnen. Gängige Parameter sind:

- **Quelle (Source)**: z. B. `wechat`, `weibo`, `email`.
- **Medium**: z. B. `social`, `banner`, `qrcode`.
- **Kampagne (Campaign)**: der Name dieser Kampagne, z. B. `spring-launch`.

## So verwenden Sie es

Öffnen Sie im gewünschten Quiz **Teilen** → **Quellen-Tracking**, erzeugen Sie UTM-markierte Links für verschiedene Kanäle und verteilen Sie jeden Link über seinen Kanal.

## Quelldaten ansehen

Wenn Teilnehmer über einen UTM-markierten Link einsenden, wird die Quelle mit der Antwort gespeichert. Unter [Einsendungen](/de/results/records) und [Insights](/de/results/insights) können Sie nach Quelle unterscheiden und auswerten.

<Callout type="info">
  Eine **klare, einheitliche Benennung** für jeden Kanal (z. B. durchgehend Kleinbuchstaben, mit Bindestrichen getrennt) hält Ihre spätere Auswertung übersichtlich.
</Callout>
