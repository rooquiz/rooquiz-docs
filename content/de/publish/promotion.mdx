Sobald das Quiz fertig ist, ist der langwierige Teil meist nicht technisch – sondern das Schreiben der passenden Texte. Das **Promotion-Kit** unter **Teilen → Promotion-Kit** liefert Ihnen Material, das Sie direkt einfügen können.

## Was es enthält

| Abschnitt | Inhalt |
| --- | --- |
| **Social-Media-Beiträge** | Drei Blickwinkel: ein Neugier-Aufhänger, die Ergebnistypen und eine Herausforderung an Ihr Publikum |
| **Mail an Ihre Liste** | Eine **Betreffzeile** und ein **E-Mail-Text** |
| **Bio- / Profil-Link** | Eine Zeile für Ihr Social-Media-Profil |

<Callout type="info">
  Die Texte werden in der **Sprache dieses Quiz** erstellt, sodass nichts übersetzt werden muss. Die drei Beiträge unterscheiden sich absichtlich – dasselbe Quiz sollte auf verschiedenen Plattformen nicht mit demselben Satz beworben werden.
</Callout>

## Jeder Link wird nachverfolgt

Jeder Text enthält **seinen eigenen UTM-markierten Link**. Veröffentlichen Sie die drei Varianten auf drei Plattformen, und ohne zusätzlichen Aufwand zeigt Ihnen die Aufschlüsselung nach Quelle in [Insights](/de/results/insights), welcher Kanal tatsächlich Einsendungen gebracht hat.

Wie Sie feinere Quellparameter von Hand erstellen, lesen Sie unter [UTM-Quellen-Tracking](/de/publish/tracking).

## Ergebnis teilen

Unter **Teilen → Link** gibt es den Schalter **Ergebnis teilen**. Ist er aktiviert:

- Erscheinen auf der Ergebnisseite Teilen-Buttons.
- Enthalten geteilte Links eine automatisch erzeugte **personalisierte Ergebniskarte**.

<Callout type="warning">
  Wenn Sie diese Option deaktivieren, wird auch die **öffentliche Teilen-Zusammenfassung deaktiviert** – wer einen geteilten Link öffnet, sieht dann keine Ergebniszusammenfassung.
</Callout>

## Suchmaschinen-Indexierung

**Standardmäßig deaktiviert.** Aktivieren Sie sie nur für Quizze, die tatsächlich über die Suche gefunden werden sollen. Dann wird:

- Das Quiz in Ihre Sitemap aufgenommen.
- Google die Indexierung erlaubt.
- Die Liste der Fragen auf der Landingpage angezeigt, damit echter Inhalt zum Indexieren vorhanden ist.

Lassen Sie sie bei Entwürfen, Tests und Quizzen für eine bestimmte Zielgruppe deaktiviert.

<Callout type="warning">
  Zwei Situationen machen sie nahezu wirkungslos, und Sie werden auf beide hingewiesen:
  - **Das Quiz hat keine Beschreibung** – Suchmaschinen zeigen unter dem Titel nichts an, und eine Seite, die nur aus einem Titel besteht, wird selten indexiert. Fügen Sie auf der Bearbeitungsseite eine Beschreibung hinzu.
  - **Die Landingpage ist deaktiviert** – das Quiz beginnt direkt mit den Fragen, und Suchmaschinen finden kaum etwas zum Lesen. Aktivieren Sie die Landingpage im Editor wieder.
</Callout>
