Dieser Abschnitt richtet sich an **Entwickler** – so greifen Sie aus Ihrem eigenen Code oder einem KI-Client auf RooQuiz zu:

<Cards>
  <Card title="REST API" href="/de/integrations/rest-api" />
  <Card title="MCP-Integration" href="/de/integrations/mcp" />
</Cards>

- **REST API** – rufen Sie Formulare und Einsendungen mit einem API-Schlüssel auf Kontoebene ab. Ideal für eigene Dashboards oder die Synchronisierung in ein Data Warehouse. Eine OpenAPI-Spezifikation ist enthalten.
- **MCP-Integration** – verbinden Sie einen KI-Client wie ChatGPT oder Claude mit Ihrem Team, damit er Quizze direkt erstellen, abfragen und ändern, Ihre Leads bearbeiten (Status, Zuständiger, Tags, Kommentare) und Buchungen lesen kann.

<Callout type="info">
  RooQuiz hat keinen integrierten KI-Quizgenerator. Um ein Quiz mit KI zu erstellen, verbinden Sie **Ihren eigenen KI-Client** über [MCP](/de/integrations/mcp) und beauftragen Sie ihn damit – zum Beispiel, mit einer Vorlage zu beginnen und Fragen hinzuzufügen.
</Callout>

## Integration ohne Code

Wenn Sie nur „Benachrichtige mich, wenn ein Lead eingeht“ oder „Synchronisiere Leads in mein E-Mail-Tool“ brauchen, **benötigen Sie die API nicht**. Nutzen Sie einen der fünf Kanäle unter [Connectors & Automatisierung](/de/connectors): E-Mail, Webhook, Slack, Zapier, Kit.

<Callout type="info">
  Der Unterschied ist **Push versus Pull**: Connectors senden Ihnen Daten, sobald ein Ereignis eintritt; mit der REST API rufen Sie Daten nach Ihrem eigenen Zeitplan ab.
</Callout>
