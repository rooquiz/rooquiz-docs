Le moment où une personne termine un quiz et lit son résultat est celui où elle est la plus disposée à échanger avec vous. Les **Réservations 1:1** lui permettent de réserver une session avec vous directement sur la page de résultats : pas d'outil d'agenda tiers, pas d'allers-retours par e-mail pour trouver un horaire.

<Callout type="info">
  Les disponibilités sont une ressource **au niveau de l'équipe** : configurez-les une fois et tous les quiz les partagent. Vous n'avez pas à replanifier votre semaine pour chaque quiz.
</Callout>

## Trois étapes pour démarrer

<Steps>
### Définissez vos disponibilités

Sur la page **Réservations 1:1**, ouvrez **Disponibilités de réservation** et définissez votre fuseau horaire, la durée des sessions et vos horaires hebdomadaires. Voir [Disponibilités de réservation](/fr/bookings/availability).

### Activez la section réservation dans un quiz

Allez dans **Partager → Réservation** du quiz concerné et activez **Afficher la section réservation sur la page de résultats**. Voir [Côté répondant](/fr/bookings/respondent).

### Traitez les réservations sur la page dédiée

Les nouvelles réservations arrivent sur la page **Réservations 1:1**. Voir [Gérer les réservations](/fr/bookings/manage).
</Steps>

<Callout type="warning">
  Tant que les disponibilités ne sont pas configurées, la page de résultats n'affiche **aucune** section réservation, même si l'option est activée ; la page de paramètres le signale explicitement.
</Callout>

## Les trois sections de la liste

La page **Réservations 1:1** est organisée selon ce qui requiert votre attention :

- **En attente de vous** : les demandes en attente figurent en haut lorsque la confirmation est activée, car elles bloquent quelqu'un d'autre.
- **À venir** : les sessions confirmées qui n'ont pas encore eu lieu ; la toute prochaine s'affiche sur une grande carte avec un compte à rebours.
- **Passées** : l'historique, replié par défaut.

L'élément **Réservations 1:1** de la barre latérale affiche un badge indiquant le nombre de demandes en attente.

## Les statuts en un coup d'œil

| Statut | Signification |
| --- | --- |
| **En attente** | Une demande en attente de confirmation par le responsable du lead (uniquement si la confirmation est activée) |
| **Réservée** | Confirmée ; le participant dispose des détails de la réunion |
| **Terminée** | La session a eu lieu ; vous l'avez indiqué |
| **Absent** | La personne ne s'est pas présentée ; vous l'avez indiqué |
| **Annulée** | Annulée par l'une ou l'autre des parties |
| **Refusée** | Vous avez refusé la demande |
