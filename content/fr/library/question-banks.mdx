Une banque de questions est un ensemble de **questions où vous pouvez puiser à volonté**. Vous la trouverez sous **Banques de questions** dans la barre latérale gauche.

<Callout type="warning">
  Chaque question d'une banque **doit avoir une bonne réponse** : les banques sont des ensembles de questions notées, pas un lieu de stockage pour des champs de collecte de données.
</Callout>

![Liste des banques de questions RooQuiz avec le nombre de questions et la difficulté](/img/en/library/question-banks.webp)

## Créer une banque

<Steps>
### Cliquez sur « Créer une banque de questions »

Le sous-titre indique « Quiz de connaissances ou quiz noté » : les banques servent ces deux scénarios notés.

### Renseignez les informations de base

**Nom de la banque** (50 caractères maximum), **Description** (200 caractères maximum) et **Niveau de difficulté**.

### Ajoutez des questions

Ouvrez la banque et cliquez sur **Ajouter une question**. Le fonctionnement est le même que dans l'éditeur : choisissez un type, rédigez l'énoncé et les options, puis définissez la bonne réponse.
</Steps>

## Copier une banque de questions publique

RooQuiz publie aussi des **banques de questions publiques** gratuites sur [rooquiz.com/explore/question-banks](https://rooquiz.com/explore/question-banks). Elles sont consultables en aperçu uniquement : pour en utiliser une, cliquez sur **Copier dans mes banques de questions**. Vous obtenez ainsi votre propre copie modifiable dans votre équipe, que vous pouvez ensuite compléter, modifier et utiliser pour les tirages.

- Seul le **propriétaire de l'équipe ou un administrateur** peut copier une banque de questions.
- Si vous avez déjà copié cette banque, le message « Vous avez déjà une copie de cette banque de questions » s'affiche au lieu d'une seconde copie.
- Les très grandes banques sont tronquées : « Cette banque est très volumineuse : seules les N premières questions ont été copiées ».

## Gérer les questions

- **Glisser pour réordonner** — réorganisez directement les questions.
- **Suppression groupée** — cochez plusieurs questions et supprimez-les en une fois. Cette action est **irréversible**.
- **Modifier les infos** — changez le nom, la description et la difficulté de la banque.

<Callout type="warning">
  Une banque **doit être vidée avant de pouvoir être supprimée** : le message « Veuillez supprimer toutes les questions avant de supprimer cette banque de questions » s'affiche. Ce garde-fou existe pour éviter d'effacer toute une banque par accident.
</Callout>

## Utiliser une banque dans un quiz

Sur le tableau de bord, cliquez sur **Créer un Quiz de connaissances** et passez à l'onglet **Créer un Quiz de connaissances aléatoire**. Choisissez une banque de questions, puis définissez les **Règles de tirage** : pour chaque type de question, le nombre de questions à tirer et le score par question. Chaque répondant reçoit un tirage aléatoire indépendant.

La **Durée de verrouillage des questions** détermine combien de temps un répondant conserve la même série : tant qu'elle est verrouillée, actualiser la page ou revenir affiche les mêmes questions ; une fois le délai écoulé, une nouvelle série est tirée. Choisissez **Aucun verrouillage (nouveau tirage à chaque actualisation)** ou une durée allant de 30 minutes à 24 heures.

<Callout type="warning">
  Vous obtenez un **Quiz de connaissances aléatoire**, un type différent du Quiz. **Le type ne peut pas être modifié après la création** : passer de questions fixes à des questions aléatoires implique donc de tout reconstruire. Consultez [Les quatre types de quiz](/fr/getting-started/quiz-types).
</Callout>
