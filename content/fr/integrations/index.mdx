Cette section s'adresse aux **développeurs** : elle explique comment accéder à RooQuiz depuis votre propre code ou depuis un client IA :

<Cards>
  <Card title="API REST" href="/fr/integrations/rest-api" />
  <Card title="Intégration MCP" href="/fr/integrations/mcp" />
</Cards>

- **API REST** : récupérez les formulaires et les réponses avec une clé API de compte. Idéal pour vos propres tableaux de bord ou pour synchroniser les données vers un entrepôt de données. Une spécification OpenAPI est fournie.
- **Intégration MCP** : connectez un client IA comme ChatGPT ou Claude à votre équipe pour qu'il puisse créer, interroger et modifier des quiz, traiter vos leads (statut, responsable, tags, commentaires) et gérer les réservations directement.

<Callout type="info">
  RooQuiz n'intègre pas de générateur de quiz par IA. Pour créer un quiz avec l'IA, connectez **votre propre client IA** via [MCP](/fr/integrations/mcp) et demandez-le-lui, par exemple en partant d'un modèle puis en ajoutant des questions.
</Callout>

## Intégrer sans code

Si vous souhaitez simplement être « prévenu à l'arrivée d'un lead » ou « synchroniser les leads avec votre outil d'e-mailing », **vous n'avez pas besoin de l'API**. Utilisez l'un des cinq canaux de [Connecteurs et automatisation](/fr/connectors) : E-mail, Webhook, Slack, Zapier, Kit.

<Callout type="info">
  La différence tient au **push ou au pull** : les connecteurs vous envoient les données dès qu'un événement se produit ; l'API REST vous permet de récupérer les données selon votre propre calendrier.
</Callout>
