## Étapes

<Steps>
### Choisissez un point d'entrée

Trois cartes figurent en haut du tableau de bord, une par type :

- **Créer un Quiz de connaissances** : corrigé par rapport à de bonnes réponses.
- **Créer un Quiz noté** : des scores, sans bonnes réponses.
- **Créer un Quiz de résultat** : pas de score, uniquement des types de résultat.

### Modèle ou page blanche

Le panneau de création s'ouvre volontairement sur les **modèles** : modifier un modèle est bien plus rapide que de partir de rien, et sa structure de questions comme la configuration de son rapport sont déjà optimisées.

- **Partir d'un modèle** : parcourez le [Centre de modèles](/fr/library/templates), filtrez par catégorie, prévisualisez sur ordinateur et sur mobile, puis dupliquez.
- **Partir d'une page blanche** : construisez tout vous-même.

### Arrivez dans l'éditeur

La création vous amène directement dans l'[éditeur](/fr/editor) pour commencer à ajouter des questions.
</Steps>

<Callout type="warning">
  **Le type de quiz ne peut plus être modifié une fois choisi.** Ce réglage n'est pas caché quelque part dans l'interface : le champ est en lecture seule après la création, au niveau des données. Une erreur oblige à tout reconstruire ; décidez donc dès le départ si vous voulez un score, un profil par dimension ou un résultat par type.
</Callout>

La comparaison complète et les conseils de choix se trouvent dans [Les quatre types de quiz](/fr/getting-started/quiz-types).

## Modèles

Un modèle est la structure complète d'un quiz : questions, notation et configuration du rapport. Dupliquez-le et modifiez-le librement ; **vos modifications n'affectent jamais le modèle**.

Voir [Modèles](/fr/library).
