## Étapes

<Steps>
### Choisissez ce que vous voulez créer

Le tableau de bord s'ouvre sur **Que souhaitez-vous créer ?** Choisissez selon votre objectif, et RooQuiz ouvre le panneau de création du [type de quiz](/fr/getting-started/quiz-types) correspondant :

| Carte | À quoi elle sert | Type de quiz |
| --- | --- | --- |
| **Quiz de personnalité** | « Lequel êtes-vous ? », conçu pour être partagé | Quiz de résultat |
| **Sélecteur de produit ou de cours** | Associer chaque personne à ce qui lui convient | Quiz de résultat |
| **Évaluation** | Score de préparation, de bilan ou de maturité | Quiz noté |
| **Test de niveau** | Tests de placement et de compétences | Quiz de connaissances ou Quiz noté |
| **Défi de culture générale** | Un quiz de connaissances ludique pour se mesurer aux autres | Quiz de connaissances |
| **Rapport personnel IA** | L'IA rédige un rapport pour chaque personne | Quiz IA |

**Test de niveau** pose une question supplémentaire : **Les questions ont-elles de bonnes réponses ?** Des questions de grammaire, de vocabulaire ou de maths notées justes ou fausses donnent un Quiz de connaissances ; des auto-évaluations comme « Je peux tenir une conversation en anglais », où chaque choix rapporte des points, donnent un Quiz noté.

### Modèle ou page blanche

Le panneau de création s'ouvre volontairement sur les **modèles** : modifier un modèle est bien plus rapide que de partir de rien, et sa structure de questions comme la configuration de son rapport sont déjà optimisées.

- **Partir d'un modèle** : parcourez les modèles par catégorie, triez par **Les plus utilisés** ou **Les plus récents**, prévisualisez le quiz (et, pour les Quiz IA, un **Exemple de rapport**), puis cliquez sur **Utiliser ce modèle**. Consultez le [Centre de modèles](/fr/library/templates).
- **Partir d'une page blanche** : construisez tout vous-même.

### Arrivez dans l'éditeur

La création vous amène directement dans l'[éditeur](/fr/editor) pour commencer à ajouter des questions.
</Steps>

<Callout type="warning">
  **Le type de quiz ne peut plus être modifié une fois choisi.** Ce réglage n'est pas caché quelque part dans l'interface : le champ est en lecture seule après la création, au niveau des données. Une erreur oblige à tout reconstruire ; décidez donc dès le départ si vous voulez un score, un profil par dimension ou un résultat par type.
</Callout>

La comparaison complète et les conseils de choix se trouvent dans [Les quatre types de quiz](/fr/getting-started/quiz-types).

## Modèles

Un modèle est la structure complète d'un quiz : questions, notation et configuration du rapport. Dupliquez-le et modifiez-le librement ; **vos modifications n'affectent jamais le modèle**.

Voir [Modèles](/fr/library).
