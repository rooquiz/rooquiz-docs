## Ce qui les distingue

| Module | Objet | Idéal pour |
| --- | --- | --- |
| **Réponses** | Détail de chaque réponse | Relire, filtrer et assurer le suivi |
| **Statistiques** | Statistiques agrégées et graphiques | Taux de complétion, points d'abandon, conversion par source |
| **Rapports** | Analyse d'une réponse individuelle | Scores, profils par dimension, évaluation IA |
| **Exporter les données** | Sortir les données | Poursuivre le travail dans Excel ou vos propres outils |

<Callout type="info">
  Les réponses pour les données brutes, les statistiques pour les tendances globales, les rapports pour les conclusions individuelles.
</Callout>

## La différence avec les leads

Cette section porte sur les **réponses**, c'est-à-dire les soumissions individuelles. Pour travailler plutôt par **personne** (combien de fois quelqu'un a soumis, où il en est, quand vous le rencontrez prochainement), rendez-vous dans [Pistes](/fr/leads).

Les deux se rejoignent sur la page de détail d'une réponse : ouvrez une réponse et la partie droite affiche le panneau de suivi du lead correspondant à cette personne.
