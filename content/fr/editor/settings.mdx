Tout ce qui, dans le quiz, n'est pas une question se trouve dans l'onglet **Paramètres** du quiz (à côté de **Modifier**, **Réponses** et **Statistiques**). Il est divisé en sept pages, listées dans le menu de gauche.

## Accès et visibilité

### Ouverture/Fermeture du quiz

Un interrupteur général entre **Ouvert — collecte en cours** et **Fermé — collecte arrêtée**. Tant que le quiz est fermé, **le lien du quiz et tous les liens de rapport déjà envoyés s'affichent comme indisponibles**. Les données recueillies ne sont pas touchées : réactivez-le et les deux fonctionnent de nouveau.

### Accès aux réponses

Répond à la question « **Qui peut répondre, et qui peut voir le rapport ?** » : trois options, et ce choix détermine si vous obtiendrez ou non des [leads](/fr/leads) :

| Option | Signification | Idéal pour |
| --- | --- | --- |
| **Ouvert à tous** | Tout le monde peut répondre sans se connecter et voit le rapport juste après l'envoi | Portée maximale, friction minimale |
| **E-mail requis pour voir le rapport** | Tout le monde peut répondre, mais doit laisser un e-mail (ou se connecter) pour voir le rapport | **La principale option de capture de leads** |
| **Se connecter pour répondre** | Seuls les répondants connectés peuvent répondre | Publics sur invitation |

Avec **E-mail requis pour voir le rapport**, vous choisissez aussi s'il faut **Vérifier l'e-mail avant d'afficher le rapport**. Cette option est **désactivée par défaut** :

- **Désactivée** : les répondants saisissent un e-mail et un nom et accèdent directement au rapport, ce qui améliore généralement le taux de complétion. L'adresse n'est pas vérifiée : certaines contiendront des fautes de frappe ou seront fausses.
- **Activée** : les répondants saisissent un code à 6 chiffres reçu dans leur boîte de réception. L'adresse de chaque lead est vérifiée, et ils obtiennent un compte dans votre équipe avec lequel ils peuvent se reconnecter pour revoir leurs rapports précédents.

<Callout type="info">
  Seules les deux dernières options produisent des leads de façon fiable : une réponse anonyme ne laisse aucune coordonnée. Pour diffuser largement *tout en* recueillant des leads, choisissez **E-mail requis pour voir le rapport**.
</Callout>

### Partage des résultats

Affiche des boutons de partage sur la page de résultats et joint une carte générée automatiquement aux liens partagés. Lorsqu'il est désactivé, aucune carte n'est générée.

### Indexation par les moteurs de recherche

Activée par défaut : le quiz est ajouté à votre sitemap et peut être trouvé via les moteurs de recherche et cité par les assistants IA. Désactivez-la pour les brouillons, les tests et les quiz destinés uniquement à un public précis. Consultez [l'indexation par les moteurs de recherche](/fr/publish/promotion#indexation-par-les-moteurs-de-recherche).

## Informations de base

**Titre du quiz**, **Image de couverture** (1200 × 630 px recommandé) et **Couleur de couverture**. Le titre identifie le quiz dans le tableau de bord et s'affiche sur la page d'accueil.

La **description** du quiz se modifie sur la page d'accueil, dans l'éditeur, et non ici. Elle alimente l'[indexation par les moteurs de recherche](/fr/publish/promotion#indexation-par-les-moteurs-de-recherche) : ne la laissez donc pas vide.

## Expérience de réponse

- **Mode d'affichage de la numérotation** — Aucune / Chiffres arabes (1, 2, 3) / Chiffres romains (I, II, III).
- **Limite de temps** — un compte à rebours démarre lorsque le répondant entre dans le quiz ; à son terme, une fenêtre s'affiche et ses **réponses en cours sont envoyées automatiquement**. Disponible **uniquement dans le Quiz de connaissances et le Quiz de connaissances aléatoire** : le Quiz noté et le Quiz de résultat ne la proposent pas.
- **Feuille de réponses** — affiche un navigateur de questions dans la barre latérale pour que les répondants voient leur progression et accèdent à n'importe quelle question. Utile à activer sur les quiz longs.
- **Comparaison avec les autres** — activez **Afficher les pourcentages par option** et les répondants voient, juste après avoir répondu, la part des personnes ayant choisi la même option (par ex. « 62 % des personnes ont choisi comme vous »). Seuls des pourcentages s'affichent, jamais les réponses individuelles.
  - Désactivée par défaut et disponible uniquement dans le Quiz noté et le Quiz de résultat ; pas dans les quiz de connaissances, où l'option la plus choisie trahirait la réponse.
  - Rien ne s'affiche tant que le quiz n'a pas reçu au moins **10 réponses** ; les pourcentages apparaissent ensuite automatiquement.
  - Voir ce que la majorité a choisi pousse les répondants suivants vers la même option : laissez-la donc désactivée pour les quiz qui orientent vers un cours ou évaluent le niveau des apprenants.

## Suivi de la page de résultats

Deux blocs facultatifs pour la page de résultats. Leur ordre sur la page se règle dans l'éditeur : consultez [Ordre des sections de la page de résultats](/fr/editor/scoring#ordre-des-sections-de-la-page-de-résultats).

- **Section réservation** — permet aux répondants de réserver une session 1:1 depuis leur résultat. Activez-la et définissez, si vous le souhaitez, le titre, la description et le texte du bouton. Elle nécessite d'avoir d'abord configuré vos disponibilités de réservation : consultez [Réservations 1:1](/fr/bookings).
- **Retour du répondant** — activez **Afficher le bloc de retour** pour poser **une seule question** sur la page de résultats. Choisissez le type de réponse : **Note de 1 à 5**, **Choix unique** ou **Texte libre**. Les réponses arrivent sur le lead du répondant : la personne chargée du suivi sait ainsi ce que cette personne veut vraiment.

## Langue

Définissez la **Langue principale** et gérez les **Versions linguistiques** de ce quiz. Tous les détails dans [Versions multilingues](/fr/editor/translations).

<Callout type="warning">
  Changer la langue principale ne fait que réétiqueter le contenu source : cela **ne traduit rien**. Ajoutez une traduction pour proposer une autre langue.
</Callout>

## Textes système

Remplacez les libellés intégrés des boutons et des messages de la page de réponse : boutons de navigation, états d'envoi, messages de la limite de temps, etc.

## Analytique

**Google Analytics** — saisissez un ID de mesure (par ex. `G-XXXXXXXXXX`) et les pages vues du quiz public sont remontées dans GA.

<Callout type="warning">
  Google Analytics est une **fonctionnalité du plan Pro**.
</Callout>

## Paramètres situés ailleurs

Le lien de partage, le QR code, la carte de partage, le code d'intégration et le plan de diffusion se trouvent dans le bouton **Partager** en haut du quiz : consultez [Publier et partager](/fr/publish). Le thème et les modèles personnalisés se trouvent dans l'éditeur : consultez [Apparence et modèles personnalisés](/fr/editor/design).
