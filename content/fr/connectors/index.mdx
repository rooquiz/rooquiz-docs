Les **connecteurs** transmettent les leads et les réservations générés par vos quiz vers les outils que vous utilisez déjà : e-mail, votre propre backend, Slack ou votre fournisseur de services d'e-mailing. Vous les trouverez sous **Connecteurs** dans la barre latérale gauche.

<Callout type="info">
  Les connecteurs sont définis **au niveau de l'équipe** : configurez-en un et tous les quiz l'utilisent. Pour que seuls certains quiz déclenchent un connecteur, restreignez-le avec la [portée du déclenchement](/fr/connectors/events).
</Callout>

![La page des connecteurs RooQuiz : cartes de connecteurs regroupées en notifier des personnes, envoyer vers des systèmes et synchroniser des audiences](/img/en/connectors/connectors-list.webp)

La page regroupe tout selon la fonction :

| Groupe | Contenu |
| --- | --- |
| **Comptes d'envoi** | **Gmail** : connectez un compte Gmail comme service d'envoi avec **Connecter Gmail**. Voir [Service d'envoi d'e-mails](/fr/connectors/email-smtp) |
| **Notifier l'équipe** | E-mail, Slack |
| **Envoyer aux systèmes** | Webhook, Zapier |
| **Synchroniser les audiences** | Kit |

## Les cinq canaux

| Canal | Usage |
| --- | --- |
| **E-mail** | Envoyer une notification personnalisable aux destinataires choisis lorsqu'un événement se produit, jusqu'à 3 par équipe |
| **Webhook** | Envoyer un POST vers votre propre URL avec une signature HMAC |
| **Slack** | Autoriser l'application Slack et publier les nouveaux leads dans un canal |
| **Zapier** | Coller une URL Catch Hook et atteindre des milliers d'applications |
| **Kit** | Ajouter les nouveaux leads comme abonnés dans Kit (ConvertKit) et les étiqueter |

Chaque connecteur se déclenche sur les événements que vous choisissez (nouvelle réponse, nouveau lead, réservation créée, annulée ou reprogrammée) : consultez [Événements déclencheurs et portée](/fr/connectors/events). Chaque connecteur fonctionne indépendamment : **désactiver l'un n'affecte pas les autres**. La configuration de chaque canal est décrite dans [Les cinq canaux](/fr/connectors/channels).

## Autorisations et forfait

<Callout type="warning">
  Seuls le **propriétaire de l'équipe ou un administrateur** peuvent gérer les connecteurs. Les autres membres reçoivent un message d'absence d'autorisation, et l'élément de la barre latérale ne leur est pas affiché.
</Callout>

**E-mail** et **Slack** sont disponibles sur tous les forfaits ; **Webhook**, **Zapier** et **Kit** sont **réservés au forfait Pro**. Dans une équipe gratuite, sélectionner un canal Pro grise la zone de configuration et propose un lien de mise à niveau.

## Ce qu'indique la carte du connecteur

Chaque connecteur configuré affiche :

- **Activé / Désactivé** : s'il fonctionne.
- **Configuration incomplète** : le flux OAuth est terminé, mais il manque encore un canal ou une dernière étape. Ces connecteurs n'envoient rien.
- **Dernier envoi** : la date du dernier déclenchement et son résultat (réussi / échoué).

<Callout type="info">
  Après en avoir configuré un, cliquez sur **Envoyer un test** pour confirmer que l'autre extrémité le reçoit bien, plutôt que de le découvrir avec votre premier vrai lead.
</Callout>
