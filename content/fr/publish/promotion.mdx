Une fois le quiz créé, l'étape la plus longue n'est généralement pas technique : c'est la rédaction des textes qui l'accompagnent. Le **Kit de promotion**, sous **Partager → Kit de promotion**, vous fournit des contenus prêts à coller.

## Ce qu'il contient

| Section | Contenu |
| --- | --- |
| **Publications sociales** | Trois angles : une accroche qui pique la curiosité, les types de résultat, et un défi lancé à votre audience |
| **E-mail à votre liste** | Un **objet** et un **corps d'e-mail** |
| **Lien dans la bio** | Une ligne pour votre profil sur les réseaux sociaux |

<Callout type="info">
  Les textes sont générés dans **la langue de ce quiz** : il n'y a rien à traduire. Les trois publications sont volontairement différentes : un même quiz publié sur différentes plateformes ne devrait pas reprendre la même phrase.
</Callout>

## Chaque lien est suivi

Chaque texte comporte **son propre lien balisé UTM**. Publiez les trois variantes sur trois plateformes et, sans effort supplémentaire, la répartition par source dans les [Statistiques](/fr/results/insights) vous indique quel canal a réellement généré des réponses.

Pour créer à la main des paramètres de source plus fins, consultez [Suivi des sources UTM](/fr/publish/tracking).

## Partage des résultats

**Partager → Lien** comporte un interrupteur **Partage des résultats**. Lorsqu'il est activé :

- Des boutons de partage apparaissent sur la page de résultat.
- Les liens partagés affichent une **carte de résultat personnalisée** générée automatiquement.

<Callout type="warning">
  Désactiver cette option **désactive aussi le résumé de partage public** : les personnes qui ouvrent un lien partagé ne verront aucun résumé du résultat.
</Callout>

## Indexation par les moteurs de recherche

**Activée par défaut.** Les nouveaux quiz peuvent être trouvés via les moteurs de recherche et cités par les assistants IA. Tant qu'elle est activée, elle permet de :

- Ajouter le quiz à votre sitemap.
- Laisser Google l'indexer.
- Lister les questions sur la page d'accueil afin qu'il y ait un vrai contenu à indexer.

Désactivez-la pour les brouillons, les tests et les quiz destinés uniquement à un public spécifique.

<Callout type="warning">
  Deux situations la rendent presque inutile, et vous serez averti dans les deux cas :
  - **Le quiz n'a pas de description** — les moteurs de recherche n'affichent rien sous le titre, et une page réduite à un titre est rarement indexée. Ajoutez-en une sur la page d'édition.
  - **La page d'accueil est désactivée** — le quiz s'ouvre directement sur les questions, ce qui ne laisse presque rien à lire aux moteurs de recherche. Réactivez la page d'accueil dans l'éditeur.
</Callout>
