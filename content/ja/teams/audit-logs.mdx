**監査ログ** は、チーム内の重要な操作を記録したものです。誰が、何を、どの対象に対して、いつ行い、成功したかどうかがわかります。**設定 → 監査ログ** にあります。

<Callout type="warning">
  **監査ログを閲覧できるのは、チームのオーナーと管理者だけです。** メンバーと閲覧者には、代わりに通知が表示されます。
</Callout>

## 列

| 列 | 説明 |
| --- | --- |
| **操作** | 何が起きたか。「メンバーを招待」「クイズを削除」「データのエクスポート」など |
| **ステータス** | 成功または失敗 |
| **実行者** | 誰が行ったか。プラットフォーム自体が開始した操作(保存期間によるクリーンアップ、モデレーションによる停止など)は **システム** と表示されます |
| **対象** | 操作の対象となったオブジェクト。ID のプレフィックス付きで表示されます |
| **日時** | 操作が行われた日時 |

任意の行をクリックすると **詳細** が展開されます。操作によって含まれる項目は異なります。たとえばエクスポートの場合は、データの種類(回答 / リード / 回答者)と件数も記録されます。

## 記録の対象

おおまかには次のとおりです。

- **チーム** — チームの削除、所有権の譲渡、プランの変更。
- **メンバー** — 招待、削除、退会、ロールの変更、無効化 / 有効化。
- **クイズ** — 作成、更新、ゴミ箱への移動、復元、完全な削除、停止 / 停止の解除。
- **リードと回答者** — ゴミ箱への移動、復元、完全な削除。
- **コネクター** — 作成、更新、削除。
- **認証情報** — API キーと MCP トークンの作成、無効化、復元、削除。
- **使用量** — AI の消費、メールの消費、[データのエクスポート](/ja/results/export)。

上部で **操作** と **ステータス** で絞り込めば、「先週データをエクスポートしたのは誰か」といった疑問に答えられます。

<Callout type="info">
  ログは **読み取り専用** で、編集も削除もできません。改変できる監査ログには、ほとんど価値がないからです。
</Callout>
