## メンバーを招待する

**設定 → メンバー一覧** でメールアドレスを入力し、ロールを選んで招待を送ります。受信者は招待メールのリンク(有効期間は 7 日間)から参加します。登録済みのユーザーはそのまま参加でき、それ以外の人は先にサインアップするよう案内されます。

チームのメンバーは **Free で最大 3 人**、**Pro で最大 10 人** までで、保留中の招待も数に含まれます。10 人を超える場合は、[support@rooquiz.com](mailto:support@rooquiz.com) までエンタープライズ版についてお問い合わせください。

## 3 つのロール

チームには、権限の強い順に 3 つのロールがあります。

| ロール | ひとことで |
| --- | --- |
| **オーナー** | チームの最終的な所有者で、すべての権限を持ちます。各チームのオーナーは **必ず 1 人だけ** です。 |
| **管理者** | チームの日々の運営を担います。メンバーができることすべてに加えて、メンバーとチーム設定を扱えます。 |
| **メンバー** | チームのすべてのクイズを作成・編集し、チームのリードに対応します。 |

チームの全員が、チーム内の **すべてのクイズとすべての回答** を見られます。クイズ単位の共有はありません。ロールが決めるのは、誰が削除できるか、誰がメンバーを管理できるか、誰がチームレベルの設定を変更できるかだけです。

オーナーと管理者の線引きは意図的なものです。**管理者はチームを運営し、オーナーはチームを所有します。** チームが誰のものか、あるいは有料のお客様としての当社との関係を変える操作は、すべてオーナーに委ねられています。

### クイズ

| | オーナー | 管理者 | メンバー |
| --- | :---: | :---: | :---: |
| クイズを作成する | ✅ | ✅ | ✅ |
| チームのすべてのクイズを見る | ✅ | ✅ | ✅ |
| クイズの内容、設定、翻訳を編集する / 複製する | ✅ | ✅ | ✅ |
| クイズを別のメンバーに譲渡する | ✅ | ✅ | **自分のもののみ** |
| ゴミ箱への移動、復元、削除 | ✅ | ✅ | **自分のもののみ** |
| 回答を見る | ✅ | ✅ | ✅ |
| 回答を削除する | ✅ | ✅ | ✅ |

「自分のもの」とは、自分がクイズのオーナーになっているクイズのことです。既定では作成した人がオーナーで、譲渡されるまで変わりません。

## 誰が誰を管理できるか

- **オーナー** と **管理者** はどちらも、ほかの全員を管理できます。管理者同士も含みます。管理者は、別の人を管理者に任命したり、降格させたり、無効化したり、削除したりできます。
- **オーナー** 自身の行には誰も手を加えられません。オーナーを変えるには[所有権の譲渡](#所有権の譲渡)を行うしかなく、ロールの編集では変更できません。
- **自分のロールは誰も変更できません**。自分から降格することもできません。ほかのオーナーまたは管理者に依頼してください。チームからの退会は、いつでも自分で行えます。
- **メンバー** は、誰も管理できません。

<Callout type="warning">
  管理者は互いを降格できるため、管理者はチームを任せられる人にだけ付与するロールと考えてください。
</Callout>

## 所有権の譲渡

チームの所有権を譲渡できるのはオーナーだけで、**設定 → メンバー一覧** から行います。新しいオーナーは、すでにチームの有効なメンバーである必要があります。譲渡後、あなたは通常のメンバーになります。チームのオーナーは常に 1 人だけです。

オーナーはチームから直接退会できません。先に所有権を譲渡してください。
