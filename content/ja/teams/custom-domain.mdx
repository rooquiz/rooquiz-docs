デフォルトでは、クイズの公開リンクはプラットフォームのドメインにあります。**カスタムドメイン** を使うと、回答者には代わりに自社のドメインが表示されます。ブランドの一貫性と信頼性が高まります。

**設定 → カスタムドメイン** にあります。

<Callout type="warning">
  カスタムドメインは **Pro プランの機能** です。
</Callout>

## 設定方法

<Steps>
### ドメインを入力する

使用したいドメインを入力します。例:`quiz.yourbrand.com`。ルートドメインよりもサブドメインをおすすめします。

### DNS レコードを追加する

ページ上の **DNS設定ガイド** に、**タイプ / 名前 / 値** の 3 列からなるレコードが 1 件表示されます。DNS プロバイダーでそのとおりに追加してください。

### 認証を待つ

ページに戻り、**ステータスを更新** をクリックします。ステータスは **認証中** から **認証済み** に変わるか、**認証に失敗しました** と表示されます。
</Steps>

<Callout type="info">
  DNS レコードの反映には、プロバイダーによって **数分から最大 48 時間** かかります。設定直後に認証されないのは正常なので、しばらくしてから再度更新してください。
</Callout>

## ステータスの値

| ステータス | 意味 |
| --- | --- |
| **認証中** | レコードは送信済みで、DNS の反映とチェックを待っています |
| **認証済み** | ドメインが有効になり、公開リンクで使われています |
| **認証に失敗しました** | 正しいレコードが見つかりません。ガイドと照らし合わせてタイプ / 名前 / 値を確認し直してください |
| **停止中** | Pro プランの期限が切れています |

<Callout type="warning">
  Pro の期限が切れるとドメインは **停止中** になります。**7 日間の猶予期間** があり、それを過ぎるとカスタムドメインは解決されなくなります。更新すれば元に戻り、DNS を設定し直す必要はありません。
</Callout>
