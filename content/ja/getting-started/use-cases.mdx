以下の各レシピでは、選ぶべきクイズタイプと、それを機能させるいくつかの設定を紹介します。目的に近いものがあれば、ダッシュボードの **何を作りますか？** のカードからテンプレートで始めましょう。詳しくは[クイズの作成](/ja/getting-started/create-quiz)をご覧ください。

## リードマグネット型のアセスメント

*「あなたのビジネスは X への準備ができていますか?」— 商談につながるスコア。*

1. カード:**アセスメント**(スコアクイズ)。各選択肢にスコアを付けると、合計はその和になります。複数の領域をレーダーチャートで見せたい場合は[次元](/ja/editor/scoring#スコアクイズ次元別の分析)を追加します。
2. 合計点を[レベル](/ja/editor/scoring#レベルと結果ページのアクション)に分け、低いレベルと中間のレベルに「相談を予約する」などの **CTA ボタン** を設定します。
3. **設定 → 公開と権限 → レポート閲覧にメールが必要** にすると、回答を終えた人がすべて[リード](/ja/leads)になります。
4. 結果ページに[予約セクション](/ja/bookings)を追加し、レベルごとに[結果に応じたメール](/ja/editor/settings#結果ページのフォローアップ)を設定します。
5. [インサイト](/ja/results/insights)でファネルを確認します。どこで離脱しているか、何人が CTA をクリックしたかがわかります。

## 商品・コースファインダー

*「あなたに合うコースはどれ?」— 一人ひとりを 1 つのオファーにマッチング。*

1. カード:**商品・コースファインダー**(結果タイプクイズ)。商品やコースごとに結果タイプを 1 つずつ作成します。
2. 各選択肢から、それが示す結果タイプに票を入れます。最も票を集めた結果タイプが選ばれます。当てはまらない設問は[条件ロジック](/ja/editor/logic)で飛ばしましょう。
3. 各結果タイプに、その商品ページへの CTA を設定します。Pro なら、結果をリンクに付けてそのページへ直接[リダイレクト](/ja/editor/scoring#送信後のリダイレクトpro)することもできます。
4. [Kit](/ja/connectors/channels#kit) で購読者に結果ごとのタグを付ければ、結果タイプごとに別々のメールシーケンスを始められます。

<Callout type="info">
  ファインダーやクラス分けのクイズでは **みんなとの比較** をオフのままにしてください。多くの人が選んだ選択肢が見えると、後から回答する人が同じ選択肢に流されやすくなります。
</Callout>

## レベルテスト

*語学学校や研修コースのクラス分けテスト。*

1. カード:**レベルテスト**。**問題には正解がありますか？** に答えます。採点する設問なら **はい**(知識クイズ)、自己評価なら **いいえ**(スコアクイズ)です。
2. A1–C2 などの[レベル](/ja/editor/scoring#レベルと結果ページのアクション)を設定し、それぞれに対応するクラスや体験レッスンへの CTA を付けます。**レベルの並び順 → 高 → 低** にすると、最上位のレベルが先頭に表示されます。
3. [即時フィードバック](/ja/editor/settings#回答体験)はオフのままにします。オンにすると、ページごとに正解がわかってしまいます。
4. 適切なクラスを勧める[結果に応じたメール](/ja/editor/settings#結果ページのフォローアップ)をフォローアップとして送ります。

## シェアされやすい性格診断クイズ

*「あなたはどの X タイプ?」— 広がるように作る。*

1. カード:**性格診断クイズ**(結果タイプクイズ)。各結果タイプに、印象的な名前、画像、説明を付けます。
2. **結果の共有** はオンのままにし、[シェアカード](/ja/publish/og)を確認します。結果が投稿されたときに表示されるのがこのカードです。
3. [みんなとの比較](/ja/editor/settings#回答体験)をオンにすると、回答者に「62% の人があなたと同じ選択をしました」と表示されます。
4. 開始ページが目を引く[デザイン](/ja/editor/design)を選び、アクセスは **全員に公開** にしてハードルを下げましょう。

## トリビアチャレンジ

*みんなで競える楽しい知識クイズ。*

1. カード:**トリビアチャレンジ**(知識クイズ)。正解を設定し、配点を決めます。
2. [制限時間](/ja/editor/settings#回答体験)を追加し、**即時フィードバック** をオンにすると、答えながら学べる体験になります。
3. レベルを使って、スコア帯ごとにシェアしたくなるような楽しい称号を付けましょう。

## AI が書く個別診断

*履歴書の添削、スピーキングの評価、ビジネス診断など — 回答者ごとの個別レポート。*

1. カード:**AI個別レポート**(AIクイズ)。設問を追加し、AI に実際の成果物を見てもらいたい場合はファイルアップロードの設問も加えます。
2. [生成指示](/ja/editor/ai-report#生成指示を書く)を書き、レポートの長さを選びます。
3. *購入意欲あり* / *育成中* / *時期尚早* などの[結果タグ](/ja/editor/ai-report#結果タグ)を追加し、それぞれに CTA を設定して、コネクターに振り分けます。
4. **レポート閲覧にメールが必要** を使いましょう。レポートが生成され、AIポイントが消費されるのは、メールアドレスを残した人の分だけです。
