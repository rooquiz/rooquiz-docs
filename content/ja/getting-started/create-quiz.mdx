## 手順

<Steps>
### 作るものを選ぶ

ダッシュボードには **何を作りますか？** が表示されます。目的で選ぶと、RooQuiz が対応する[クイズタイプ](/ja/getting-started/quiz-types)の作成ドロワーを開きます。

| カード | 用途 | クイズタイプ |
| --- | --- | --- |
| **性格診断クイズ** | 「あなたはどのタイプ？」— シェアされやすい診断 | 結果タイプクイズ |
| **商品・コースファインダー** | 一人ひとりに合うものをマッチング | 結果タイプクイズ |
| **アセスメント** | 準備度、ヘルスチェック、成熟度スコア | スコアクイズ |
| **レベルテスト** | クラス分けやスキルチェック | 知識クイズまたはスコアクイズ |
| **トリビアチャレンジ** | みんなで競える楽しい知識クイズ | 知識クイズ |
| **AI個別レポート** | AI が一人ひとりに専用レポートを作成 | AIクイズ |

**レベルテスト** では、もう 1 つ **問題には正解がありますか？** と尋ねられます。文法、語彙、数学など、正誤を判定する設問なら知識クイズになります。「英語で会話できる」のような自己評価で、各選択肢にポイントがある場合はスコアクイズになります。

### テンプレートか空白か

作成ドロワーは、意図的に **テンプレート** が表示された状態で開きます。テンプレートを編集するほうが一から書くよりもずっと速く、設問の構成やレポートの設定もすでに調整済みだからです。

- **テンプレートから始める** — カテゴリごとにテンプレートを閲覧し、**よく使われる順** または **新しい順** で並べ替え、クイズ(AIクイズでは **サンプルレポート** も)をプレビューしてから **このテンプレートを使う** をクリックします。[テンプレートセンター](/ja/library/templates)をご覧ください。
- **空白から始める** — すべてを自分で組み立てます。

### エディターに移動する

作成すると、そのまま[エディター](/ja/editor)が開き、設問の追加を始められます。
</Steps>

<Callout type="warning">
  **クイズタイプは一度選ぶと変更できません。** UI のどこかに隠れているわけではなく、データ層で作成後は読み取り専用になっています。間違えた場合は作り直しになるため、点数・次元別のプロフィール・タイプ判定のどれが欲しいのかを事前に決めておきましょう。
</Callout>

詳しい比較と選び方のアドバイスは[4 つのクイズタイプ](/ja/getting-started/quiz-types)をご覧ください。

## テンプレート

テンプレートは、設問・採点・レポート設定を含むクイズ全体の構成です。複製して自由に編集できます。**加えた変更がテンプレートに影響することはありません**。

詳しくは[テンプレート](/ja/library)をご覧ください。
