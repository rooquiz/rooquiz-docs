サインインすると **ダッシュボード** が開きます。自分とチームのクイズがすべてここに集まり、日々の管理の起点となります。

![RooQuiz のダッシュボード:サイドバーのナビゲーションとクイズ一覧](/img/en/getting-started/dashboard.webp)

## メインエリア

- **作成カード** — 上部の 3 枚のカードは、[知識クイズを作成 / スコアクイズを作成 / 結果タイプクイズを作成](/ja/getting-started/create-quiz)に対応しています。
- **グループタブ** — **すべて**、**お気に入り**、そして作成したグループが並びます。詳しくは[ワークスペース](/ja/getting-started/workspace)をご覧ください。
- **クイズカード** — タイプのバッジ、カバー、タイトル、作成日、回答数が表示され、下部に編集・回答記録・その他の操作が並びます。

## 左サイドバー

| 項目 | 用途 |
| --- | --- |
| **マイクイズ** | このページ |
| **[問題バンク](/ja/library/question-banks)** | 再利用できる設問のプール |
| **[回答者](/ja/respondents)** | クイズに回答した人のプロフィール |
| **[リード](/ja/leads)** | 連絡先を残した人をフォローアップするためのパイプライン |
| **[1:1予約](/ja/bookings)** | 結果ページから予約されたセッション。未対応の件数がバッジで表示されます |
| **[コネクター](/ja/connectors)** | チーム単位の配信チャネル。**オーナーと管理者のみに表示されます** |

上部の検索ボックスでは、クイズ・問題バンク・回答者・リードを横断して検索できます。下部からは **サイドバーを折りたたむ** ことができます。

## クイズ内のタブ

クイズを開くと、4 つのタブがあります。

| タブ | 用途 |
| --- | --- |
| **[編集](/ja/editor)** | 設問、ロジック、採点、デザインを作成します |
| **[共有](/ja/publish)** | 公開リンク、QR コード、埋め込み、ソーシャルカード、流入元トラッキング、予約セクション、プロモーションキット |
| **[回答記録](/ja/results/records)** | すべての送信内容 |
| **[インサイト](/ja/results/insights)** | 完了率、離脱ポイント、流入元ごとのコンバージョン |

<Callout type="info">
  以前はクイズごとに「連携」タブがありました。これはチーム単位の[コネクター](/ja/connectors)に移行しています。クイズごとに設定を繰り返す必要はなく、一度設定すればすべてのクイズで使われます。
</Callout>

<Callout type="info">
  ダッシュボードには **現在のチーム** のクイズが表示されます。複数のチームに所属している場合は、左上のチーム切り替えで切り替えると、一覧もそれに合わせて変わります。
</Callout>
