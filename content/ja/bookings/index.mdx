クイズを終えて結果を読んだ瞬間こそ、人があなたと話したいと最も強く思うタイミングです。**1:1予約** を使えば、その場で結果ページからあなたとのセッションを予約してもらえます。外部のカレンダーツールも、日時を調整するためのメールのやり取りも必要ありません。

<Callout type="info">
  予約可能時間は **チーム単位** のリソースです。一度設定すれば、すべてのクイズで共有されます。クイズごとに週のスケジュールを設定し直す必要はありません。
</Callout>

## 使い始めるための 3 つのステップ

<Steps>
### 予約可能時間を設定する

**1:1予約** ページで **予約可能時間** を開き、タイムゾーン、セッションの長さ、毎週の予約枠を設定します。[予約可能時間](/ja/bookings/availability)をご覧ください。

### クイズで予約セクションをオンにする

対象のクイズの **共有 → 予約** を開き、**結果ページに予約セクションを表示** をオンにします。[回答者側の操作](/ja/bookings/respondent)をご覧ください。

### 予約ページで予約に対応する

新しい予約は **1:1予約** ページに届きます。[予約の管理](/ja/bookings/manage)をご覧ください。
</Steps>

<Callout type="warning">
  予約可能時間を設定するまでは、スイッチをオンにしていても結果ページに予約セクションは **表示されません**。設定ページにもその旨がはっきりと表示されます。
</Callout>

## 一覧の 3 つのセクション

**1:1予約** ページは、対応が必要な順に並んでいます。

- **承認待ち** — 承認制をオンにしている場合、保留中のリクエストが一番上に表示されます。相手を待たせている状態だからです。
- **今後** — 確定済みで、まだ実施していないセッションです。直近のセッションはカウントダウン付きの大きなカードで表示されます。
- **過去** — 履歴です。デフォルトでは折りたたまれています。

サイドバーの **1:1予約** の項目には、承認待ちの件数がバッジで表示されます。

## ステータスの一覧

| ステータス | 意味 |
| --- | --- |
| **承認待ち** | リードの担当者による確定を待っているリクエスト(承認制がオンの場合のみ) |
| **予約済み** | 確定済みで、参加者には会議情報が届いています |
| **完了** | セッションが実施されました(あなたがマークします) |
| **不参加** | 相手が現れませんでした(あなたがマークします) |
| **キャンセル** | どちらかの側が取り消しました |
| **却下** | あなたがリクエストを断りました |
