**Cal.com コネクター** があることで、RooQuiz は結果ページから予約された通話を把握できるようになります。これは **コネクター → 通話の予約** にあるチーム単位のコネクターで、各チームに **1 つ** だけ設定できます。

<Callout type="warning">
  Cal.com コネクターは **Pro** の機能で、設定できるのは **チームのオーナーまたは管理者** だけです。[予約セクション](/ja/bookings/respondent)そのものは、コネクターがなくても Free プランで利用できます。
</Callout>

## 接続する

<Steps>
### Cal.com のカードを開く

**コネクター** を開き、**通話の予約** の下にある **Cal.com** を見つけて **Cal.com を接続** をクリックします。

### データのリージョンを選ぶ

Cal.com アカウントがある場所に合わせて、**グローバル(cal.com)** または **EU(cal.eu)** を選びます。

### 認可する

- **グローバル** — **Cal.com に進む** をクリックし、アクセスを許可します。RooQuiz が読み取るのはプロフィールとイベントタイプだけで、予約を戻すための Webhook を 1 つ追加します。
- **EU** の場合、または OAuth を使いたくない場合 — **代わりに API キーを使う** を選びます。Cal.com で **Settings → Developer → API keys** を開き、有効期限のないキーを作成して貼り付けます。
</Steps>

接続すると、RooQuiz は Cal.com アカウントに Webhook を自動で登録し、イベントタイプを読み込みます。コネクターを削除すると、その Webhook も削除されます。

## クイズでイベントタイプを選ぶ

コネクターを設定すると、クイズの予約セクションにある **Cal.com の予約リンク** の欄にイベントタイプの候補が表示されるので、リンクを貼り付ける代わりに一覧から選べます。Cal.com で新しいイベントタイプを作成した直後は、**イベントタイプを更新** をクリックしてください。

## プランを変更したとき

チームが Free プランに戻った場合、コネクターは残りますが **同期は停止** し、新しい予約は Cal.com にだけ残ります。再びアップグレードすると、同期が再開されます。どちらの場合も、結果ページの予約セクションはそのまま動作します。

<Callout type="info">
  日程変更やキャンセルは **Cal.com** で行います。あなたが行うことも、参加者が Cal.com から届いたメールを使って行うこともあり、いずれも RooQuiz に同期されます。RooQuiz 側で管理する必要はありません。
</Callout>
