条件ロジックは、回答内容に応じて **後続の設問を表示・非表示にする** 機能で、固定のアンケートを回答者に合わせて変化するアンケートに変えます。

<Callout type="warning">
  条件ロジックは **スコアクイズ** と **結果タイプクイズ** でのみ利用できます。知識クイズとランダム知識クイズでは、エディターの右パネルに **ルール** タブがありません。
</Callout>

## ルールの構成

ルールは 1 つの文のように読めます。**もし … ならば、設問を表示 / 非表示にする。**

エディター右パネルの **ルール** タブで **+ ルールを追加** をクリックし、次の項目を入力します。

| 部分 | 説明 |
| --- | --- |
| **もし** | **前にある設問**、演算子、値を選びます |
| **かつ** | **条件を追加** で条件を増やせます。1 つのルール内の条件は AND で結ばれ、すべてを満たす必要があります |
| **ならば** | **表示** または **非表示** を選び、**対象の設問** を選びます |

1 つのクイズに複数のルールを設定でき、**ルール 1 / ルール 2** のように一覧で表示されます。

## 使える演算子

| 演算子 | 使える設問 |
| --- | --- |
| **等しい** | 単一選択、真偽 |
| **いずれかを含む / いずれも含まない** | 複数選択 — 選んだ選択肢のいずれかが選択されていれば一致します |
| **より大きい / 以上 / より小さい / 以下 / 範囲内** | 数値の回答 |

真偽の設問では **✓ 真** と **✗ 偽** を選べます。

<Callout type="info">
  **条件** で参照できるのは、値が確定する設問(選択式、真偽、評価、数値)だけです。**対象** の範囲はそれより広く、穴埋め、説明文、画像カルーセルの設問も表示・非表示にできます。これを使えば、「『その他』を選んだ人にだけ理由を尋ねる」という追加の設問を作れます。
</Callout>

## 設定の手順

<Steps>
### 先に設問を作る

ルールは特定の設問を参照するため、トリガーとなる設問と対象の設問の両方がすでに存在している必要があります。

### ルールを追加する

設問 → 演算子 → 値 → 表示または非表示 → 対象の設問の順に選びます。未完成のルールを保存しようとすると、**ルールをすべて入力してください** と表示されます。

### プレビューで確認する

回答のパターンを一つずつ試してください。ルールが 2〜3 個を超えると、頭の中で考えるだけでは必ずどこかのケースを見落とします。
</Steps>

## 注意すべき点

- 対象の設問より **前にある** 設問を参照してください。後ろにある設問を指定すると、条件を評価する時点ではまだ回答が存在しません。
- 非表示の設問は表示されず、**必須チェックの対象にもならない** ため、送信の妨げになることはありません。
- ルールを削除するときは確認が求められます。削除後、対象の設問はデフォルトの表示状態に戻ります。

<Callout type="info">
  設問を非表示にすると採点に影響します。表示されなかった設問には回答がないため、点数も加算されません。回答者に合わせて変化するアンケートを設計するときは、[採点ルール](/ja/editor/scoring)が非表示になりうる設問と整合しているか確認してください。
</Callout>
