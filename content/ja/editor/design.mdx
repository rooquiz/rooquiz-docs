見た目は 2 つのレイヤーで構成されています。**テーマ** はカラーと角丸を、**パーソナライズテンプレート** はページのレイアウトそのものを制御します。ほとんどの場合、テーマの調整だけで十分です。

## テーマ

エディターの **テーマの選択** で調整します。変更はプレビューにリアルタイムで反映されます。

| 項目 | 説明 |
| --- | --- |
| **テーマカラー** | プライマリ、セカンダリ、アクセント、ニュートラルに加え、情報 / 成功 / 警告 / エラー |
| **角丸** | ボックス、入力欄、選択パーツごとに個別の値を設定 |
| **エフェクト** | 奥行き、ノイズなどの質感の切り替え |
| **サイズと枠線** | 全体の密度と枠線の太さ |

<Callout type="info">
  ブランドの画像がある場合は **画像から色を抽出** を使いましょう。画像をアップロードするとパレットが抽出されてテーマカラーに反映されるので、カラーコードを手入力するより手軽です。
</Callout>

## パーソナライズテンプレート

パーソナライズテンプレートは、配色だけでなく **レイアウト** を変更します。次の 2 種類があります。

| テンプレート | 説明 |
| --- | --- |
| **デフォルト** | 標準のレイアウトです。すっきりとしたニュートラルなデザインで、ほとんどのクイズに適しています |
| **キネティック** | デザインを重視したレイアウトで、ランディングページと結果ページの視覚的な演出が強くなります |

<Callout type="warning">
  キネティックへの切り替えには **Pro が必要** です。制限がかかるのは *切り替える* 操作だけである点に注意してください。すでにキネティックを使っているクイズは、Free プランのチームでも通常どおり表示・編集・複製できます。ダウングレードされるものはありません。
</Callout>

テンプレートを切り替えると、**現在のパーソナライズ設定がリセットされる** という警告が表示されます。レイアウトが変わるとレイアウトのパラメーターも別物になるため、以前の調整は引き継げません。調整内容を残したい場合は、先にクイズを複製してください。

## ランディングページ

ランディングページは、回答者が最初に目にする画面です。エディターでは次の項目を設定できます。

- **タイトル** と **説明** を表示するかどうか、およびその配置。
- **カバー画像**。
- 開始ボタンの文言。

<Callout type="info">
  ランディングページは[検索エンジンへの登録](/ja/publish/promotion)にも影響します。オフにするとクイズはいきなり設問から始まり、検索エンジンが読み取れる内容がほとんどなくなります。検索で見つけてもらいたい場合は、ランディングページをオンのままにして、しっかりとした説明を書きましょう。
</Callout>
