クイズの見た目は 3 つのレイヤーで構成されており、すべてエディター右側の **パーソナライズ** タブで設定します。

| レイヤー | 制御する内容 |
| --- | --- |
| **デザイン** | 開始ページ、設問ページ、結果ページのレイアウト、つまり全体の雰囲気 |
| **テーマ** | そのレイアウトの上に重ねるカラー、角丸、密度 |
| **モジュール** | 開始ページと結果ページに追加するコンテンツブロック(ギャラリーのデザインのみ) |

変更はプレビューにリアルタイムで反映されます。プレビュー内の要素をクリックすると、右側のパネルにその設定が開きます。

## デザインを選ぶ

**デザイン** カードには現在のデザインが表示されます。サムネイルか **変更** をクリックすると、ギャラリーが開きます。

- **デフォルト** は、ほとんどのクイズに合う、すっきりとしたニュートラルなレイアウトです。
- ほかのデザインは、コーチング、コース、金融、フィットネス、ウェルネスなど、特定の用途に合わせて作られており、それぞれ独自の開始ページ、結果ページ、デフォルトのモジュールを備えています。[Quiz themes](https://rooquiz.com/explore/themes) ページでは、サンプルクイズを動かしながら見比べられます。
- あなたのチーム専用に作られたデザインは、**専用** タグ付きで先頭に表示されます。
- デザインを選ぶと、説明とプレビュー画像が表示されます。**自分のクイズで試す** を使うと、何も変更せずに自分の設問でプレビューできます。
- **選択を確定** をクリックすると切り替わります。

<Callout type="warning">
  デザインを切り替えると、**現在のパーソナライズ設定がリセットされます**。デザインごとにレイアウトのパラメーター、文言、デフォルトのモジュールが異なるため、以前の調整は引き継げません。調整内容を残したい場合は、先にクイズを複製してください。
</Callout>

### Pro のデザイン

**Pro** マークの付いたデザインはどのチームでも試したり編集したりできますが、**Pro のデザインを使ったクイズを保存するには Pro プランが必要** です。Free プランでは「This design requires Pro. Upgrade to save, or switch to a free design.」と表示されます。

チームが Pro から外れた場合、すでに Pro のデザインを使っているクイズの設定はそのまま残りますが、公開ページは再びアップグレードするまで **デフォルト** のデザインで表示されます。

<Callout type="info">
  ぴったりの見た目が見つからない場合は、RooQuiz チームがあなたのブランドに合わせたテーマを、あなたのチームだけに表示される形でデザインします。[Custom quiz design](https://rooquiz.com/custom-quiz-design) をご覧ください(Pro プランが必要です)。
</Callout>

## テーマ

**テーマ** カードではカラーパレットを設定します。

- グリッドからテーマを選びます。**カラー** の行にはそのパレット(ベース、プライマリ、セカンダリ、アクセント、ニュートラル、および情報 / 成功 / 警告 / エラーの色)が表示され、**すべて表示** で展開できます。
- **画像から色を抽出** — ブランドの画像をアップロードすると、そこからパレットが生成されます。カラーコードを手入力するより手軽です。
- **ダークテーマを追加**(または **ライトテーマを追加**)— 訪問者の端末がダークモード(またはライトモード)のときに、クイズが自動で切り替わります。追加したテーマで変わるのはカラーだけで、形は常にメインのテーマに従います。ライトとダークの組み合わせが固定されているデザインもあります。

**スタイル** カードでは形を細かく調整します。

| 項目 | 説明 |
| --- | --- |
| **角丸** | ボックス、入力欄、選択パーツごとに個別の値を設定 |
| **エフェクト** | **奥行き** と **ノイズ** の質感の切り替え |
| **サイズ** | 入力欄と選択パーツのサイズ、枠線の太さ |

## 文言と画像

ギャラリーのデザインには、キャッチコピー、開始ボタンの横の文言、結果ページの「Next step」ボックスなど、独自の文言が含まれています。これらは開始ページと結果ページの設定にある **テーマの文言** で編集でき、表示される場所ごとに **Header**、**Next to the start button**、**"Next step" box**、**Other** に分かれています。

画像の項目は、アップロード、差し替え、削除ができるほか、**Unsplash から選択** で選ぶこともできます。**表示範囲を調整** では、デザインが使う比率に合わせて切り抜き範囲をドラッグしたりサイズを変えたりできます。

## モジュール

ギャラリーのデザインでは、紹介、お客様の声、FAQ、料金、プロフィールなどのコンテンツブロックである **モジュール** を、**開始ページ** と **結果ページ** に追加できます。デフォルトのデザインにはモジュールはありません。

- **追加** — 既存のモジュールの下にある **+ モジュールを追加** をクリックし、ギャラリーから選びます。デザインによっては独自のモジュールがあり、**Exclusive to this theme** の下に表示されます。
- **編集** — モジュールをクリックし、**編集** をクリックします。編集画面の左側にはライブプレビュー(テキストをクリックするとその場で編集できます)、右側には項目が表示されます。**保存** で変更が反映され、**キャンセル** で破棄されます。
- **並べ替え・削除** — モジュールのアクションバーにある **上へ移動**、**下へ移動**、**削除** を使います。
- **開始ボタン** — 開始ページでは、開始ボタンをモジュールの間で上下に移動できます。
- **結果ページのセクション** — 組み込みの **次元分析**、**予約セクション**、**回答者フィードバック** のブロックはモジュールと同じ一覧に並ぶので、たとえば予約をお客様の声より上に置けます。組み込みのセクションはここで移動できますが、編集や削除はできません。

<Callout type="info">
  1 つのクイズに追加できるモジュールは、開始ページと結果ページを合わせて **最大 20 個** です。開始ボタンと組み込みの結果セクションは数に含まれません。
</Callout>

## ヘッダーと進捗表示

エディター左側の一覧で **ヘッダー** をクリックすると、**ヘッダータイトル**(**タイトルを表示** の切り替え付き)、**ヘッダーの説明**、**ヘッダーの配置**(左 / 中央 / 右)を設定できます。

**Progress style** では、複数ページのクイズで進捗をどう表示するかを **None**、**Badge**、**Bar**、**Segments** から選びます。デフォルトはデザインごとに決まっています。

評価の設問には、設問の設定に独自の **Display style**(**Stars** または **Numbers**)があります。

## 結果ページのスコアの表示形式

結果ページで総合スコアをどう描くか(**Scale**、**Ring**、**Gauge**、**Steps**)は、**レポート** セクションの **総合分析** で設定します。デザインを切り替えるとそのデザインのデフォルトに設定されますが、後から変更できます。[レベルと結果ページのアクション](/ja/editor/scoring#レベルと結果ページのアクション)をご覧ください。

## ランディングページ

ランディングページ(開始ページ)は、回答者が最初に目にする画面です。設定では次の項目を制御できます。

- **ランディングページを有効化** — オフにすると、いきなり設問から始まります。
- **カバー画像**(**ヘッダー画像をアップロード**)、クイズのタイトルと説明。
- ギャラリーのデザインでは、**テーマの文言** とモジュール。

開始ボタンの文言は **設定 → システム文言** にあります。

<Callout type="info">
  ランディングページは[検索エンジンへの登録](/ja/publish/promotion#検索エンジンへの登録)にも影響します。オフにするとクイズはいきなり設問から始まり、検索エンジンが読み取れる内容がほとんどなくなります。検索で見つけてもらいたい場合は、ランディングページをオンのままにして、しっかりとした説明を書きましょう。
</Callout>
