**コネクター** は、クイズから生まれたリードや予約を、メール、自社のバックエンド、Slack、メール配信サービスなど、すでに使っているツールに送り届けます。左サイドバーの **コネクター** にあります。

<Callout type="info">
  コネクターは **チーム単位** です。一度設定すれば、すべてのクイズで使われます。特定のクイズだけでコネクターを動かしたい場合は、[トリガー範囲](/ja/connectors/events)で絞り込みます。
</Callout>

![RooQuiz のコネクターページ:コネクターのカードが「通知」「システムへ送信」「オーディエンス同期」の 3 グループに並んでいます](/img/en/connectors/connectors-list.webp)

ページは用途ごとにグループ分けされています。

| グループ | 含まれるもの |
| --- | --- |
| **送信アカウント** | **Gmail** — **Gmail を接続** で Gmail アカウントを送信サービスとして接続します。[メール送信サービス](/ja/connectors/email-smtp)をご覧ください |
| **メンバーに通知** | メール、Slack |
| **システムに送信** | Webhook、Zapier |
| **リストを同期** | Kit |
| **通話の予約** | Cal.com — 結果ページから行われた予約を RooQuiz に取り込みます。[Cal.com を接続する](/ja/bookings/calcom)をご覧ください |

## 5 つのチャネル

| チャネル | 用途 |
| --- | --- |
| **メール** | イベントが発生したときに、指定した受信者にカスタマイズ可能な通知を送ります。チームごとに最大 3 つ |
| **Webhook** | HMAC 署名付きで、自社の URL に POST します |
| **Slack** | Slack アプリを認可し、新しいリードをチャンネルに投稿します |
| **Zapier** | Catch Hook の URL を貼り付けて、数千のアプリと連携します |
| **Kit** | 新しいリードを Kit(ConvertKit)の購読者として追加し、タグを付けます |

各コネクターは、選んだイベント(新しい回答、新規リード、予約の作成・キャンセル・変更)で動作します。[トリガーイベントと範囲](/ja/connectors/events)をご覧ください。各コネクターは独立して動作します。**1 つを無効にしても、ほかのコネクターには影響しません**。チャネルごとの設定方法は[5 つのチャネル](/ja/connectors/channels)で説明しています。

## 権限とプラン

<Callout type="warning">
  コネクターを管理できるのは **チームのオーナーまたは管理者** だけです。ほかのメンバーには権限がない旨が表示され、サイドバーの項目も表示されません。
</Callout>

**メール** と **Slack** はすべてのプランで利用できます。**Webhook**、**Zapier**、**Kit**、**Cal.com** は **Pro 限定** です。Free プランのチームで Pro のチャネルを選ぶと、設定エリアがグレーアウトし、アップグレードへのリンクが表示されます。

## コネクターのカードに表示される情報

設定済みの各コネクターには、次の情報が表示されます。

- **有効 / 無効** — 動作しているかどうか。
- **設定が未完了** — OAuth は完了したものの、チャンネルの選択や最後の手順がまだ残っている状態です。この状態では配信されません。
- **最終配信** — 最後に動作した日時と、その結果(成功 / 失敗)。

<Callout type="info">
  設定が終わったら **テスト送信** をクリックして、相手側で本当に受信できることを確認しましょう。最初の本物のリードで問題に気づく事態を避けられます。
</Callout>
