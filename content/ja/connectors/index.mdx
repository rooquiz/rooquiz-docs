**コネクター** は、クイズから生まれたリードや予約を、メール、自社のバックエンド、Slack、メール配信サービスなど、すでに使っているツールに送り届けます。左サイドバーの **コネクター** にあります。

<Callout type="info">
  コネクターは **チーム単位** です。一度設定すれば、すべてのクイズで使われます。特定のクイズだけでコネクターを動かしたい場合は、[トリガー範囲](/ja/connectors/events)で絞り込みます。
</Callout>

![RooQuiz のコネクターページ:コネクターのカードが「通知」「システムへ送信」「オーディエンス同期」の 3 グループに並んでいます](/img/en/connectors/connectors-list.webp)

## 5 つのチャネル

| チャネル | 用途 |
| --- | --- |
| **メール** | イベントが発生したときに、指定した受信者にカスタマイズ可能な通知を送ります |
| **Webhook** | HMAC 署名付きで、自社の URL に POST します |
| **Slack** | Slack アプリを認可し、新しいリードをチャンネルに投稿します |
| **Zapier** | Catch Hook の URL を貼り付けて、数千のアプリと連携します |
| **Kit** | 新しいリードを Kit(ConvertKit)の購読者として追加し、タグを付けます |

各コネクターは独立して動作します。**1 つを無効にしても、ほかのコネクターには影響しません**。チャネルごとの設定方法は[5 つのチャネル](/ja/connectors/channels)で説明しています。

## 権限とプラン

<Callout type="warning">
  コネクターを管理できるのは **組織のオーナーまたは管理者** だけです。ほかのメンバーには権限がない旨が表示され、サイドバーの項目も表示されません。
</Callout>

**メール** チャネルはすべてのプランで利用できます。[自社の SMTP サーバー](/ja/connectors/email-smtp)を通じて送信するため、当社にコストがかからないからです。ほかの 4 つは **Pro 限定** です。Free プランのチームで Pro のチャネルを選ぶと、設定エリアがグレーアウトし、アップグレードへのリンクが表示されます。

## コネクターのカードに表示される情報

設定済みの各コネクターには、次の情報が表示されます。

- **有効 / 無効** — 動作しているかどうか。
- **設定が未完了** — OAuth は完了したものの、チャンネルの選択や最後の手順がまだ残っている状態です。この状態では配信されません。
- **最終配信** — 最後に動作した日時と、その結果(成功 / 失敗 / 上限を超過)。

<Callout type="info">
  設定が終わったら **テスト送信** をクリックして、相手側で本当に受信できることを確認しましょう。最初の本物のリードで問題に気づく事態を避けられます。
</Callout>
