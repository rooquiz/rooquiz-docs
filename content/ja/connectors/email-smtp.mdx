[メールコネクター](/ja/connectors/channels)は **自社の SMTP サーバー** を通じて送信します。RooQuiz が中継することはありません。そのため、通知は自社のアドレスから届き、プラットフォーム側の送信上限もありません。

チームごとに **設定 → 組織 → メール送信** で一度だけ設定します。チーム内のすべてのメールコネクターがこの設定を使います。

<Callout type="warning">
  **確認済み** の送信サービスがない場合でも、メールコネクターは保存できますが、配信されることはありません。そのカードには赤い「送信サービス未設定」タグが表示されます。
</Callout>

## 入力する項目

| 項目 | 説明 |
| --- | --- |
| **SMTP サーバー** | プロバイダーのホスト名。例:`smtp.gmail.com` |
| **ポート** | `587`(STARTTLS)、`465`(SSL/TLS)、または `2525` |
| **ユーザー名** | 通常はメールアドレス全体です。固定の文字列を使うプロバイダーもあります |
| **パスワード** | SMTP のパスワードまたは API キー。後で編集するときは、空欄にすると保存済みのものがそのまま使われます |
| **送信元アドレス** | SMTP サーバーが送信者として使うことを許可しているアドレスである必要があります |
| **送信者名** | 受信者に表示される名前 |
| **返信先** | 任意。返信を別の場所に届けたい場合に設定します |

<Callout type="info">
  **ポート 25 は使用できません。** ホスティング基盤がこのポートでの外向きの接続をブロックしているためです。587 または 465 を使用してください。
</Callout>

## プロバイダーごとの設定

<Tabs items={['Gmail', 'Resend', '社内メールサーバー']}>
  <Tab value="Gmail">
    | 項目 | 値 |
    | --- | --- |
    | SMTP サーバー | `smtp.gmail.com` |
    | ポート | `587 (STARTTLS)` |
    | ユーザー名 | Gmail アドレス全体 |
    | パスワード | **16 文字のアプリパスワード** |
    | 送信元アドレス | **同じ** Gmail アドレス、または確認済みの「他のアドレスからメールを送信」のエイリアス |

    アプリパスワードは [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords) で作成します。4 文字ずつ 4 つのグループに分かれて一度だけ表示されるので、貼り付ける前に **スペースを取り除いて** ください。

    <Callout type="warning">
      通常のアカウントのパスワードは使えません。Google はメールクライアントでのパスワードによるサインインを無効にしているため、アプリパスワードが必要です。また、アプリパスワードは **2 段階認証プロセス** をオンにしていないと作成できません。
    </Callout>

    そのページに *"The setting you are looking for is not available for your account"* と表示される場合は、次のいずれかに該当します。2 段階認証プロセスがオフになっている、管理者がアプリパスワードを無効にした Google Workspace アカウントである、またはアプリパスワードを完全にブロックする高度な保護機能プログラムに登録されている、のいずれかです。

    Gmail には送信数の上限もあり、個人アカウントでは 1 日あたり約 **500 人**、Workspace では **2,000 人** です。チームへの通知には十分ですが、一斉配信には向きません。
  </Tab>

  <Tab value="Resend">
    | 項目 | 値 |
    | --- | --- |
    | SMTP サーバー | `smtp.resend.com` |
    | ポート | `587 (STARTTLS)` |
    | ユーザー名 | `resend`(この文字列そのもの) |
    | パスワード | Resend の API キー(`re_…`) |
    | 送信元アドレス | Resend で確認済みのドメインの任意のアドレス |

    個人のメールボックスではなく **自社ブランドのドメイン** から通知を送りたい場合に最も手軽な方法で、Gmail のような 1 日あたりの上限もありません。
  </Tab>

  <Tab value="社内メールサーバー">
    メールサーバーの管理者に、**SMTP のホスト名、ポート、認証情報** を問い合わせてください。STARTTLS を使うポート 587 が望ましく、それしか提供されていない場合は 465 を使います。

    つまずきやすいポイントが 2 つあります。

    - ユーザー名は、`@` より前の部分ではなく、**メールボックスのアドレス全体** であることが多いです。
    - **送信元アドレスは自社のドメインのものである必要があります**。ほとんどの企業のサーバーは、別のドメインからのメールを装った中継を拒否します。
  </Tab>
</Tabs>

## 保存と確認

<Steps>
### 項目を入力して「保存して確認」をクリックする

保存と確認は 1 つの操作になっているため、保存されたまま未検証の設定が残ることはありません。

### 受信箱でテストメールを確認する

<Callout type="warning">
  テストメールは、先ほど設定した送信元アドレスでは **なく**、**自分の RooQuiz アカウントのアドレス**(サインインに使っているアドレス)に送られます。何も届かない場合は、設定を変更する前に、そのアドレスの受信箱と迷惑メールフォルダを確認してください。
</Callout>

### ステータスが「確認済み」になっていることを確認する
</Steps>

**確認済み** とは、SMTP サーバーがメッセージを受け付けて成功コードを返したという意味です。これは配信完了と同じではありません。SMTP サーバーはまずメールを受け付けてから転送するため、後から迷惑メールとして振り分けられたり、バウンスしたりする可能性があります。確認は成功したのに何も届かない場合、問題は受信側にあります。まず迷惑メールフォルダを確認し、次に送信元のメールボックスにバウンスメールが届いていないかを確認してください。

## 確認に失敗した場合

ページには **SMTP サーバーが返した正確なエラー** が、あえて手を加えずにそのまま表示されるので、それをもとに直接対処できます。よくあるエラーは次のとおりです。

| エラー | 意味 |
| --- | --- |
| `535 Username and Password not accepted` | 認証情報が間違っています。Gmail の場合は、アプリパスワードではなくアカウントのパスワードを使った、またはパスワードにスペースが残っている可能性があります |
| `553 Sender address rejected: not owned by user` | 送信元アドレスが、このサーバーで送信者として使えるアドレスではありません。そのアカウントが実際に所有するメールボックスまたはエイリアスに変更してください |
| `550 relay not permitted` | サーバーがそもそも中継を許可していません。通常はユーザー名の間違いか、メールボックスで SMTP アクセスが有効になっていないことが原因です |
| タイムアウト / 接続失敗 | ホスト名またはポートが間違っているか、サーバーが社外のネットワークからの接続を受け付けていません |

## 知っておきたいこと

- パスワードは保存後、**二度と表示されません**。ほかの項目を編集するときはパスワード欄を空欄のままにしておけば、変更されません。
- サーバー、ポート、ユーザー名、パスワード、送信元アドレスを変更すると、次に確認が成功するまでステータスは **未確認** に戻ります。
- 保存と確認には **回数制限** があり、チームごとに 1 時間あたり数回までです。毎回、実際にサーバーに接続して、実際にメッセージを送信するためです。
- 送信サービスを **削除** すると、保存されているパスワードも削除されます。設定を変更するために削除する必要はなく、上書き保存するだけで構いません。メールコネクターが 1 つでも **有効** になっている間は削除できないため、自分の配信を知らないうちに止めてしまうことはありません。
- 後の配信が恒久的に失敗した場合(認証情報が使えなくなった、送信元アドレスが拒否されたなど)、ステータスは **確認に失敗** に切り替わり、修正するまでメールコネクターは配信を停止します。受信者のアドレスが 1 件間違っているだけではこの状態には **なりません**。そのメッセージ 1 件が失敗するだけです。
