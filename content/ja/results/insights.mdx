インサイトは、ばらばらの回答を **統計とグラフ** に集約し、回答記録を 1 件ずつスクロールしなくても全体像をつかめるようにします。

## よく使う指標とグラフ

- **完了率**:回答を開始した数に対する、回答を完了した数の割合で、離脱の状況を表します。
- **回答数**:回答の総数と、その時間の経過に伴う推移です。
- **設問ごとの分布**:選択式の設問について、各選択肢の割合と分布です。
- **流入元の分布**:[UTM による流入元トラッキング](/ja/publish/tracking)と組み合わせて、チャネルごとの回答数を比較します。

## コンバージョンファネル

ファネルは、**1 回の訪問(セッション)** を **閲覧 → 開始 → 回答 → レポート閲覧 → CTAクリック** の 5 段階で追跡します。各段階のカウント方法は次のとおりです。

| 段階 | カウントされるタイミング |
| --- | --- |
| 閲覧 | クイズのページが実際にブラウザで開かれたとき(クローラーと管理者のプレビューは除外) |
| 開始 | 回答者がいずれかの設問に初めて回答したとき(「開始」をクリックしただけではカウントされません) |
| 回答 | 送信が成功したとき |
| レポート閲覧 | 回答者が結果ページにいる間にレポートの生成が完了したとき |
| CTAクリック | 回答者がレポート下部の [CTA ボタン](/ja/results/reports)をクリックしたとき |

各段階の横に表示される割合は、**直前の段階に対する** コンバージョン率です。そのため、どこで離脱が起きているかを正確に把握できます。

### 離脱ポイント上位10件

**送信しなかった** ものの、少なくとも 1 問には回答したセッションを、**最後に回答した設問** ごとにまとめたものです。件数の多い設問は、難しすぎる、デリケートすぎる、あるいは次の設問を見てやめてしまった、といった理由で人々があきらめているポイントです。何も回答せずに去った訪問者はここには表示されず、閲覧 → 開始の減少として現れます。

### ソース別コンバージョン

リンクに付いた流入元タグ(`?from=`。[流入元トラッキング](/ja/publish/tracking)または[埋め込み](/ja/publish/embed)で生成されます)ごとにまとめ、流入元ごとの閲覧・開始・回答の数と完了率を比較します。ウェブサイトの埋め込みから来た流入元には **埋め込み** タグが付きます。

<Callout type="info">
  ファネルは、この機能がリリースされて以降のセッションを集計しています。それ以前の過去の回答はさかのぼって反映されないため、最初のうちは「回答の総数」がファネルの回答数より多くなることがあります。時間の経過とともに両者は近づいていきます。
</Callout>

## 活用のヒント

- **コンバージョンファネル** で離脱が起きている場所を特定しましょう。閲覧が多いのに開始が少ない場合は、ランディングページか最初の設問に問題があります。開始が多いのに回答が少ない場合は、離脱ポイント上位の設問を確認してください。
- **選択肢の分布** から、回答者全体の傾向を把握しましょう。
- 時間の推移と **ソース別コンバージョン** を組み合わせて、チャネルごとのキャンペーンを評価しましょう。

<Callout type="info">
  インサイトが示すのは「集団の傾向」です。特定の回答を詳しく調べるには[回答記録](/ja/results/records)を、個人ごとの診断結果を確認するには[レポート](/ja/results/reports)をご覧ください。
</Callout>
