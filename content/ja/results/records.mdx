回答記録は、クイズに寄せられた **すべての送信内容** で、クイズの **回答記録** タブにあります。これは生データです。全体の傾向を見たい場合は[インサイト](/ja/results/insights)をご覧ください。

![フィルターとテーブルが表示された RooQuiz の回答記録一覧](/img/en/results/records-list.webp)

## フィルター

**フィルター** をクリックすると条件の作成画面が開き、条件を重ねていけます(条件は AND で結ばれます)。

| 項目 | 説明 |
| --- | --- |
| **設問別** | 特定の設問への回答で絞り込みます。選択式の設問では「いずれかに一致 / いずれにも一致しない / 空である / 空でない」が使えます |
| **回答者** | 特定の 1 人による回答 |
| **UTMソース** | どのチャネルから来たか。[UTM トラッキング](/ja/publish/tracking)と組み合わせて使います |
| **スコア** | 数値の範囲(最小値と最大値の **範囲内**) |
| **レベル** | どのレポートレベルに該当したか |
| **言語** | どの[言語バージョン](/ja/editor/translations)で回答したか |
| **リードステータス / 担当者** | [リード](/ja/leads)のフォローアップのステータスや担当者で絞り込みます |
| **提出日時** | 開始日と終了日 |

条件を設定したら **適用** を、最初からやり直す場合は **すべてクリア** をクリックします。

<Callout type="info">
  ここにはボードビューはありません。ボードは[リード](/ja/leads/list-board)ページにあります。この 2 つは異なる問いに答えるものです。回答記録は **送信内容** を、リードは **人** を扱います。
</Callout>

## 1 件の回答記録

任意の行を開くと、詳細画面は 2 つに分かれます。

- **左** — 設問ごとの回答とそのスコア、およびレポート。
- **右** — この人を[リード](/ja/leads)としてフォローアップするためのサイドバー。ステータスの変更、**コメント** の記入、統合されたアクティビティのタイムラインの確認ができます。

つまり、リードのページに移動しなくても、回答を読みながらフォローアップを進められます。

<Callout type="info">
  コメントには **返信** でき、自分のコメントは削除できます。これは[リードの詳細ページ](/ja/leads/detail)のコメントと同じもので、どちらの画面にも共通の 1 つのスレッドが表示されます。
</Callout>

## 回答記録に含まれる内容

回答そのもの以外に、回答記録には通常次の情報が含まれます。

- **レコード番号** — クイズ内で連番になる番号です。
- **回答者** — サインインしていた場合のみ記録され、匿名の回答では空欄になります。
- **流入元** — [UTM リンク](/ja/publish/tracking)から訪れた場合に記録されます。
- **提出日時**、**言語バージョン**、**スコアとレベル**。

## エクスポート

ツールバーの **エクスポート** では、選択した行、または現在の絞り込み条件に一致するすべての行をエクスポートできます。全件のエクスポートは週ごとの回数枠を消費します。詳しくは[データのエクスポート](/ja/results/export)をご覧ください。

<Callout type="warning">
  エクスポートしたデータには、回答者が提供した個人情報が含まれている場合があります。組織のプライバシーおよびコンプライアンスのルールに従って取り扱ってください。
</Callout>
