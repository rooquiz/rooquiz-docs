リードが数百件になると、毎日実際に対応するのはそのごく一部です。**絞り込み** でその一部を切り出し、**保存済みビュー** を使えば明日また切り出し直す必要がなくなります。

## 使える絞り込み条件

**絞り込み条件** をクリックして作成画面を開き、次の項目を組み合わせます。

| 項目 | 説明 |
| --- | --- |
| **検索** | 回答者の名前またはメールアドレスのあいまい一致 |
| **作成日** | 全期間 / 今日 / 今週 / 今月 / カスタム |
| **ステータス** | 1 つ以上のフォローアップのステータス |
| **タグ** | 選択したタグの **いずれか** が付いているリードに一致 |
| **担当者** | 特定のメンバーが担当しているリード |
| **予約** | 今後の予約がある / ない |

<Callout type="info">
  「今週」は **月曜日** から始まります。今日 / 今週 / 今月は、チームのタイムゾーンではなく、**ブラウザのタイムゾーン** で判定されます。
</Callout>

有効な絞り込み条件はページ上部に小さなチップとして表示されます。チップの × をクリックすると、その条件だけを外せます。

## ビューとして保存する

よく使う絞り込み条件のセットを保存しておけば、ワンクリックで呼び出せます。

<Steps>
### 先に絞り込み条件を設定する

ステータス、タグ、担当者などを選び、意図した人がリストに表示されていることを確認します。

### 「ビューを新規作成」をクリックする

ひと目でわかる名前を付けます。たとえば「今週フォローするホットリード」などです。名前は 50 文字までです。

### ページ上部で切り替える

保存したビューは、ページ上部の **すべて** と **自分のリード** の隣に並びます。ワンクリックで切り替えられます。
</Steps>

次の 2 つのビューは組み込まれているため、作成する必要はありません。

- **すべて** — 絞り込み条件なし。
- **自分のリード** — 自分に割り当てられたリード。

<Callout type="info">
  ビューは **自分だけのもの** で、自分のビューは自分にしか見えず、同僚に影響することはありません。ビューに保存されるのはリードのスナップショットではなく絞り込み条件なので、データの変化に合わせて中身も変わります。
</Callout>

<Callout type="warning">
  ビューを削除しても、保存された絞り込み条件が消えるだけで、**リードには影響しません**。保存できるビューの数には上限があり、上限に達すると通知が表示されます。
</Callout>
