**リード** ページには 2 つのビューがあり、右上の **リスト / ボード** の切り替えで選びます。この選択はあなただけのもので、チームメンバーの表示には影響しません。

![回答者、ステータス、タグ、担当者の列が並ぶ RooQuiz のリード一覧](/img/en/leads/leads-list.webp)

## リストビュー

**一括での作業** や、項目ごとの並べ替えに向いています。テーブルには次の列があります。

| 列 | 意味 |
| --- | --- |
| **回答者** | 名前とメールアドレス。クリックすると[リードの詳細](/ja/leads/detail)が開きます |
| **ステータス** | パイプラインのどこにいるか。[ステータス・タグ・担当者](/ja/leads/status-tags)をご覧ください |
| **タグ** | カラータグ。1 件のリードに複数のタグを付けられます |
| **担当者** | このリードを担当するチームメンバー |
| **回答数** | この人がこれまでに送信したクイズの合計数 |
| **次の予約** | 今後の直近の[予約](/ja/bookings)。ない場合は空欄です |
| **最終回答** | 最後に回答を送信した日時 |
| **最初のクイズ** | 最初に連絡先を残したクイズ |

リストは **無限スクロール** で、スクロールを続けるとさらに読み込まれます。列の見出しで並べ替えができます。

## ボードビュー

列は **フォローアップのステータス** で、ステータスごとに 1 列ずつ並びます。カードを別の列にドラッグすると、ステータスが変わります。1 日 1 回パイプラインを見渡して、人を次の段階に進めるのに向いています。

<Callout type="info">
  カードをドラッグすると **列の中での位置** も変わり、その順番は保持されます。そのため、今日電話する人を一番上に移動しておくことができます。
</Callout>

## 一括操作

リストビューで複数のリードにチェックを入れると、一括操作バーが表示されます。

- **担当者を割り当て** — 選択したリードをチームメンバーに任せます。メンバーには 1 件にまとめられた通知が届きます。
- **タグ付け** — **タグを追加** と **タグを外す** の 2 つの操作があります。タグ全体を置き換えると他の人が付けたタグまで消えてしまうため、まとめて処理するときはこちらを使ってください。
- **ゴミ箱に移動** — リードはゴミ箱に移動し、**5 日以内であれば復元できます**。

<Callout type="warning">
  3 つの一括操作はいずれも **一度に 50 件まで** です。それ以上を選択すると通知が表示されるので、何回かに分けて操作してください。
</Callout>

<Callout type="info">
  ゴミ箱に移動して削除されるのは **フォローアップの記録** だけです。回答者とその回答には影響しません。その人自体も削除したい場合は、[回答者](/ja/respondents)で操作してください。
</Callout>
