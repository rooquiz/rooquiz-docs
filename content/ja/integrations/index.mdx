このセクションは **開発者** 向けで、自社のコードや AI クライアントから RooQuiz にアクセスする方法を説明します。

<Cards>
  <Card title="REST API" href="/ja/integrations/rest-api" />
  <Card title="MCP 連携" href="/ja/integrations/mcp" />
</Cards>

- **REST API** — アカウント単位の API キーを使って、フォームと回答を取得します。独自のダッシュボードやデータウェアハウスへの同期に適しています。
- **MCP 連携** — Claude などの AI クライアントをチームに接続し、クイズの作成、照会、変更を直接行えるようにします。

## コードを書かずに連携する

「リードが届いたら知らせてほしい」「リードをメールツールに同期したい」というだけなら、**API は必要ありません**。[コネクターと自動化](/ja/connectors)の 5 つのチャネル(メール、Webhook、Slack、Zapier、Kit)のいずれかを使ってください。

<Callout type="info">
  違いは **プッシュかプルか** です。コネクターはイベントが発生したときにあなたのもとへ送り届け、REST API では自分のタイミングでデータを取得します。
</Callout>
