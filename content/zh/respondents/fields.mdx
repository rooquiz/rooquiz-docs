# 扩展字段与头像

**扩展字段**是你在标准的姓名 / 邮箱之外,想额外收集的答题者信息——学号、公司、所在城市、手机号。配置好之后,答题者**首次登录时**会被要求填写。

两项都在 **答题者 → 答题者设置** 里配置。

## 扩展字段

<Callout type="warning">
  最多 **5 个字段**。这是刻意的限制:首次登录要填的东西越多,流失越大。
</Callout>

### 三种字段类型

| 类型 | 适用 |
| --- | --- |
| **单行文本** | 学号、公司名这类自由输入,可配正则校验 |
| **下拉选项** | 城市、来源渠道这类固定枚举,可开启多选 |
| **手机号** | 带国家区号的号码,自动做号码合法性校验 |

### 每个字段可以设置

- **必填** —— 不填不让过。
- **唯一** —— 值在**整个团队内不允许重复**,适合学号、工号这种天然唯一的标识。
- **占位提示** —— 输入框里的灰字示例。
- **正则**(仅单行文本)—— JavaScript 正则,**不要带两侧的斜杠**,如 `^1\d{10}$`。
- **允许多选**(仅下拉选项)—— 允许选多个值。
- **允许的国家/地区**(仅手机号)—— 限定可选区号,列表里的第一个默认选中;**留空表示不限**。

### 顺序与删除

字段以折叠面板呈现,用**上移 / 下移**调整顺序,顺序就是答题者看到的填写顺序。

<Callout type="warning">
  删除字段定义后,答题者**已经填过的值仍然留在数据库里**,只是不再展示。保存前弹窗会告诉你要删几个。
</Callout>

## 头像主题

答题者被创建或自助注册时,系统会从你选定的**头像主题**里随机生成一个头像,省得每个人都是灰色默认图。

可选主题包括 Adventurer、Emoji、Lorelei、Thumbs、Robot、Notionist 等,在设置里可以展开预览全部风格。

<Callout type="info">
  换主题只影响**之后**新建的答题者,已有的头像不会被重新生成。
</Callout>
