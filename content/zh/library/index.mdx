两者都是**复用**机制,但复用的东西不同:

| | 题库 | 模板 |
| --- | --- | --- |
| 复用什么 | 一堆**可反复抽取的题目** | 一份**完整的测评结构** |
| 怎么用 | 建卷时从题库随机抽题 | 克隆成一份新测评,再改 |
| 适合 | 同一批知识点要反复考 | 同一种测评要给不同客户各来一份 |

<Callout type="info">
  拿不准就这样选:**每次答题的题目应该不一样 → 题库;每次都一样、只是换个客户 → 模板。**
</Callout>

## 题库

题库是团队自己维护的题目集合,每道题都带正确答案。建卷时选「随机抽题」,系统每次从库里抽一批不同的题,适合练习测验、知识自测。

见 [题库](/zh/library/question-banks)。

## 模板

模板中心里是可以直接克隆的完整测评。你既可以用官方模板快速起步,也可以把自己做得好的测评发布成模板供团队复用。

见 [模板中心](/zh/library/templates)。
