# 答卷记录

答卷记录是某个测评收到的**每一份作答**,在测评的 **记录** 页签里。这里看的是原始数据——想看汇总趋势去 [数据洞察](/zh/results/insights)。

![RooQuiz 答卷记录列表:筛选器与答卷表格](/img/zh/results/records-list.webp)

## 筛选器

点 **筛选** 打开筛选器,可以叠加多个条件(彼此是「且」的关系):

| 可筛字段 | 说明 |
| --- | --- |
| **按题目筛** | 直接按某道题的答案筛,选项类支持「是其中之一 / 不是其中之一 / 为空 / 不为空」 |
| **答题者** | 指定某个人的作答 |
| **UTM 来源** | 从哪个渠道来的,配合 [UTM 追踪](/zh/publish/tracking) |
| **得分** | 按分数区间(**介于** 最小值与最大值) |
| **等级** | 落在哪个报告等级 |
| **语言** | 用哪个 [语言版本](/zh/editor/translations) 作答的 |
| **线索状态 / 负责人** | 按 [线索](/zh/leads) 的跟进状态或负责人筛 |
| **提交时间** | 起止日期 |

条件配好点 **应用**,不要了点 **清除全部**。

<Callout type="info">
  记录页没有看板视图——看板在 [线索](/zh/leads/list-board) 页。两者关注点不同:记录是**一份份答卷**,线索是**一个个人**。
</Callout>

## 单份记录详情

点开任意一条,详情分左右两块:

- **左侧** —— 逐题的作答内容与得分,以及报告。
- **右侧** —— 这个人作为 [线索](/zh/leads) 的跟进侧栏:改跟进状态、写**评论**、看合并后的动态时间线。

也就是说,你在看答卷的同时就能完成跟进,不必再跳去线索页。

<Callout type="info">
  评论支持**回复**,自己写的可以删。这些评论与 [线索详情](/zh/leads/detail#评论) 里的是同一份,两边都能看到。
</Callout>

## 记录里包含什么

除作答内容外,一条记录通常还带:

- **序号** —— 测评内递增的作答编号。
- **答题者** —— 登录后提交才有;匿名提交这一列为空。
- **来源信息** —— 通过 [UTM 链接](/zh/publish/tracking) 提交时记录对应来源。
- **提交时间**、**语言版本**、**得分与等级**。

## 导出

工具栏上的 **导出** 支持导出选中的几条,或导出当前筛选条件下的全部数据。全量导出占用每周额度,详见 [导出数据](/zh/results/export)。

<Callout type="warning">
  导出的数据可能包含答题者填写的个人信息,请按你所在组织的隐私与合规要求妥善保管。
</Callout>
