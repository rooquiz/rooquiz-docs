数据洞察把零散的作答汇总成**统计与图表**,帮助你快速把握整体情况,而无需逐条翻看记录。

用顶部的 **7D / 30D / 90D** 切换时间范围(默认 30 天)。**导出** 会把当前洞察视图下载为 **Excel(.xlsx)** 或 **CSV**——包括概览、受众、趋势、漏斗、渠道、流失点和答案分布。它与 [导出数据](/zh/results/export) 是两回事,不占用每周导出额度。

## 关键数字

顶部一排显示 **今日提交**(与昨日对比)、**累计提交**、**独立答题者**(仅统计已登录的答题者)、**平均得分**、**报告生成率**(已完成 / 失败 / 生成中的报告)以及 **分享** 次数与分享率。

## 常见图表

- **近 N 天提交趋势**:作答量随时间的变化。
- **题目答案分布**:针对单选、下拉、判断和评分题(最多 10 道),展示各选项的占比。
- **来源渠道**:配合 [UTM 来源追踪](/zh/publish/tracking),对比不同渠道带来的作答量。
- **登录方式** 与 **设备类型**:匿名与已注册答题者的占比,以及 iOS / Android / 桌面端的分布。

## 转化漏斗

**转化漏斗**以**一次访问(会话)**为单位,追踪 **浏览 → 开始作答 → 提交 → 查看报告 → CTA 点击**。另有两个阶段只在适用时出现:**登录留资**(在提交之后),出现在设为 **看报告需留邮箱**、或此前已有留资数据的测评上;**分享**(在最后),在结果被分享过之后出现。各阶段的口径:

| 阶段 | 何时计入 |
| --- | --- |
| 浏览 | 答题页在浏览器中真正打开(爬虫与管理端预览不计) |
| 开始作答 | 首次答了任意一题(不是点"开始"按钮) |
| 提交 | 提交成功 |
| 登录留资 | 这次提交关联到了某个答题者——对方留了邮箱或登录了 |
| 查看报告 | 报告生成完成且答题者停留在结果页 |
| CTA 点击 | 点击了报告底部的 [CTA 按钮](/zh/results/reports#结果页-cta-按钮) |
| 分享 | 答题者点击了结果页上的分享按钮(首次、任意渠道) |

每个阶段旁的百分比是**相对上一阶段**的转化率,可以直接看出衰减发生在哪一环。

### 流失点 Top 10

统计**未提交**且至少答过一题的会话,按"最后回答的那道题"分组——人数高的题目就是放弃的高发点,可能太难、太敏感,或它后面那道劝退了答题者。完全没动笔就离开的人不在这里,他们体现在"浏览 → 开始作答"的衰减中。

### 来源转化

按链接的 `utm_source` 分组(由[分发计划](/zh/publish/promotion)、[UTM 来源追踪](/zh/publish/tracking)或[网站嵌入](/zh/publish/embed)的 UTM 属性设置),对比各来源的浏览、开始、提交与完成率;来自网站嵌入的来源会带**嵌入**标识。

<Callout type="info">
  漏斗自功能上线起统计,更早的历史提交不会回填,因此初期"累计提交"可能大于漏斗中的提交数,运行一段时间后自然对齐。
</Callout>

## 使用建议

- 用**转化漏斗**定位流失发生的环节:浏览多、开始少,问题在着陆页或第一题;开始多、提交少,看流失点 Top 10 找具体题目。
- 用**题目答案分布**理解答题者的整体倾向。
- 结合时间趋势与**来源转化**评估各渠道推广活动的效果。

<Callout type="info">
  洞察看的是"群体趋势"。如果你想深入某一份具体作答,请到 [答卷记录](/zh/results/records);如果想看测评的个体分析结论,请到 [测评报告](/zh/results/reports)。
</Callout>
