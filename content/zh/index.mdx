# 创建你的第一个测验

RooQuiz 是一个创建、分发与分析**测验、测评和问卷**的平台,本套文档面向创建者(在后台搭建与管理测验的用户)。这一页带你在几分钟内走完从创建到收到第一份答卷的完整流程。

<Steps>
### 注册并登录

用邮箱创建账号、完成验证后进入控制台。详见 [注册与登录](/zh/getting-started/account)。

### 选类型,创建测验

![RooQuiz 控制台](/img/zh/getting-started/dashboard.webp)

控制台顶部有三张创建卡片,按你想让答题者拿到什么来选:

- 一个分数、对错判定 → **创建测验**
- 一张多维度画像 → **创建评分测验**
- 「你是哪种类型」的结论 → **创建分型测验**

每次随机抽题的 Random Knowledge Quiz 则从 [题库](/zh/library/question-banks) 创建。**推荐从模板开始**——创建抽屉默认停在模板上,克隆后随便改。

<Callout type="warning">
  测验类型创建后**不可更改**,选错只能重建。四种类型的详细差异见 [四种测验类型](/zh/getting-started/quiz-types)。
</Callout>

### 加一道题

创建完成后会直接进入编辑器。点击**添加题目**,加一道**单选题**,写好题干与选项;知识测验记得勾选正确答案并设置分值。用**预览**确认手机和电脑上的效果。更多题型见 [题型总览](/zh/editor/question-types)。

### 发布,拿到链接和二维码

切换到**分享**页签,确认测验处于**启用**状态,复制公开链接或下载二维码发给答题者。详见 [公开链接与二维码](/zh/publish/link-qrcode)。

### 看第一份答卷

自己先打开链接答一遍。回到**记录**就能看到第一份答卷,**洞察**里有完成率与来源数据。详见 [答卷记录](/zh/results/records)。
</Steps>
