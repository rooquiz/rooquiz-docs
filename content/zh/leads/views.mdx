# 筛选与保存视图

线索多起来之后,每天真正要看的往往只是其中一小撮。**筛选**负责圈出这一撮,**保存视图**负责让你明天不用再圈一次。

## 可用的筛选条件

点页面上的 **筛选** 打开筛选器,可以按这些字段组合:

| 字段 | 说明 |
| --- | --- |
| **搜索** | 按答题者姓名或邮箱模糊匹配 |
| **创建时间** | 全部时间 / 今天 / 本周 / 本月 / 自定义区间 |
| **跟进状态** | 选一个或多个状态 |
| **标记** | 命中任意一个所选标记即算匹配 |
| **负责人** | 指派给某个成员的线索 |
| **预约** | 有未开始的预约 / 没有未开始的预约 |

<Callout type="info">
  「本周」按**周一**起算,「今天 / 本周 / 本月」都用**你浏览器所在时区**判定,不是团队时区。
</Callout>

已生效的条件会以小标签的形式排在页面顶部,点标签上的叉即可单独去掉某一条。

## 保存为视图

把一组常用条件存下来,下次一键切回:

<Steps>
### 先调好筛选条件

在筛选器里选好状态、标记、负责人等,确认列表里是你想要的那批人。

### 点「新建视图」

给它起个一眼能认出来的名字,比如「本周待回访的高意向」。名字最长 50 个字符。

### 之后在页顶切换

保存后的视图会和 **全部**、**我的线索** 并排出现在页面顶部,点一下即可切换。
</Steps>

内置的两个视图不用自己建:

- **全部** —— 不带任何条件。
- **我的线索** —— 指派给你自己的线索。

<Callout type="info">
  视图是**私人的**,只有你自己看得到,不会影响同事。视图里存的只是筛选条件,不是线索快照——数据变了,视图里的内容跟着变。
</Callout>

<Callout type="warning">
  删除视图只删这组保存的筛选条件,**不动任何线索**。视图数量有上限,超出时会提示。
</Callout>
