**线索** 页有两种视图,右上角的 **列表 / 看板** 开关随时切换。切换只影响你自己,不会改变别人看到的样子。

![RooQuiz 线索列表:答题者、跟进状态、标记、负责人等列](/img/zh/leads/leads-list.webp)

## 列表视图

适合**批量处理**和按字段排序。表格包含这些列:

| 列 | 含义 |
| --- | --- |
| **答题者** | 姓名与邮箱,点击进入 [线索详情](/zh/leads/detail) |
| **跟进状态** | 当前处在管道的哪一档,见 [状态、标记与负责人](/zh/leads/status-tags) |
| **标记** | 彩色标记,可以同时挂多个 |
| **负责人** | 指派给哪个团队成员 |
| **答卷数** | 这个人一共提交过几份测评 |
| **下一场预约** | 最近一场未开始的 [预约](/zh/bookings),没有则留空 |
| **最近提交** | 最后一次提交的时间 |
| **首次来源** | 第一次留资的那张测评 |

列表是**无限滚动**的,往下滚自动加载更多;点列头可以排序。

## 看板视图

按**跟进状态分列**,每个状态一列,卡片可以直接拖到另一列完成状态变更。适合每天过一遍管道、推进阶段。

<Callout type="info">
  拖动卡片同时改变它在列内的**位置**——顺序会被记住,可以把今天要打的电话拖到最上面。
</Callout>

## 批量操作

在列表视图勾选多条线索,顶部会出现批量操作条:

- **批量指派负责人** —— 一次把选中的线索交给某个成员,对方只收到一条汇总通知。
- **批量打标记** —— 分为**添加标记**和**移除标记**两种模式。批量场景请用这两种,不要用「替换」,否则会把别人打的标记一起洗掉。
- **移入回收站** —— 线索进入回收站,**5 天内可恢复**。

<Callout type="warning">
  三个批量操作**每次最多 50 条**。选超了会提示,分批处理即可。
</Callout>

<Callout type="info">
  移入回收站删的只是**线索这条跟进记录**,答题者本人与他提交的答卷都不受影响。要连人一起删,去 [答题者](/zh/respondents) 页操作。
</Callout>
