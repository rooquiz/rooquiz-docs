# 线索与转化

**线索(Lead)** 是把测评结果变成生意的那一层:每一个在你团队留下联系方式的人,在 **线索** 页里都对应一条记录,带着跟进状态、负责人、标记、答卷数和下一场预约。

<Callout type="info">
  线索是**跨测评**的。同一个人做了你三张测评,线索只有一条,答卷数记为 3。判重的依据是答题者本人,不是某一次提交。
</Callout>

## 线索从哪来

一条线索在**答题者登录后提交测评**时自动产生。匿名提交不会产生线索——系统没有联系方式可留。

因此,想稳定收线索,需要让答题者先登录。常见做法有两种:

- 在测评设置里把提交后的报告设为**登录后可见**,答题者为了看结果会主动登录,提交也随之认领到他名下。
- 在结果页开启 [预约块](/zh/bookings/respondent):点预约会要求登录,顺带把这次提交认领过去。

除此之外,你也可以在 **线索** 页 **手动添加**一条,用于线下认识、别的渠道来的人。见 [线索详情](/zh/leads/detail#手动添加线索)。

## 线索与答题者的区别

这两个概念容易混:

| | 答题者 | 线索 |
| --- | --- | --- |
| 是什么 | 一个人的**账号档案**:姓名、邮箱、头像、扩展字段 | 这个人的**跟进记录**:状态、负责人、标记、评论 |
| 谁产生 | 提交、注册或被手动创建时产生 | 登录提交或被手动添加时产生 |
| 在哪看 | [答题者](/zh/respondents) | 线索 |
| 能不能没有对方 | 可以有答题者而没有线索 | 线索一定挂在某个答题者上 |

简单说:**答题者是人,线索是这个人的销售管道位置。**
