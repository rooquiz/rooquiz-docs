不同测验类型的"评分"含义不同:Knowledge Quiz 知识测验关注**对错与总分**,Scored Quiz 关注**多维度分析与评测报告**。

## Knowledge Quiz:计分与判定

在 **Knowledge Quiz 知识测验** 中,你可以:

- **设置分值**:为题目或正确选项配置分值。
- **判定对错**:标记正确答案,系统自动判定每题对错。
- **汇总总分**:自动累加得到总分。
- **等级**:把总分划分为若干分数段(见 [等级与结果页行动](#等级与结果页行动)),每一档展示各自的结果,而不只是一个干巴巴的分数。
- **作答反馈**:可向答题者展示每题的对错与解析——提交后统一展示,或用 [即时反馈](/zh/editor/settings#答题体验) 逐页展示。
- **AI 匹配**:填空题除了精确匹配、包含匹配,还可以按语义相似度判分,准确度阈值由你设定。AI 判分不限量。

<Callout type="info">
  分值与对错判定在 Knowledge Quiz 里可用。Scored Quiz 按选项计分,Outcome Quiz 完全不计分。
</Callout>

## Outcome:票数判型

**Outcome Quiz 分型测验** 不算分,它**数票**:每个选项给一个或多个结果类型投票,答完后票数最高的类型胜出,平票按类型列表顺序取靠前的那个。如果测评用了 [条件逻辑](/zh/editor/logic),则改按得票率比较,追问支线更长的类型不会只因多拿几票就胜出。

每个类型可以单独配 CTA 按钮或 [跳转链接](#交卷后跳转pro),把"有趣的结果"接到下一步行动上。详见 [四种测验类型](/zh/getting-started/quiz-types#outcome-quiz-分型测验)。

## Scored Quiz:维度分析

在 **Scored Quiz 评分测验** 中,评分更偏向"画像"而非对错:

- **多维度评分**:定义多个维度,每个维度用**各自的公式**引用题目 code 计算;提交后由各维度的公式算出得分,常以**雷达图**呈现。没有配公式的维度得分恒为 0。
- **结果画像**:基于维度得分输出性格/能力等分析结论。

### 总分怎么算

评分测验的总分默认是**所有计分题得分之和**:单选、多选、下拉和判断题按所选选项的分值计,评分题按打出的星数计(给某个星级单独设了分就按设的分)。满分是每道题最高可得分之和,结果页据此画出得分环。数字题的作答不计入——它是年龄这类原始值,不是分数。

需要加权、用维度分或把数字题算进总分时,在报告设置的综合测评里写**计算公式**。公式会取代默认求和,可以引用题目 code 和维度 code——比如让某道题计双倍分,或把两个维度分相加。用了公式就没有天然的满分,结果页只显示分数、不画得分环。

**填空题只收集文本,不参与计分**——自由文本无法参与运算,所以它既不产生分数,也不会出现在公式编辑器的可插入字段列表里。想在计分测评里追问一句开放性问题(如"还有什么想让我们知道的"),用它正合适。

## 等级与结果页行动

在编辑器 **报告** 区的 **分数等级配置** 里给总分划**等级**(如 0-60 待提升 / 60-80 良好 / 80+ 优秀)。每级可配名称、颜色、描述,还能挂自己的 **CTA 按钮** 和 **跳转链接**——比如低分档引导「预约咨询」。这是把测评接到转化上的关键一步。

- **等级顺序** —— 按 **低 → 高** 或 **高 → 低** 排列等级。它只影响展示,包括编辑器里和结果页的分数刻度;两种顺序下计分完全一样。维度等级跟随综合等级的顺序。
- **得分款式** —— 结果页上总分的画法:**刻度条**(默认)、**圆环**、**仪表盘** 或 **阶梯**。阶梯至少需要 2 个等级,圆环和仪表盘需要等级或满分;测评还没有这些数据时,结果页显示刻度条。

<Callout type="info">
  不想让答题者看到具体分数?在 **设置 → 答题体验** 里打开 **隐藏分数**:答题者在任何地方都看不到分数——结果页上没有(总分与维度分),答题时每道题上没有,即时反馈和答案回顾里也没有——等级、分析与对错照常保留。如果总结模板里还插着分数变量,也要一并删掉,否则分数仍会在那里显示。
</Callout>

### CTA 按钮

在 **CTA 按钮** 下打开按钮,并设置一个 **默认按钮**(文字和链接)。没有单独配按钮的等级——分型测验里则是结果类型——都使用默认按钮;默认按钮留空时,只有单独配了按钮的等级才显示按钮。关掉 **CTA 按钮**,所有结果都不显示按钮。见 [结果页 CTA 按钮](/zh/results/reports#结果页-cta-按钮)。

### 交卷后跳转(Pro)

打开 **交卷后跳转**,答题者交卷后不看结果页,直接按结果跳到对应链接——比如低分的人去入门课页面,高分的人去预约页面。

- 给每个等级(或每个结果类型)设置 **跳转链接**,另外可以设一个 **默认链接**,给没有单独链接的结果用。
- **在链接上附带结果参数** 会追加 `score`、`level`、`outcome` 和 `outcome_name`,以及测评的 [URL 参数](/zh/publish/tracking#url-参数隐藏字段) 和 UTM 标签。邮箱等个人信息永远不会附带,链接里原有的参数会保留,隐藏分数时不附带 `score`。
- 如果看报告需要留邮箱或登录,答题者会在完成这一步**之后**再跳转。
- 在 [嵌入的测评](/zh/publish/embed) 里,整个宿主页面都会跳转到该链接。

以下情况仍然显示结果页(带结果描述和 CTA 按钮):答题者的结果没有链接、也没有默认链接;答题者之后回来查看自己的结果;有人打开分享出去的结果链接。

<Callout type="warning">
  交卷后跳转是 **Pro** 功能,AI 测评不可用。团队不再是 Pro 时,答题者会重新看到结果页;你配的链接会保留,升级后恢复生效。
</Callout>

## 结果页板块排序

在总体结果下方,结果页可以带 **维度分析**、**预约块** 和 **答题者反馈** 三个板块。在编辑器的 **报告页** 预览里选中某个板块,用 **上移** / **下移** 调整答题者看到的顺序——比如目标是约通话时,就把预约块放到最前面。

预约块和反馈块在 **设置 → 结果页跟进** 里开启,见 [测评设置](/zh/editor/settings#结果页跟进)。

## 报告生成

- **同步**:提交后立即计算基础评分。
- **异步**:多维分析等较重的计算会异步生成,报告会经历"生成中 → 完成"的状态;失败时系统会自动重试。

报告的查看、导出与投递详见 [测评报告](/zh/results/reports)。
