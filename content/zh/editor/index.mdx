# 编辑器概览

可视化编辑器是搭建测评的主工作区,分**左中右三栏**:添加题目、实时预览、配置细节都在这一屏里完成。

![RooQuiz 编辑器三栏:题型面板、预览与属性设置](/img/zh/editor/editor-overview.webp)

## 三栏各管什么

| 区域 | 作用 |
| --- | --- |
| **左栏 题型面板** | 按分类列出全部题型,点击或拖入即加进题目列表;Random Quiz 类型这里是**题库**页签 |
| **中栏 预览** | 答题者视角的实时渲染。顶部可在 **填写页 / 报告页** 之间切换,报告页还能指定 **预览级别** 或 **预览类型**,看不同结果长什么样 |
| **右栏 设置** | 针对当前选中项的细节配置 |

## 右栏的三个页签

| 页签 | 内容 | 何时出现 |
| --- | --- | --- |
| **属性** | 当前题目的题干、选项、是否必填、分值等 | 一直在 |
| **个性化** | 这道题的外观定制 | 一直在 |
| **规则** | [条件逻辑](/zh/editor/logic) | **仅 Scorecard 与 Outcome** |

<Callout type="info">
  找不到「规则」页签,通常不是没找到,而是这份测评的类型不支持——见 [四种测验类型](/zh/getting-started/quiz-types)。
</Callout>

## 常用操作

- **添加题目** —— 从左栏选题型。完整清单见 [题型总览](/zh/editor/question-types)。
- **拖拽排序** —— 直接拖题目改先后。注意 [条件逻辑](/zh/editor/logic) 要求触发题排在目标题之前,调序后记得复查规则。
- **复制题目** —— 结构相似的题目复制一份再改,比重新建快。
- **分页符** —— 插入分页符把长测评切成多页,避免一屏塞满题目。
- **富文本与配图** —— 题目描述支持富文本,可以插图。

## 顶部还有什么

- **预览** —— 打开完整的答题者视角预览。
- **更多设置** —— 进入 [表单设置](/zh/editor/settings)。
- **发布为模板** —— 把这份测评发布到 [模板中心](/zh/library/templates) 供团队复用。
