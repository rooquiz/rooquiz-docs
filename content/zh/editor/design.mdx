# 外观与个性化模板

外观分两层:**主题**决定颜色与圆角这些基础视觉,**个性化模板**决定整个页面的版式风格。多数情况下调主题就够了。

## 主题

在编辑器的**主题选择**里调整,改动实时反映在右侧预览:

| 可调项 | 说明 |
| --- | --- |
| **主题色** | 主色、辅助色、强调色、中性色,以及信息 / 成功 / 警告 / 错误四个语义色 |
| **圆角** | 卡片、输入框、选择器三处的圆角分别可调 |
| **效果** | 景深、噪点等质感开关 |
| **尺寸与描边** | 整体的疏密与边框粗细 |

<Callout type="info">
  有品牌图的话可以用 **从图片取色**——上传一张图,系统提取配色填进主题色,比手工调色号快。
</Callout>

## 个性化模板

个性化模板换的是**版式**,不只是配色。目前可选两个:

| 模板 | 说明 |
| --- | --- |
| **默认** | 标准版式,清爽中性,适合绝大多数测评 |
| **Kinetic** | 带设计感的版式,落地页与结果页有更强的视觉表达 |

<Callout type="warning">
  切换到 Kinetic **需要 Pro**。注意这个限制只卡「切换」这个动作:已经在用它的测评,免费团队照样正常渲染、正常编辑、正常复制,不会被降级。
</Callout>

切换模板时会提示**当前个性化设置将被重置**——换版式意味着换一套布局参数,原来的调整留不下来。想保留就先复制一份测评再试。

## 落地页

落地页是答题者进来看到的第一屏。在编辑器里可以控制:

- 是否显示**标题**与**描述**,以及它们的对齐方式。
- **封面图**。
- 开始按钮的文案。

<Callout type="info">
  落地页对 [搜索引擎收录](/zh/publish/promotion#搜索引擎收录) 也有影响:关掉落地页,测评一进来就是题目,搜索引擎几乎读不到内容。想被搜到就把落地页留着并写好描述。
</Callout>
