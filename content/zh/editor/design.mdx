测评的外观分三层,都在编辑器右侧的 **个性化** 页签里:

| 层 | 管什么 |
| --- | --- |
| **设计方案** | 开始页、答题页与结果页的版式——整体的风格与观感 |
| **主题** | 在版式之上调配色、圆角与疏密 |
| **模块** | 开始页与结果页上额外的内容块(仅画廊里的设计方案支持) |

改动会实时反映在预览里。在预览里点任意元素,右侧面板就会打开它对应的设置。

## 选择设计方案

**设计方案** 卡片显示当前使用的设计方案。点缩略图或 **更换** 打开画廊。

- **默认** 是清爽中性的标准版式,适合绝大多数测评。
- 其他设计方案面向特定用途——教练、课程、理财、健身、身心健康等——各有自己的开始页、结果页和默认模块。可以在 [Quiz themes](https://rooquiz.com/explore/themes) 页面配合在线示例测评浏览它们。
- 专为你的团队制作的设计方案排在最前,带 **专属** 标签。
- 选中一个设计方案可以看到它的介绍和预览图。点 **在我的测评上试穿**,用你自己的题目预览效果,不会改动任何设置。
- 点 **确认选择** 完成切换。

<Callout type="warning">
  切换设计方案会**重置当前的个性化设置**。每个设计方案都有自己的布局参数、文案和默认模块,原来的调整没法带过去。想保留就先复制一份测评。
</Callout>

### Pro 设计方案

标有 **Pro** 的设计方案所有团队都可以试用和编辑,但**保存使用 Pro 设计方案的测评需要 Pro 套餐**。免费版保存时会提示「该设计需要 Pro 套餐。升级后即可保存，或换用免费设计。」

如果团队不再是 Pro,已经在用 Pro 设计方案的测评会保留设置,但公开页会改用默认设计方案显示,直到重新升级。

<Callout type="info">
  找不到合适的风格?RooQuiz 团队可以按你的品牌定制一套主题,只对你的团队可见——见 [Custom quiz design](https://rooquiz.com/custom-quiz-design)(需要 Pro 套餐)。
</Callout>

## 主题

**主题** 卡片决定配色:

- 在网格里选一个主题。**配色** 一行显示它的调色板——基础、主色、辅色、强调、中性,以及信息 / 成功 / 警告 / 错误几个颜色;点 **展开** 查看全部。
- **从图片拾取配色** —— 上传一张品牌图,系统据此生成调色板,比手工填色号快。
- **添加深色主题**(或 **添加浅色主题**)—— 访客设备处于深色(或浅色)模式时,测评自动切换过去。附加主题只换颜色,形状始终沿用主主题。有些设计方案自带固定的浅色 / 深色搭配。

**样式** 卡片微调形状:

| 可调项 | 说明 |
| --- | --- |
| **圆角** | 卡片、输入框、选择器三处分别可调 |
| **特效** | **深度** 与 **噪声** 两个质感开关 |
| **尺寸** | 输入框与选择器的尺寸,以及边框粗细 |

## 文案与图片

画廊里的设计方案自带文案——宣传语、开始按钮旁的说明、结果页的「下一步」区块等。在开始页和结果页设置的 **主题文案** 里修改,按出现位置分组:**页头**、**开始按钮旁**、**「下一步」区块** 和 **其他**。

图片字段可以上传、替换或删除,也可以用 **从 Unsplash 选择** 挑图。**调整显示区域** 让你按设计方案使用的比例拖动、缩放裁剪框。

## 模块

画廊里的设计方案可以往 **开始页** 和 **结果页** 添加**模块**——介绍、用户评价、常见问题、价格、个人简介等内容块。默认设计方案没有模块。

- **添加** —— 点现有模块下方的 **+ 添加模块**,从画廊里选一个。有些设计方案有自己的模块,列在 **本主题专属** 下。
- **编辑** —— 点选一个模块,再点 **编辑**。编辑器左边是实时预览(点任意文字可以就地修改),右边是它的字段。**保存** 应用改动,**取消** 放弃改动。
- **排序或删除** —— 用模块操作栏上的 **上移**、**下移** 和 **删除**。
- **开始按钮** —— 在开始页上,开始按钮可以在模块之间上下移动。
- **结果页板块** —— 内置的 **维度分析**、**预约块** 和 **答题者反馈** 与模块排在同一个列表里,所以可以把预约块放到某条用户评价上面。内置板块在这里只能移动,不能编辑或删除。

<Callout type="info">
  一份测评的开始页与结果页**合计最多 20 个模块**。开始按钮和内置结果页板块不计入。
</Callout>

## 页头与进度

在编辑器左侧列表里点 **页头**,设置 **页眉标题**(带 **显示标题** 开关)、**页眉描述** 和 **页眉对齐**(左对齐 / 居中 / 右对齐)。

**进度款式** 决定多页测评如何显示进度:**无**、**角标**、**进度条** 或 **分段**。每个设计方案都有自己的默认值。

评分题有自己的 **展示样式**——**星星** 或 **数字**——在该题的设置里调整。

## 结果页得分款式

结果页上总分的呈现方式——**刻度条**、**圆环**、**仪表盘** 或 **阶梯**——在 **报告** 区的 **综合分析** 下设置。切换设计方案时会改成该设计方案的默认款式,之后可以再改。见 [等级与结果页行动](/zh/editor/scoring#等级与结果页行动)。

## 落地页

落地页(开始页)是答题者进来看到的第一屏。在它的设置里可以控制:

- **启用 Landing 页** —— 关掉后测评一进来就是题目。
- **封面图**(**上传头图**)、测评标题与描述。
- 画廊设计方案的 **主题文案** 与模块。

开始按钮的文案在 **设置 → 系统文案** 里改。

<Callout type="info">
  落地页对 [搜索引擎收录](/zh/publish/promotion#搜索引擎收录) 也有影响:关掉落地页,测评一进来就是题目,搜索引擎几乎读不到内容。想被搜到就把落地页留着并写好描述。
</Callout>
