RooQuiz 提供 11 种作答题型,外加展示与结构块(富文本、图片轮播、分页符、随机题目)。下面按用途分组介绍,帮助你为每道题挑选合适的形式。

## 选择类

| 题型 | 说明 | 常见用途 |
| --- | --- | --- |
| **单选** | 一组选项中只能选一个 | 单选知识题、满意度单选 |
| **多选** | 一组选项中可选多个 | 多选题、兴趣偏好 |
| **下拉** | 以下拉列表呈现的单选 | 选项较多时节省空间 |
| **级联** | 多级联动选择(如省-市-区) | 地区、分类等层级选择 |
| **判断题** | 对 / 错 二选一 | 是非题 |

## 输入类

| 题型 | 说明 | 常见用途 |
| --- | --- | --- |
| **填空** | 文本输入 | 简答、开放性回答、「其他,请说明」 |
| **数字** | 数值输入(可校验) | 年龄、金额、数量 |
| **日期** | 日期选择器 | 出生日期、预约日期 |
| **时间** | 时间选择器 | 时间段、时刻 |

## 评价与排序类

| 题型 | 说明 | 常见用途 |
| --- | --- | --- |
| **评分** | 按量表打分(如 1–5 / 1–10) | 满意度、重要性评分 |
| **排序** | 拖拽对若干项排序 | 优先级、偏好排序 |

## 展示与特殊类

这些块用来组织测评结构,不收集作答。

| 题型 | 说明 | 常见用途 |
| --- | --- | --- |
| **富文本** | 展示带格式的文字和图片 | 分节说明、指引、声明 |
| **图片轮播** | 展示一组可左右滑动浏览的图片 | 产品图、示例、视觉背景 |
| **分页符** | 把测评分成多页 | 篇幅较长的测评 |
| **随机题目** | 一个从题库抽题的占位 | 配合「随机知识测验」类型 |

## 哪种测验能用哪些题型

题型不是每种测验都通用——有的题型天生没有"正确答案",有的没法给结果类型投票。编辑器左栏只会列出当前测验类型能用的题型。

| 题型 | 知识测验 | 评分测验 | 分型测验 |
| --- | --- | --- | --- |
| 单选 / 多选 / 下拉 / 判断 | ✅ | ✅ | ✅ |
| 填空 | ✅ 可配正确答案判分 | ✅ **仅收集,不计分** | ❌ |
| 数字 | ✅ 可配正确答案判分 | ✅ 作答数值进公式 | ❌ |
| 级联 / 评分 | ❌ | ✅ | ❌ |
| 日期 / 时间 | ❌ | ✅ 取值可进公式 | ❌ |
| 排序 | ✅ | ❌ | ❌ |
| 富文本 / 图片轮播 / 分页符 | ✅ | ✅ | ✅ |

**Random Knowledge Quiz 随机题库**只用随机题与展示类题型,题目本身来自关联的题库。

<Callout type="info">
  评分测验里的**填空题只收集文本**:它不产生分数,也不能被评分公式引用。适合在计分题之后追问一句"还有什么想让我们知道的",把开放性线索一起收上来。
</Callout>

<Callout type="info">
  评分测验里的选择题也可以切换为**仅收集数据**:答案会被记录但不计分——没有选项分值,公式也不能引用这道题。答题者看到的是普通的单选圈 / 多选框,而不是 A/B/C 字母徽章。如果某个公式还引用着这道题,要先把它从公式里移除才能保存。适合用来收集职位、公司规模这类画像题:给线索分群,但不影响得分。
</Callout>

<Callout type="info">
  每种题型在右侧设置面板中都有各自的配置项,常见包括:题目标题与描述、是否必答、选项内容、校验规则等。带评分能力的题型还可设置分值(详见 [评分与测评规则](/zh/editor/scoring))。
</Callout>

<Callout type="warning">
  **随机题**通常用于「Random Knowledge Quiz 随机题库」类型,需要先关联题库;在其他类型中可能不适用。
</Callout>
