# 条件逻辑

条件逻辑让测评根据答题者的作答**动态显示或隐藏后续题目**,做出"千人千面"的自适应问卷。

<Callout type="warning">
  条件逻辑只在 **Scorecard 评分诊断** 与 **Outcome 分型测评** 里可用。Quiz 与 Random Quiz 的编辑器右栏没有「规则」页签。
</Callout>

## 一条规则长什么样

规则读起来就是一句话:**如果 …… 则 显示 / 隐藏 某道题**。

在编辑器右栏的 **规则** 页签点 **+ 添加规则**,逐项填:

| 组成 | 说明 |
| --- | --- |
| **如果** | 选一道**前置题目**、一个运算符、一个值 |
| **且** | 可以继续 **添加条件**;同一条规则里的多个条件是「且」的关系,要全部满足 |
| **则** | 选 **显示** 或 **隐藏**,再选**目标题目** |

一份测评里可以有多条规则,界面上按 **规则 1 / 规则 2** 依次排列。

## 可用的运算符

| 运算符 | 适用 |
| --- | --- |
| **等于** | 单选、判断 |
| **包含任一 / 不包含任一** | 多选——命中所选选项中的任意一个即成立 |
| **大于 / 大于等于 / 小于 / 小于等于 / 介于** | 数字类作答 |

判断题的取值是 **✓ 正确** 与 **✗ 错误** 两项。

## 配置步骤

<Steps>
### 先把题目搭齐

规则引用的是具体题目,题目不存在就没法选。先把前置题和目标题都建出来。

### 添加规则

选前置题 → 选运算符 → 选值 → 选显示还是隐藏 → 选目标题。没填完就保存会提示 **请完整填写规则**。

### 用预览走查

按不同答案各走一遍,确认该出现的出现、该藏的藏住。规则一多,只靠脑补很容易漏掉某条路径。
</Steps>

## 注意事项

- 触发条件请引用**排在目标题之前**的题目——引用后面的题目,答题者还没答到,条件无从判定。
- 被隐藏的题目不会展示给答题者,**也不参与必填校验**,不会卡住提交。
- 删除规则会二次确认,删掉之后目标题恢复为默认显示。

<Callout type="info">
  隐藏题目会影响评分:没展示的题目自然没有作答,也就不贡献分数。设计自适应问卷时,记得让 [评分规则](/zh/editor/scoring) 与可能被隐藏的题目对得上。
</Callout>
