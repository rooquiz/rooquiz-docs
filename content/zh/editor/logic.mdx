条件逻辑让测评根据答题者的作答**动态显示或隐藏后续题目**,做出"千人千面"的自适应问卷。

<Callout type="info">
  条件逻辑在 **Scored Quiz 评分测验** 与 **Outcome Quiz 分型测验** 中可用。Knowledge Quiz 知识测验与 AI 测评的编辑器右栏没有「规则」页签——隐藏题目会改变知识测验的满分与正确率口径。
</Callout>

## 一条规则长什么样

规则读起来就是一句话:**如果 …… 则 显示 / 隐藏 某道题**。

在编辑器右栏的 **规则** 页签点 **+ 添加规则**,逐项填:

| 组成 | 说明 |
| --- | --- |
| **如果** | 选一道**前置题目**、一个运算符、一个值 |
| **且** | 可以继续 **添加条件**;同一条规则里的多个条件是「且」的关系,要全部满足 |
| **则** | 选 **显示** 或 **隐藏**,再选**目标题目** |

一份测评里可以有多条规则,界面上按 **规则 1 / 规则 2** 依次排列。

## 可用的运算符

| 运算符 | 适用 |
| --- | --- |
| **等于** | 单选、判断 |
| **包含任一 / 不包含任一** | 多选——命中所选选项中的任意一个即成立 |
| **大于 / 大于等于 / 小于 / 小于等于 / 介于** | 数字类作答 |

判断题的取值是 **✓ 正确** 与 **✗ 错误** 两项。

<Callout type="info">
  能当**条件**的是有确定取值的题(单选、多选、下拉、判断、评分、数字);能当**目标**的范围更宽,填空题以及富文本、图片轮播也可以被显示/隐藏——「选了『其他』才追问一句『请说明』」就是这么配的。
</Callout>

## 配置步骤

<Steps>
### 先把题目搭齐

规则引用的是具体题目,题目不存在就没法选。先把前置题和目标题都建出来。

### 添加规则

选前置题 → 选运算符 → 选值 → 选显示还是隐藏 → 选目标题。没填完就保存会提示 **请完整填写规则**。

### 用预览走查

按不同答案各走一遍,确认该出现的出现、该藏的藏住。规则一多,只靠脑补很容易漏掉某条路径。
</Steps>

## 注意事项

- 触发条件请引用**排在目标题之前**的题目——引用后面的题目,答题者还没答到,条件无从判定。
- 被隐藏的题目不会展示给答题者,**也不参与必填校验**,不会卡住提交。
- 删除规则会二次确认,删掉之后目标题恢复为默认显示。

<Callout type="info">
  隐藏题目会影响结果。在 **评分测验** 里,没展示的题目自然没有作答,也就不贡献分数,记得让 [评分规则](/zh/editor/scoring) 与可能被隐藏的题目对得上。在 **分型测验** 里,被隐藏的题目不会投票,所以用了规则的测评改按**得票率**判型,见下文。
</Callout>

## 分型测验:按得票率判型

不用规则时,分型测验取票数最高的类型。用了规则之后,不同答题者看到的题目不同,追问支线更长的类型可能只因为多拿了几票就胜出。所以用了规则的测评比较的是每个类型**在该答题者实际看到的题目里能拿到的票中,拿到了多少比例**:

- 得票率 = (得票 + 0.5) ÷ (能拿到的票 + 1)。这一点平滑能防止只有一道题投给它的类型凭 1/1 胜出。
- 没有任何可见题目投给它的类型记 0。
- 得票率相同时先比原始票数,再按结果类型列表顺序。

编辑器会在结果类型下方运行 **类型覆盖检查**,遍历所有作答路径:标出永远判不中的类型,并列出某个类型一票都拿不到的路径。它只提示、不拦保存,但被标出的类型通常意味着某条支线需要一道给它投票的题目。
