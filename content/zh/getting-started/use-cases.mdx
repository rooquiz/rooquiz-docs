下面每个方案都写明要选的测验类型，以及让它真正跑起来的几项关键设置。只要控制台 **你想做什么？** 卡片里有接近的模板，就从模板开始——见 [创建测验](/zh/getting-started/create-quiz)。

## 引流评估诊断

*「你的企业为 X 做好准备了吗？」——用一个分数换来一次销售对话。*

1. 卡片：**评估诊断**（评分测验）。给每个选项设分，总分就是各选项分数之和。想用雷达图展示多个方面，再加上 [维度](/zh/editor/scoring#scored-quiz维度分析)。
2. 把总分划成 [等级](/zh/editor/scoring#等级与结果页行动)，给低分档和中间档配一个 **CTA 按钮**，比如「预约通话」。
3. 打开 **设置 → 开放与权限 → 看报告需留邮箱**，每一份完成的测评都会变成一条 [线索](/zh/leads)。
4. 在结果页加一个 [预约块](/zh/bookings)，再给每个等级配一封 [按结果发邮件](/zh/editor/settings#结果页跟进)。
5. 在 [数据洞察](/zh/results/insights) 里看漏斗——答题者在哪一步流失、多少人点了 CTA。

## 产品 / 课程推荐

*「哪门课最适合你？」——给每个人匹配一个产品或课程。*

1. 卡片：**产品 / 课程推荐**（分型测验）。每个产品或课程建一个结果类型。
2. 让每个选项给它指向的结果类型投票，得票最多的类型胜出。用 [条件逻辑](/zh/editor/logic) 跳过不相关的题目。
3. 给每个结果类型配一个指向对应产品页的 CTA——Pro 套餐也可以带上结果参数，直接 [跳转](/zh/editor/scoring#交卷后跳转pro) 过去。
4. 在 [Kit](/zh/connectors/channels#kit) 里按结果给订阅者打标签，让每种结果各自启动一套邮件序列。

<Callout type="info">
  推荐类和分级定位类测评请关闭 **群体对照**：看到大多数人选了什么，会把后来的答题者往同一个选项上带。
</Callout>

## 水平测试

*语言学校或培训课程的分级定位测试。*

1. 卡片：**水平测试**。回答 **题目有标准答案吗？**——判对错的题目选 **有**（知识测验），自我评估选 **没有**（评分测验）。
2. 设置 A1–C2 这样的 [等级](/zh/editor/scoring#等级与结果页行动)，给每个等级配一个指向对应班型或试听课的 CTA。等级顺序选 **高 → 低**，最高等级会排在最前面。
3. 保持 [即时反馈](/zh/editor/settings#答题体验) 关闭——它会逐页公布答案。
4. 配一封 [按结果发邮件](/zh/editor/settings#结果页跟进)，推荐适合的班级。

## 适合传播的人格测试

*「你是哪一种 X？」——为传播而生。*

1. 卡片：**人格测试**（分型测验）。给每个结果类型起一个有记忆点的名字，配上图片和描述。
2. 保持 **结果页分享** 开启，并检查 [分享卡片](/zh/publish/og)——结果被转发出去时，别人看到的就是它。
3. 打开 [群体对照](/zh/editor/settings#答题体验)，让答题者看到「62% 的人和你选得一样」。
4. 挑一个开始页有冲击力的 [设计方案](/zh/editor/design)；填写权限用 **完全公开**，尽量减少门槛。

## 知识挑战

*好玩、能比拼的知识问答。*

1. 卡片：**知识挑战**（知识测验）。标出正确答案并设置分值。
2. 加上 [限时答题](/zh/editor/settings#答题体验)，再打开 **即时反馈**，让答题者边答边学。
3. 用等级给每个分数段起一个值得分享的有趣称号。

## AI 撰写的个性化诊断

*简历点评、口语测评、业务诊断——为每位答题者写一份专属报告。*

1. 卡片：**AI 个性化报告**（AI 测评）。添加题目；如果要让 AI 审阅真实作品，再加一道附件上传题。
2. 编写 [生成说明](/zh/editor/ai-report#编写生成说明)，并选择报告篇幅。
3. 添加 [结果标签](/zh/editor/ai-report#结果标签)，比如 *准备购买* / *继续培育* / *为时尚早*，给每个标签配一个 CTA，并把它们接到你的连接里。
4. 打开 **看报告需留邮箱**：只有留下邮箱的人才会生成报告，也只有这时才消耗 AI 点数。
