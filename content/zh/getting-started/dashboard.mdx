登录后进入**控制台**,这里集中展示你与团队的全部测评,是日常管理的起点。

![RooQuiz 控制台:左侧导航栏与测验列表](/img/en/getting-started/dashboard.webp)

## 页面主体

- **创建入口** —— 顶部三张卡片对应 [创建知识测验 / 创建评分测验 / 创建分型测验](/zh/getting-started/create-quiz)。
- **分组标签** —— **全部**、**我的收藏**,以及你自建的分组,旁边是 **创建分组**,见 [工作区](/zh/getting-started/workspace)。
- **测验卡片** —— 每张卡显示类型角标、封面、标题、创建日期和答卷数,底部是编辑、记录、更多三个快捷入口。

## 左侧导航

| 入口 | 作用 |
| --- | --- |
| **我的测验** | 就是当前这一页 |
| **[题库](/zh/library/question-banks)** | 可复用的题目池 |
| **[答题者](/zh/respondents)** | 做过你测评的人的档案 |
| **[线索](/zh/leads)** | 留过联系方式的人的跟进管道 |
| **[1:1 预约](/zh/bookings)** | 结果页约来的会谈,带待确认角标 |
| **[连接](/zh/connectors)** | 团队级的推送渠道,**仅所有者与管理员可见** |

顶部的搜索框跨测评、题库、答题者、线索全局查找;底部可以**收起侧边栏**。

<Callout type="info">
  **线索**和 **1:1 预约**是团队可选的**功能模块**。团队所有者可以在团队设置的 **基本信息** 里关掉其中任意一个。关掉的模块会对所有成员从侧边栏和所有相关页面消失,也不再产生新数据。已有数据会保留,重新打开后就回来;已排好的预约不会被取消。
</Callout>

## 拿到你的第一条线索

新团队会在控制台上看到 **拿到你的第一条线索** 清单:从零到第一份提交的四步。

1. **创建第一个测评** —— 从模板开始,计分、结果页和留资墙都已预先配好。
2. **发布上线** —— 打开测评,把它切换为开启状态。
3. **把链接发出去** —— 在 **分享** 里拿到链接或嵌入代码;个人主页链接、你的网站、社区帖子都行。
4. **收到第一条提交** —— 有人完成测评后,答案和联系方式会出现在 **记录** 里。

收到第一份提交后,清单会变成 **跑起来了!**。你随时可以点 **隐藏** 收起清单。

## 单个测验的功能入口

进入某个测验后有四个页签:

| 页签 | 作用 |
| --- | --- |
| **[编辑](/zh/editor)** | 搭建题目、逻辑、评分与外观 |
| **[设置](/zh/editor/settings)** | 开放与权限、基本信息、答题体验、结果页跟进、语言、系统文案、分析 |
| **[记录](/zh/results/records)** | 查看每一份作答 |
| **[洞察](/zh/results/insights)** | 完成率、流失点与来源转化 |

**[分享](/zh/publish)** 是页签旁边的一个按钮,不是单独的页签。点开是 **分享测验**,分四块:**分享链接**(含二维码)、**分享卡片**、**网站嵌入** 和 **分发计划**(各渠道的链接与文案,还能用 **添加渠道** 加上你自己的来源)。

<Callout type="info">
  以前测评内有一个「连接 / 集成」页签,现在已经上移成团队级的 [连接](/zh/connectors)——配一次,所有测评共用,不必每张卷子重配。
</Callout>

<Callout type="info">
  控制台展示的是**当前所在团队**的测验。属于多个团队时,用左上角的团队切换器切换,列表会随之变化。
</Callout>
