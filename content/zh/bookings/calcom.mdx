**Cal.com 连接** 让 RooQuiz 能看到答题者从结果页约下的通话。它是团队级的连接,位于 **连接 → 预约通话** 分组,每个团队只能有**一个**。

<Callout type="warning">
  Cal.com 连接所有套餐都可用(包括免费版),但只有**团队所有者或管理员**能配置。[预约块](/zh/bookings/respondent) 本身不依赖它。
</Callout>

## 连接步骤

<Steps>
### 打开 Cal.com 卡片

进入 **连接**,在 **预约通话** 分组下找到 **Cal.com**,点 **连接 Cal.com**。

### 选择数据区域

按你的 Cal.com 账户所在地选择 **全球（cal.com）** 或 **欧盟（cal.eu）**。

### 授权

- **全球** —— 点 **前往 Cal.com 授权** 并同意访问。RooQuiz 只读取你的个人资料和预约类型,并添加一个 webhook,让预约自动同步回来。
- **欧盟**,或者你不想用 OAuth —— 选 **改用 API Key**。在 Cal.com 打开 **Settings → Developer → API keys**,新建一个永不过期的 Key,粘贴进来即可。
</Steps>

连接成功后,RooQuiz 会自动在你的 Cal.com 账户里注册 webhook,并拉取你的预约类型。删除这个连接时,webhook 也会一并移除。

## 在测评里挑选预约类型

连上之后,测评预约块里的 **Cal.com 预约链接** 字段会列出你的预约类型,直接选一个即可,不用再手动粘贴链接。如果刚在 Cal.com 新建了预约类型,点 **刷新预约类型**。

<Callout type="info">
  改期和取消都在 **Cal.com** 里完成 —— 由你操作,或由预约人通过 Cal.com 发出的邮件自行操作 —— 变更会同步回 RooQuiz。RooQuiz 这一侧不需要做任何管理。
</Callout>
