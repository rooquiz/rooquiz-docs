# 1:1 预约

测评做完、结果看完,是对方意愿最高的那一刻。**1:1 预约**让答题者能在结果页上直接约你一场会谈,不用跳去第三方日历工具、也不用来回发邮件对时间。

<Callout type="info">
  可约时间是**团队级**的资源:配置一次,所有测评共用。不需要给每张测评单独排一遍日程。
</Callout>

## 跑通它的三步

<Steps>
### 配置可约时间

在 **1:1 预约** 页打开 **可约时间**,设好时区、单次时长和每周可约时段。见 [可约时间设置](/zh/bookings/availability)。

### 在测评里开启预约块

到目标测评的 **分享 → 预约** 里打开 **在结果页展示预约块**。见 [答题者侧体验](/zh/bookings/respondent)。

### 在预约页处理约单

新的预约会出现在 **1:1 预约** 页。见 [管理预约](/zh/bookings/manage)。
</Steps>

<Callout type="warning">
  没配可约时间之前,即使打开了开关,结果页也**不会**显示预约块——设置页会直接告诉你这一点。
</Callout>

## 预约列表的三段

**1:1 预约** 页按处理顺序分成三段:

- **等你确认** —— 开启了预约审核时,待确认的申请排在最上面,因为它们卡着别人。
- **即将到来** —— 已确认、还没开始的会谈,最近的一场以大卡片形式突出显示并带倒计时。
- **已过去** —— 历史场次,默认折叠。

侧边栏的 **1:1 预约** 上会有一个角标,显示待确认的数量。

## 状态一览

| 状态 | 含义 |
| --- | --- |
| **待确认** | 对外提交的申请,等线索负责人确认(仅在开启预约审核时出现) |
| **已预约** | 已确认的会谈,对方已拿到会议地址 |
| **已完成** | 会谈已发生,你手动标记的 |
| **未出席** | 对方没来,你手动标记的 |
| **已取消** | 任意一方取消 |
| **已拒绝** | 你拒绝了这个申请 |
