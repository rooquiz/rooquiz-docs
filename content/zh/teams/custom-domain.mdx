# 自定义域名

默认情况下,测评的公开链接挂在平台域名下。配置**自定义域名**后,答题者看到的是你自己的域名——对品牌一致性和信任感都有帮助。

入口在 **设置 → 自定义域名**。

<Callout type="warning">
  自定义域名是 **Pro 套餐功能**。
</Callout>

## 配置步骤

<Steps>
### 填入你的域名

在设置页填写要使用的域名,比如 `quiz.yourbrand.com`。建议用子域名而不是主域名。

### 按 DNS 配置指引加解析

页面上的 **DNS 配置指引** 会给你一条要添加的记录,包含**类型 / 名称 / 值**三列。到你的域名 DNS 服务商那里原样添加。

### 等验证通过

回到设置页点 **刷新状态**。状态会在 **验证中 → 已验证** 之间流转,失败会显示 **验证失败**。
</Steps>

<Callout type="info">
  DNS 记录生效需要**几分钟到 48 小时**,取决于你的 DNS 服务商。刚配完没通过很正常,过一会儿再刷新。
</Callout>

## 状态说明

| 状态 | 含义 |
| --- | --- |
| **验证中** | 记录已提交,等待 DNS 生效与校验 |
| **已验证** | 域名可用,公开链接走你的域名 |
| **验证失败** | 没查到正确的解析记录,核对一下类型 / 名称 / 值是否与指引一致 |
| **已暂停** | Pro 套餐已过期 |

<Callout type="warning">
  Pro 过期后域名进入 **已暂停**:还有 **7 天宽限期**,之后自定义域名会停止解析。续费即可恢复,不必重新配置 DNS。
</Callout>
