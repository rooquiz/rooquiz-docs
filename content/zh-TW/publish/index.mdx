測驗搭建完成後,透過分享區域把它分發給答題者。RooQuiz 提供連結、QR Code、網站嵌入、社交卡片,以及為每個管道配好追蹤連結的分發計畫。

## 發佈前檢查清單

- 題目與邏輯已用**預覽**走查無誤。
- 評分 / 測評規則設定正確(如需要)。
- 外觀、封面與基本資訊已設定。
- 測驗已開啟：**設定 → 開放與權限 → 測驗開啟/關閉** 處於開啟狀態。

<Callout type="warning">
  如果答題者開啟連結卻無法作答，請檢查 **設定 → 開放與權限** 下的 **測驗開啟/關閉** 和 **填寫權限**。測驗關閉期間，分享對話框會顯示警告，連結、QR Code 和嵌入內容都會向訪客顯示「無法使用」頁面。
</Callout>
