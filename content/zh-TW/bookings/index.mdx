測評做完、結果看完,是對方意願最高的那一刻。**1:1 預約**讓答題者能在結果頁上直接約你一場會談,不用跳去第三方日曆工具、也不用來回發郵件對時間。

<Callout type="info">
  可約時間是**團隊級**的資源:設定一次,所有測評共用。不需要給每張測評單獨排一遍日程。
</Callout>

## 跑通它的三步

<Steps>
### 設定可約時間

在 **1:1 預約** 頁開啟 **可約時間**,設好時區、單次時長和每週可預約時段。見 [可約時間設定](/zh-TW/bookings/availability)。

### 在測評裡開啟預約區塊

到目標測評的 **分享 → 預約** 裡開啟 **在結果頁展示預約區塊**。見 [答題者側體驗](/zh-TW/bookings/respondent)。

### 在預約頁處理約單

新的預約會出現在 **1:1 預約** 頁。見 [管理預約](/zh-TW/bookings/manage)。
</Steps>

<Callout type="warning">
  沒配可約時間之前,即使開啟了開關,結果頁也**不會**顯示預約區塊——設定頁會直接告訴你這一點。
</Callout>

## 預約列表的三段

**1:1 預約** 頁按處理順序分成三段:

- **等你確認** —— 開啟了預約稽核時,待確認的申請排在最上面,因為它們卡著別人。
- **即將到來** —— 已確認、還沒開始的會談,最近的一場以大卡片形式突出顯示並帶倒數計時。
- **已過去** —— 歷史場次,預設摺疊。

側邊欄的 **1:1 預約** 上會有一個角標,顯示待確認的數量。

## 狀態一覽

| 狀態 | 含義 |
| --- | --- |
| **待確認** | 對外提交的申請,等線索負責人確認(僅在開啟預約稽核時出現) |
| **已預約** | 已確認的會談,對方已拿到會議地址 |
| **已完成** | 會談已發生,你手動標記的 |
| **未出席** | 對方沒來,你手動標記的 |
| **已取消** | 任意一方取消 |
| **已拒絕** | 你拒絕了這個申請 |
