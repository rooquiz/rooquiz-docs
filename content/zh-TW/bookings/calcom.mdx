**Cal.com 連接**讓 RooQuiz 能看到有人從你的結果頁約下的會談。它是團隊級連接，位於 **連接 → 預約會談**，每個團隊只能有**一個**。

<Callout type="warning">
  Cal.com 連接是 **Pro 方案** 功能，且只有**團隊所有者或管理員**能設定。[預約區塊](/zh-TW/bookings/respondent) 本身在免費版就能使用，不依賴這條連接。
</Callout>

## 連接步驟

<Steps>
### 開啟 Cal.com 卡片

進入 **連接**，在 **預約會談** 下找到 **Cal.com**，點 **連接 Cal.com**。

### 選擇資料區域

依你的 Cal.com 帳號所在地，選 **全球（cal.com）** 或 **歐盟（cal.eu）**。

### 授權

- **全球** —— 點 **前往 Cal.com** 並同意授權。RooQuiz 只讀取你的個人資料與事件類型，並新增一個 webhook 讓預約回流。
- **歐盟**，或你不想用 OAuth —— 選 **改用 API 金鑰**。在 Cal.com 開啟 **Settings → Developer → API keys**，建立一把永不過期的金鑰，貼上即可。
</Steps>

連接完成後，RooQuiz 會自動在你的 Cal.com 帳號裡註冊 webhook，並拉取你的事件類型。刪除這條連接時，webhook 也會一併移除。

## 在測評裡挑選事件類型

接好連接後，測評預約區塊裡的 **Cal.com 預約連結** 欄位會列出你的事件類型，直接挑一個即可，不必手動貼連結。如果你剛在 Cal.com 建了新的事件類型，點 **重新整理事件類型**。

## 方案變動

如果團隊降回免費版，連接會保留但**停止同步**：新的預約只留在 Cal.com 裡。重新升級後同步會恢復。無論哪種情況，結果頁上的預約區塊都照常運作。

<Callout type="info">
  改期與取消都在 **Cal.com** 裡進行——由你操作，或由預約人透過 Cal.com 寄出的郵件操作——並同步回 RooQuiz。RooQuiz 這一側不需要做任何管理。
</Callout>
