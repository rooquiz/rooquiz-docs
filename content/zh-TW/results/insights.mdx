數據洞察把零散的作答彙總成**統計與圖表**,幫助你快速把握整體情況,而無需逐條翻看記錄。

## 關鍵數字

頂部一排顯示 **今日提交**（與昨日相比）、**累計提交**、**獨立答題者**（僅統計已登入的答題者）、**平均得分**、**報告生成率**（已生成 / 失敗 / 產生中的報告）以及 **分享** 與分享率。

## 常見圖表

- **近 N 天提交趨勢**：作答量隨時間的變化。
- **題目答案分佈**：針對單選、下拉、判斷與評分題（最多 10 題），展示各選項的佔比。
- **來源管道**：配合 [UTM 來源追蹤](/zh-TW/publish/tracking)，對比不同管道帶來的作答量。
- **登入方式** 與 **裝置類型**：匿名與已註冊答題者的對比，以及 iOS / Android / 桌面的分佈。

## 轉化漏斗

**轉化漏斗**以**一次造訪（工作階段）**為單位，追蹤 **瀏覽 → 開始作答 → 提交 → 查看報告 → CTA 點擊**。有兩個階段只在適用時出現：**登入留資**（在提交之後），出現在設為 **看報告需留信箱**、或以前就有留資資料的測驗上；**分享**（在最後），出現在結果被分享過之後。各階段的口徑：

| 階段 | 何時計入 |
| --- | --- |
| 瀏覽 | 答題頁在瀏覽器中真正開啟(爬蟲與管理端預覽不計) |
| 開始作答 | 首次答了任意一題(不是點"開始"按鈕) |
| 提交 | 提交成功 |
| 登入留資 | 這次提交關聯到了某個答題者——他留了信箱或登入了 |
| 查看報告 | 報告生成完成且答題者停留在結果頁 |
| CTA 點擊 | 點擊了報告底部的 [CTA 按鈕](/zh-TW/results/reports#結果頁-cta-按鈕) |
| 分享 | 答題者點擊了結果頁上的分享按鈕（首次，任意管道） |

每個階段旁的百分比是**相對上一階段**的轉化率,可以直接看出衰減發生在哪一環。

### 流失點 Top 10

統計**未提交**且至少答過一題的工作階段,按"最後回答的那道題"分組——人數高的題目就是放棄的高發點,可能太難、太敏感,或它後面那道勸退了答題者。完全沒動筆就離開的人不在這裡,他們體現在"瀏覽 → 開始作答"的衰減中。

### 來源轉化

按連結上的 `utm_source` 分組(由[分發計畫](/zh-TW/publish/promotion)、[UTM 來源追蹤](/zh-TW/publish/tracking)或[網站嵌入](/zh-TW/publish/embed)的 UTM 屬性設定),對比各來源的瀏覽、開始、提交與完成率;來自網站嵌入的來源會帶**嵌入**標記。

<Callout type="info">
  漏斗自功能上線起統計,更早的歷史提交不會回填,因此初期"累計提交"可能大於漏斗中的提交數,執行一段時間後自然對齊。
</Callout>

## 使用建議

- 用**轉化漏斗**定位流失發生的環節:瀏覽多、開始少,問題在到達頁或第一題;開始多、提交少,看流失點 Top 10 找具體題目。
- 用**題目答案分佈**理解答題者的整體傾向。
- 結合時間趨勢與**來源轉化**評估各管道推廣活動的效果。

<Callout type="info">
  洞察看的是"群體趨勢"。如果你想深入某一份具體作答,請到 [答卷記錄](/zh-TW/results/records);如果想看測評的個體分析結論,請到 [測評報告](/zh-TW/results/reports)。
</Callout>
