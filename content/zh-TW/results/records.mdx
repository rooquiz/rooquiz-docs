答卷記錄是某個測評收到的**每一份作答**,在測評的 **記錄** 頁籤裡。這裡看的是原始資料——想看彙總趨勢去 [數據洞察](/zh-TW/results/insights)。

![RooQuiz 答卷記錄列表:篩選器與答卷表格](/img/en/results/records-list.webp)

## 篩選器

點 **篩選** 開啟篩選器,可以疊加多個條件(彼此是「且」的關係):

| 可篩欄位 | 說明 |
| --- | --- |
| **按題目篩** | 直接按某道題的答案篩,選項類支援「是其中之一 / 不是其中之一 / 為空 / 不為空」 |
| **答題者** | 指定某個人的作答 |
| **UTM 來源** | 從哪個管道來的,配合 [UTM 追蹤](/zh-TW/publish/tracking) |
| **得分** | 按分數區間(**介於** 最小值與最大值) |
| **等級** | 落在哪個報告等級 |
| **語言** | 用哪個 [語言版本](/zh-TW/editor/translations) 作答的 |
| **線索狀態 / 負責人** | 按 [線索](/zh-TW/leads) 的跟進狀態或負責人篩 |
| **提交時間** | 起止日期 |

條件配好點 **套用**,不要了點 **清除全部**。

<Callout type="info">
  記錄頁沒有看板檢視——看板在 [線索](/zh-TW/leads/list-board) 頁。兩者關注點不同:記錄是**一份份答卷**,線索是**一個個人**。
</Callout>

## 單份記錄詳情

點開任意一條,詳情分左右兩塊:

- **左側** —— 逐題的作答內容與得分,以及報告。
- **右側** —— 這個人作為 [線索](/zh-TW/leads) 的跟進側欄:改跟進狀態、寫**評論**、看合併後的動態時間軸。

也就是說,你在看答卷的同時就能完成跟進,不必再跳去線索頁。

<Callout type="info">
  評論支援**回覆**,自己寫的可以刪。這些評論與 [線索詳情](/zh-TW/leads/detail) 裡的是同一份,兩邊都能看到。
</Callout>

## 記錄裡包含什麼

除作答內容外,一條記錄通常還帶:

- **序號** —— 測評內遞增的作答編號。
- **答題者** —— 登入後提交才有;匿名提交這一列為空。
- **來源資訊** —— 透過 [UTM 連結](/zh-TW/publish/tracking) 提交時記錄對應來源。
- **提交時間**、**語言版本**、**得分與等級**。

## 匯出

工具列上的 **匯出** 支援匯出選中的幾條,或匯出目前篩選條件下的全部資料。全量匯出佔用每週額度,詳見 [匯出資料](/zh-TW/results/export)。

<Callout type="warning">
  匯出的資料可能包含答題者填寫的個人資訊,請按你所在組織的隱私與合規要求妥善保管。
</Callout>
