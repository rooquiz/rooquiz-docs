**稽核日誌**記錄團隊裡發生過的關鍵操作:誰、在什麼時候、對什麼物件、做了什麼、成功還是失敗。入口在 **設定 → 稽核日誌**。

<Callout type="warning">
  **只有團隊擁有者與管理員能檢視稽核日誌。**成員和檢視者開啟會看到提示。
</Callout>

## 表格裡的列

| 列 | 說明 |
| --- | --- |
| **操作** | 做了什麼,如「邀請成員」「刪除測評」「匯出資料」 |
| **狀態** | 成功 / 失敗 |
| **操作人** | 誰做的。系統自動發起的操作(如到期清理、稽核封禁)顯示為**系統** |
| **物件** | 被操作的東西及其 ID 前綴 |
| **時間** | 發生時間 |

點擊任意一行可以展開**詳情**,不同操作帶的欄位不一樣——比如匯出會額外記錄匯出的資料類型(答卷 / 線索 / 答題者)和行數。

## 覆蓋哪些操作

大致分這幾類:

- **團隊** —— 刪除團隊、轉讓所有權、方案變更。
- **成員** —— 邀請、移除、離開、改角色、停用 / 啟用。
- **測評** —— 建立、更新、移入回收站、恢復、徹底刪除、封禁 / 解封。
- **線索與答題者** —— 移入回收站、恢復、徹底刪除。
- **連接** —— 建立、更新、刪除。
- **憑證** —— API 金鑰與 MCP 權杖的建立、撤銷、恢復、刪除。
- **用量** —— AI 消耗、郵件消耗、[資料匯出](/zh-TW/results/export)。

頂部可以按**操作類型**和**狀態**篩選,便於回答「上週誰匯出過資料」這類問題。

<Callout type="info">
  日誌是**唯讀**的,不能編輯或刪除——能被改的稽核日誌沒有意義。
</Callout>
