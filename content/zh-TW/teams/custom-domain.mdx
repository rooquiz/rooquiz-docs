預設情況下,測評的公開連結掛在平台網域下。設定**自訂網域**後,答題者看到的是你自己的網域——對品牌一致性和信任感都有幫助。

入口在 **設定 → 自訂網域**。

<Callout type="warning">
  自訂網域是 **Pro 方案功能**。
</Callout>

## 設定步驟

<Steps>
### 填入你的網域

在設定頁填寫要使用的網域,比如 `quiz.yourbrand.com`。建議用子網域而不是主網域。

### 按 DNS 設定指引加解析

頁面上的 **DNS 設定指引** 會給你一條要新增的記錄,包含**類型 / 名稱 / 值**三列。到你的網域 DNS 服務供應商那裡原樣新增。

### 等驗證通過

回到設定頁點 **重新整理狀態**。狀態會在 **驗證中 → 已驗證** 之間流轉,失敗會顯示 **驗證失敗**。
</Steps>

<Callout type="info">
  DNS 記錄生效需要**幾分鐘到 48 小時**,取決於你的 DNS 服務供應商。剛配完沒通過很正常,過一會兒再重新整理。
</Callout>

## 狀態說明

| 狀態 | 含義 |
| --- | --- |
| **驗證中** | 記錄已提交,等待 DNS 生效與校驗 |
| **已驗證** | 網域可用,公開連結走你的網域 |
| **驗證失敗** | 沒查到正確的解析記錄,核對一下類型 / 名稱 / 值是否與指引一致 |
| **已暫停** | Pro 方案已過期 |

<Callout type="warning">
  Pro 過期後網域進入 **已暫停**:還有 **7 天寬限期**,之後自訂網域會停止解析。續費即可恢復,不必重新設定 DNS。
</Callout>
