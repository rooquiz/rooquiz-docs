登入後進入**控制台**,這裡集中展示你與團隊的全部測評,是日常管理的起點。

![RooQuiz 控制台:左側導覽欄與測驗列表](/img/en/getting-started/dashboard.webp)

## 頁面主體

- **建立入口** —— 頂部三張卡片對應 [建立知識測驗 / 建立評分測驗 / 建立分型測驗](/zh-TW/getting-started/create-quiz)。
- **分組標籤** —— **全部**、**我的收藏**,以及你自建的分組，旁邊是 **建立分組**。見 [工作區](/zh-TW/getting-started/workspace)。
- **測驗卡片** —— 每張卡顯示類型角標、封面、標題、建立日期和答卷數,底部是編輯、記錄、更多三個快捷入口。

## 左側導覽

| 入口 | 作用 |
| --- | --- |
| **我的測驗** | 就是目前這一頁 |
| **[題庫](/zh-TW/library/question-banks)** | 可複用的題目池 |
| **[答題者](/zh-TW/respondents)** | 做過你測評的人的檔案 |
| **[線索](/zh-TW/leads)** | 留過聯絡方式的人的跟進管道 |
| **[1:1 預約](/zh-TW/bookings)** | 結果頁約來的會談,帶待確認角標 |
| **[連接](/zh-TW/connectors)** | 團隊級的推送管道,**僅所有者與管理員可見** |

頂部的搜尋框跨測評、題庫、答題者、線索全域查詢;底部可以**收合側邊欄**。

<Callout type="info">
  **線索** 和 **1:1 預約** 是團隊可選的 **功能模組**。團隊所有者可以在團隊設定的 **基本資訊** 裡關閉其中任意一個。關閉的模組會從所有成員的側邊欄和相關頁面中消失，也不再產生新資料。已有資料會保留，重新開啟後就會回來；已排好的預約不會被取消。
</Callout>

## 拿到你的第一條線索

新團隊會在控制台看到一份 **拿到你的第一條線索** 清單：從零到第一份提交，一共四步。

1. **建立第一個測評** —— 從範本開始，計分、結果頁和留資牆都已預先接好。
2. **發布上線** —— 打開你的測評，把它切換為上線狀態。
3. **把連結發出去** —— 在 **分享** 裡拿到連結或嵌入程式碼；個人簡介連結、你的網站或社群貼文都行。
4. **收到第一條提交** —— 有人做完你的測評後，答案和聯絡方式會出現在 **記錄** 裡。

收到第一份提交後，清單會變成 **跑起來了！**。你隨時可以點 **隱藏** 收起這份清單。

## 單個測驗的功能入口

進入某個測驗後有四個頁籤:

| 頁籤 | 作用 |
| --- | --- |
| **[編輯](/zh-TW/editor)** | 搭建題目、邏輯、評分與外觀 |
| **[設定](/zh-TW/editor/settings)** | 開放與權限、基本資訊、作答體驗、結果頁跟進、語言、系統文案、分析 |
| **[記錄](/zh-TW/results/records)** | 檢視每一份作答 |
| **[洞察](/zh-TW/results/insights)** | 完成率、流失點與來源轉化 |

**[分享](/zh-TW/publish)** 是頁籤旁邊的一個按鈕，而不是單獨的頁籤。點開是 **分享測驗**，分四個區塊：**分享連結**（含 QR Code）、**分享卡片**、**網站嵌入** 和 **分發計畫**（各管道的連結與文案，以及用來新增自有來源的 **新增渠道**）。

<Callout type="info">
  以前測評內有一個「連接 / 整合」頁籤,現在已經上移成團隊級的 [連接](/zh-TW/connectors)——配一次,所有測評共用,不必每張卷子重配。
</Callout>

<Callout type="info">
  控制台展示的是**目前所在團隊**的測驗。屬於多個團隊時,用左上角的團隊切換器切換,列表會隨之變化。
</Callout>
