登入後進入**控制台**,這裡集中展示你與團隊的全部測評,是日常管理的起點。

![RooQuiz 控制台:左側導覽欄與測驗列表](/img/zh/getting-started/dashboard.webp)

## 頁面主體

- **建立入口** —— 頂部三張卡片對應 [建立測驗 / 建立評分測驗 / 建立分型測驗](/zh-TW/getting-started/create-quiz)。
- **分組標籤** —— **全部**、**我的收藏**,以及你自建的分組,見 [工作區](/zh-TW/getting-started/workspace)。
- **測驗卡片** —— 每張卡顯示類型角標、封面、標題、建立日期和答卷數,底部是編輯、記錄、更多三個快捷入口。

## 左側導覽

| 入口 | 作用 |
| --- | --- |
| **我的測驗** | 就是目前這一頁 |
| **[題庫](/zh-TW/library/question-banks)** | 可複用的題目池 |
| **[答題者](/zh-TW/respondents)** | 做過你測評的人的檔案 |
| **[線索](/zh-TW/leads)** | 留過聯絡方式的人的跟進管道 |
| **[1:1 預約](/zh-TW/bookings)** | 結果頁約來的會談,帶待確認角標 |
| **[連接](/zh-TW/connectors)** | 團隊級的推送管道,**僅所有者與管理員可見** |

頂部的搜尋框跨測評、題庫、答題者、線索全域查詢;底部可以**收合側邊欄**。

## 單個測驗的功能入口

進入某個測驗後有四個頁籤:

| 頁籤 | 作用 |
| --- | --- |
| **[編輯](/zh-TW/editor)** | 搭建題目、邏輯、評分與外觀 |
| **[分享](/zh-TW/publish)** | 公開連結、QR Code、嵌入、社交卡片、來源追蹤、預約區塊、推廣工具包 |
| **[記錄](/zh-TW/results/records)** | 檢視每一份作答 |
| **[洞察](/zh-TW/results/insights)** | 完成率、流失點與來源轉化 |

<Callout type="info">
  以前測評內有一個「連接 / 整合」頁籤,現在已經上移成團隊級的 [連接](/zh-TW/connectors)——配一次,所有測評共用,不必每張卷子重配。
</Callout>

<Callout type="info">
  控制台展示的是**目前所在團隊**的測驗。屬於多個團隊時,用左上角的團隊切換器切換,列表會隨之變化。
</Callout>
