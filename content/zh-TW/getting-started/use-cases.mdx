下面每種做法都會寫明要選的測驗類型，以及讓它真正發揮作用的那幾項設定。只要控制台 **你想做什麼？** 卡片裡有接近的範本，就從範本開始——見 [建立測驗](/zh-TW/getting-started/create-quiz)。

## 收集線索的評估診斷

*「你的企業為 X 準備好了嗎？」——用一個分數換來一次銷售對話。*

1. 卡片：**評估診斷**（評分測驗）。為每個選項設定分數，總分就是它們的加總。想用雷達圖呈現多個面向，就加上 [維度](/zh-TW/editor/scoring#scored-quiz維度分析)。
2. 把總分切成 [等級](/zh-TW/editor/scoring#等級與結果頁行動)，給低分段和中間段配一個 **CTA 按鈕**，例如「預約通話」。
3. **設定 → 開放與權限 → 看報告需留信箱**，讓每一份完成的作答都變成一條 [線索](/zh-TW/leads)。
4. 在結果頁加上 [預約區塊](/zh-TW/bookings)，並為每個等級設定一封 [按結果發送的郵件](/zh-TW/editor/settings#結果頁跟進)。
5. 在 [數據洞察](/zh-TW/results/insights) 裡看漏斗——答題者在哪裡流失、有多少人點了 CTA。

## 產品或課程推薦

*「哪門課最適合你？」——為每個人配對一個方案。*

1. 卡片：**產品 / 課程推薦**（分型測驗）。每個產品或課程建立一個結果類型。
2. 讓每個選項投票給它指向的結果類型，得票最多的類型勝出。用 [條件邏輯](/zh-TW/editor/logic) 跳過不相關的題目。
3. 給每個結果類型一個連到產品頁的 CTA——或者在 Pro 方案下，帶著結果參數直接 [跳轉](/zh-TW/editor/scoring#提交後跳轉pro) 過去。
4. 在 [Kit](/zh-TW/connectors/channels#kit) 裡按結果為訂閱者打標籤，讓每個結果類型各自啟動一組郵件序列。

<Callout type="info">
  推薦類和分級類測驗請保持 **群體對照** 關閉：看到多數人選了什麼，會把後面的答題者推向同一個選項。
</Callout>

## 程度測驗

*語言學校或培訓課程的分級測驗。*

1. 卡片：**程度測驗**。回答 **題目有標準答案嗎？**——題目有對錯就選 **有**（知識測驗），答題者自我評估就選 **沒有**（評分測驗）。
2. 設定 A1–C2 之類的 [等級](/zh-TW/editor/scoring#等級與結果頁行動)，給每個等級一個連到對應班級或試聽課的 CTA。**等級順序 → 高 → 低** 會把最高等級排在最前面。
3. 保持 [即時回饋](/zh-TW/editor/settings#作答體驗) 關閉——它會逐頁揭示答案。
4. 發送一封 [按結果發送的郵件](/zh-TW/editor/settings#結果頁跟進) 作為跟進，推薦合適的班級。

## 可分享的人格測驗

*「你是哪一種 X？」——為傳播而生。*

1. 卡片：**人格測驗**（分型測驗）。給每個結果類型一個響亮的名字、圖片和描述。
2. 保持 **結果頁分享** 開啟，並檢查 [分享卡片](/zh-TW/publish/og)——結果被貼出去時，大家看到的就是它。
3. 開啟 [群體對照](/zh-TW/editor/settings#作答體驗)，讓答題者看到「62% 的人和你選的一樣」。
4. 挑一套開始頁有吸引力的 [設計](/zh-TW/editor/design)；填寫權限用 **完全公開**，把門檻降到最低。

## 知識挑戰

*好玩、能互相較量的知識問答。*

1. 卡片：**知識挑戰**（知識測驗）。標出正確答案並設定分值。
2. 加上 [限時答題](/zh-TW/editor/settings#作答體驗)，並開啟 **即時回饋**，邊答邊學。
3. 用等級給每個分數段一個值得分享的有趣稱號。

## AI 撰寫的個人診斷

*履歷健檢、口說評估、企業診斷——為每位答題者寫一份個人報告。*

1. 卡片：**AI 個人化報告**（AI 測評）。加入題目；如果要讓 AI 審閱真實作品，再加一道附件上傳題。
2. 撰寫 [產生說明](/zh-TW/editor/ai-report#撰寫產生說明)，並選擇報告篇幅。
3. 加上 *可成交* / *需培育* / *時機未到* 之類的 [結果標籤](/zh-TW/editor/ai-report#結果標籤)，每個標籤配一個 CTA，再把它們分流到你的連接。
4. 使用 **看報告需留信箱**：只有留下信箱的人才會產生報告——也只有這時才會消耗 AI 點數。
