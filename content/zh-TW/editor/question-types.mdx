RooQuiz 提供 14 種以上題型。下面按用途分組介紹,幫助你為每道題挑選合適的形式。

## 選擇類

| 題型 | 說明 | 常見用途 |
| --- | --- | --- |
| **單選** | 一組選項中只能選一個 | 單選知識題、滿意度單選 |
| **多選** | 一組選項中可選多個 | 多選題、興趣偏好 |
| **下拉** | 以下拉式清單呈現的單選 | 選項較多時節省空間 |
| **級聯** | 多級聯動選擇(如省-市-區) | 地區、分類等層級選擇 |
| **判斷** | 對 / 錯 二選一 | 是非題 |
| **輪播** | 以圖片輪播方式選擇 | 圖片偏好、視覺化選項 |

## 輸入類

| 題型 | 說明 | 常見用途 |
| --- | --- | --- |
| **填空** | 文字輸入 | 簡答、開放性回答、「其他,請說明」 |
| **數字** | 數值輸入(可校驗) | 年齡、金額、數量 |
| **日期** | 日期選擇器 | 出生日期、預約日期 |
| **時間** | 時間選擇器 | 時間段、時刻 |

## 評價與排序類

| 題型 | 說明 | 常見用途 |
| --- | --- | --- |
| **評分** | 按量表評分(如 1–5 / 1–10) | 滿意度、重要性評分 |
| **排序** | 拖曳對若干項排序 | 優先順序、偏好排序 |

## 內容與特殊類

| 題型 | 說明 | 常見用途 |
| --- | --- | --- |
| **說明** | 僅展示文字/說明,不收集作答 | 分節說明、指引、宣告 |
| **隨機題** | 從題庫隨機抽取題目 | 配合「隨機題庫」類型 |

## 哪種測驗能用哪些題型

題型不是每種測驗都通用——有的題型天生沒有"正確答案",有的沒法給結果類型投票。編輯器左欄只會列出目前測驗類型能用的題型。

| 題型 | 知識測驗 | 評分測驗 | 分型測驗 |
| --- | --- | --- | --- |
| 單選 / 多選 / 下拉 / 判斷 | ✅ | ✅ | ✅ |
| 填空 | ✅ 可配正確答案判分 | ✅ **僅收集,不計分** | ❌ |
| 數字 | ✅ 可配正確答案判分 | ✅ 作答數值進公式 | ❌ |
| 級聯 / 評分 | ❌ | ✅ | ❌ |
| 日期 / 時間 | ❌ | ✅ 僅收集 | ❌ |
| 排序 | ✅ | ❌ | ❌ |
| 說明 / 輪播 / 分頁符 | ✅ | ✅ | ✅ |

**Random Knowledge Quiz 隨機題庫**只用隨機題與展示類題型,題目本身來自關聯的題庫。

<Callout type="info">
  評分測驗裡的**填空題只收集文字**:它不產生分數,也不能被評分公式引用。適合在計分題之後追問一句"還有什麼想讓我們知道的",把開放性線索一起收上來。
</Callout>

<Callout type="info">
  每種題型在右側設定面板中都有各自的設定項,常見包括:題目標題與描述、是否必答、選項內容、校驗規則等。帶評分能力的題型還可設定分值(詳見 [評分與測評規則](/zh-TW/editor/scoring))。
</Callout>

<Callout type="warning">
  **隨機題**通常用於「Random Knowledge Quiz 隨機題庫」類型,需要先關聯題庫;在其他類型中可能不適用。
</Callout>
