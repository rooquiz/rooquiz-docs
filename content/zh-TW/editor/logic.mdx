條件邏輯讓測評根據答題者的作答**動態顯示或隱藏後續題目**,做出"千人千面"的自適應問卷。

<Callout type="warning">
  條件邏輯只在 **Scored Quiz 評分測驗** 與 **Outcome Quiz 分型測驗** 裡可用。Quiz 與 Random Knowledge Quiz 的編輯器右欄沒有「規則」頁籤。
</Callout>

## 一條規則長什麼樣

規則讀起來就是一句話:**如果 …… 則 顯示 / 隱藏 某道題**。

在編輯器右欄的 **規則** 頁籤點 **+ 新增規則**,逐項填:

| 組成 | 說明 |
| --- | --- |
| **如果** | 選一道**前置題目**、一個運算子、一個值 |
| **且** | 可以繼續 **新增條件**;同一條規則裡的多個條件是「且」的關係,要全部滿足 |
| **則** | 選 **顯示** 或 **隱藏**,再選**目標題目** |

一份測評裡可以有多條規則,介面上按 **規則 1 / 規則 2** 依次排列。

## 可用的運算子

| 運算子 | 適用 |
| --- | --- |
| **等於** | 單選、判斷 |
| **包含任一 / 不包含任一** | 多選——命中所選選項中的任意一個即成立 |
| **大於 / 大於等於 / 小於 / 小於等於 / 介於** | 數字類作答 |

判斷題的取值是 **✓ 正確** 與 **✗ 錯誤** 兩項。

<Callout type="info">
  能當**條件**的是有確定取值的題(選擇類、判斷、評分、數字);能當**目標**的範圍更寬,填空題、說明、輪播也可以被顯示/隱藏——「選了『其他』才追問一句『請說明』」就是這麼配的。
</Callout>

## 設定步驟

<Steps>
### 先把題目搭齊

規則引用的是具體題目,題目不存在就沒法選。先把前置題和目標題都建出來。

### 新增規則

選前置題 → 選運算子 → 選值 → 選顯示還是隱藏 → 選目標題。沒填完就儲存會提示 **請完整填寫規則**。

### 用預覽走查

按不同答案各走一遍,確認該出現的出現、該藏的藏住。規則一多,只靠腦補很容易漏掉某條路徑。
</Steps>

## 注意事項

- 觸發條件請引用**排在目標題之前**的題目——引用後面的題目,答題者還沒答到,條件無從判定。
- 被隱藏的題目不會展示給答題者,**也不參與必填校驗**,不會卡住提交。
- 刪除規則會二次確認,刪掉之後目標題恢復為預設顯示。

<Callout type="info">
  隱藏題目會影響評分:沒展示的題目自然沒有作答,也就不貢獻分數。設計自適應問卷時,記得讓 [評分規則](/zh-TW/editor/scoring) 與可能被隱藏的題目對得上。
</Callout>
