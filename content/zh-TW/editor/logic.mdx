條件邏輯讓測評根據答題者的作答**動態顯示或隱藏後續題目**,做出"千人千面"的自適應問卷。

<Callout type="info">
  條件邏輯在 **Scored Quiz 評分測驗** 與 **Outcome Quiz 分型測驗** 中可用。Knowledge Quiz 知識測驗與 AI 測評的編輯器右欄沒有「規則」頁籤——隱藏題目會改變知識測驗的滿分與正確率口徑。
</Callout>

## 一條規則長什麼樣

規則讀起來就是一句話:**如果 …… 則 顯示 / 隱藏 某道題**。

在編輯器右欄的 **規則** 頁籤點 **+ 新增規則**,逐項填:

| 組成 | 說明 |
| --- | --- |
| **如果** | 選一道**前置題目**、一個運算子、一個值 |
| **且** | 可以繼續 **新增條件**;同一條規則裡的多個條件是「且」的關係,要全部滿足 |
| **則** | 選 **顯示** 或 **隱藏**,再選**目標題目** |

一份測評裡可以有多條規則,介面上按 **規則 1 / 規則 2** 依次排列。

## 可用的運算子

| 運算子 | 適用 |
| --- | --- |
| **等於** | 單選、判斷 |
| **包含任一 / 不包含任一** | 多選——命中所選選項中的任意一個即成立 |
| **大於 / 大於等於 / 小於 / 小於等於 / 介於** | 數字類作答 |

判斷題的取值是 **✓ 正確** 與 **✗ 錯誤** 兩項。

<Callout type="info">
  能當**條件**的是有確定取值的題（單選、多選、下拉、判斷、評分、數字）；能當**目標**的範圍更寬，填空題、富文本與圖片輪播區塊也可以被顯示/隱藏——「選了『其他』才追問一句『請說明』」就是這麼配的。
</Callout>

## 設定步驟

<Steps>
### 先把題目搭齊

規則引用的是具體題目,題目不存在就沒法選。先把前置題和目標題都建出來。

### 新增規則

選前置題 → 選運算子 → 選值 → 選顯示還是隱藏 → 選目標題。沒填完就儲存會提示 **請完整填寫規則**。

### 用預覽走查

按不同答案各走一遍,確認該出現的出現、該藏的藏住。規則一多,只靠腦補很容易漏掉某條路徑。
</Steps>

## 注意事項

- 觸發條件請引用**排在目標題之前**的題目——引用後面的題目,答題者還沒答到,條件無從判定。
- 被隱藏的題目不會展示給答題者,**也不參與必填校驗**,不會卡住提交。
- 刪除規則會二次確認,刪掉之後目標題恢復為預設顯示。

<Callout type="info">
  隱藏題目會影響結果。在 **評分測驗** 裡,沒展示的題目自然沒有作答,也就不貢獻分數,記得讓 [評分規則](/zh-TW/editor/scoring) 與可能被隱藏的題目對得上。在 **分型測驗** 裡,被隱藏的題目不會投票,所以用了規則的測評改按**得票率**判型,見下文。
</Callout>

## 分型測驗:按得票率判型

不用規則時,分型測驗取票數最高的類型。用了規則之後,不同答題者看到的題目不同,追問支線較長的類型可能只因為多拿了幾票就勝出。所以用了規則的測評比較的是每個類型**在該答題者實際看到的題目裡能拿到的票中,拿到了多少比例**:

- 得票率 = (得票 + 0.5) ÷ (能拿到的票 + 1)。這一點平滑能防止只有一道題投給它的類型憑 1/1 勝出。
- 沒有任何可見題目投給它的類型記 0。
- 得票率相同時先比原始票數,再按結果類型列表順序。

編輯器會在結果類型下方執行 **類型覆蓋檢查**,遍歷所有作答路徑:標出永遠判不中的類型,並列出某個類型一票都拿不到的路徑。它只提示、不擋儲存,但被標出的類型通常代表某條支線需要一道給它投票的題目。
