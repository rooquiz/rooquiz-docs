線索多起來之後,每天真正要看的往往只是其中一小撮。**篩選**負責圈出這一撮,**儲存檢視**負責讓你明天不用再圈一次。

## 可用的篩選條件

點頁面上的 **篩選** 開啟篩選器,可以按這些欄位組合:

| 欄位 | 說明 |
| --- | --- |
| **搜尋** | 按答題者姓名或電子郵件模糊符合 |
| **建立時間** | 全部時間 / 今天 / 本週 / 本月 / 自訂區間 |
| **跟進狀態** | 選一個或多個狀態 |
| **標記** | 命中任意一個所選標記即算符合 |
| **負責人** | 指派給某個成員的線索 |
| **預約** | 有未開始的預約 / 沒有未開始的預約 |

<Callout type="info">
  「本週」按**週一**起算,「今天 / 本週 / 本月」都用**你瀏覽器所在時區**判定,不是團隊時區。
</Callout>

已生效的條件會以小標籤的形式排在頁面頂部,點標籤上的叉即可單獨去掉某一條。

## 儲存為檢視

把一組常用條件存下來,下次一鍵切回:

<Steps>
### 先調好篩選條件

在篩選器裡選好狀態、標記、負責人等,確認列表裡是你想要的那批人。

### 點「新增檢視」

給它起個一眼能認出來的名字,比如「本週待回訪的高意向」。名字最長 50 個字元。

### 之後在頁頂切換

儲存後的檢視會和 **全部**、**我的線索** 並排出現在頁面頂部,點一下即可切換。
</Steps>

內建的兩個檢視不用自己建:

- **全部** —— 不帶任何條件。
- **我的線索** —— 指派給你自己的線索。

<Callout type="info">
  檢視是**私人的**,只有你自己看得到,不會影響同事。檢視裡存的只是篩選條件,不是線索快照——資料變了,檢視裡的內容跟著變。
</Callout>

<Callout type="warning">
  刪除檢視只刪這組儲存的篩選條件,**不動任何線索**。檢視數量有上限,超出時會提示。
</Callout>
