**線索** 頁有兩種檢視,右上角的 **列表 / 看板** 開關隨時切換。切換只影響你自己,不會改變別人看到的樣子。

![RooQuiz 線索列表:答題者、跟進狀態、標記、負責人等列](/img/zh/leads/leads-list.webp)

## 列表檢視

適合**批次處理**和按欄位排序。表格包含這些列:

| 列 | 含義 |
| --- | --- |
| **答題者** | 姓名與電子郵件,點擊進入 [線索詳情](/zh-TW/leads/detail) |
| **跟進狀態** | 目前處在管道的哪一檔,見 [狀態、標記與負責人](/zh-TW/leads/status-tags) |
| **標記** | 彩色標記,可以同時掛多個 |
| **負責人** | 指派給哪個團隊成員 |
| **答卷數** | 這個人一共提交過幾份測評 |
| **下一場預約** | 最近一場未開始的 [預約](/zh-TW/bookings),沒有則留空 |
| **最近提交** | 最後一次提交的時間 |
| **首次來源** | 第一次留資的那張測評 |

列表是**無限捲動**的,往下捲自動載入更多;點列頭可以排序。

## 看板檢視

按**跟進狀態分列**,每個狀態一列,卡片可以直接拖到另一列完成狀態變更。適合每天過一遍管道、推進階段。

<Callout type="info">
  拖曳卡片同時改變它在列內的**位置**——順序會被記住,可以把今天要打的電話拖到最上面。
</Callout>

## 批次操作

在列表檢視勾選多條線索,頂部會出現批次操作條:

- **批次指派負責人** —— 一次把選中的線索交給某個成員,對方只收到一條彙總通知。
- **批次加標記** —— 分為**新增標記**和**移除標記**兩種模式。批次場景請用這兩種,不要用「替換」,否則會把別人打的標記一起洗掉。
- **移入回收站** —— 線索進入回收站,**5 天內可恢復**。

<Callout type="warning">
  三個批次操作**每次最多 50 條**。選超了會提示,分批處理即可。
</Callout>

<Callout type="info">
  移入回收站刪的只是**線索這條跟進記錄**,答題者本人與他提交的答卷都不受影響。要連人一起刪,去 [答題者](/zh-TW/respondents) 頁操作。
</Callout>
