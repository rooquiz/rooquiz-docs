# Question Banks & Templates

Both are reuse mechanisms, but they reuse different things:

| | Question bank | Template |
| --- | --- | --- |
| Reuses | A pool of **questions to draw from repeatedly** | A **complete quiz structure** |
| How you use it | Draw random questions when building a quiz | Clone it into a new quiz, then edit |
| Good for | Testing the same material over and over | Running the same assessment for different clients |

<Callout type="info">
  If you're unsure: **the questions should differ each time → question bank; the quiz is the same and only the audience changes → template.**
</Callout>

## Question banks

A question bank is your team's own pool of questions, each with a correct answer. Choose random draw when building a quiz and the system pulls a different set each time — good for practice quizzes and knowledge checks.

See [Question Banks](/en/library/question-banks).

## Templates

The Template Center holds complete quizzes you can clone. Start fast from an official template, or publish a quiz you're proud of as a template for your team to reuse.

See [Template Center](/en/library/templates).
