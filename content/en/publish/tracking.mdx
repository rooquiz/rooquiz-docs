When you distribute the same quiz across multiple channels, **UTM source tracking** helps you tell where each response came from, so you can evaluate each channel's effectiveness.

## What is UTM

UTM is a set of parameters appended to a link to label its traffic source. Common ones include:

- **Source**: e.g. `facebook`, `linkedin`, `x`, `newsletter`.
- **Medium**: e.g. `post`, `bio`, `email`, `cpc`.
- **Campaign**: the name of this campaign, e.g. `spring-launch`.

## How to use it

In the target quiz, open **Share** → **Distribution plan**. Every built-in channel card already has its own UTM-tagged link. For any other channel, click **Add a channel** and fill in **utm_source** (required), **utm_medium** and **utm_campaign** (both optional); the new card gets its own tracked link. See [Distribution Plan](/en/publish/promotion).

UTM values may only contain letters, digits, underscores and hyphens.

Website embeds can carry UTM tags too — see the `data-rooquiz-utm-*` attributes in [Embed](/en/publish/embed#available-attributes).

## Viewing source data

When respondents submit via a UTM-tagged link, the source is recorded with the response. UTM parameters on any link (`utm_source`, `utm_medium`, `utm_campaign`) are saved this way, whether the link came from the Distribution plan or you built it by hand. You can distinguish and analyze by source in [Response Records](/en/results/records) and [Insights](/en/results/insights).

<Callout type="info">
  Using **clear, consistent naming** for each channel (e.g. all lowercase, hyphen-separated) keeps your later analysis tidy.
</Callout>

## URL parameters (hidden fields)

UTM tags cover channels. To capture anything else from the link — which **partner**, **campaign ID** or **landing page** sent the respondent — declare your own URL parameters.

<Steps>
### Declare the parameters

On the quiz, open **Settings → Analytics → URL parameters** and add the names, for example `partner` and `campaign_id`. Use lowercase letters, digits and underscores, up to 10 per quiz. `utm_*` and system names such as `email`, `name`, `lang` and `ref` are reserved.

### Add them to your link

Append the values to the quiz link: `https://YOUR_QUIZ_LINK?partner=acme&campaign_id=spring`.
</Steps>

The values are saved with each response and appear in [Response Records](/en/results/records) details, in exports (one column per parameter), and in webhook and Zapier payloads under `metadata.params`. Only declared parameters are kept; anything else on the link is ignored. Values are trimmed to 256 characters. Available on every plan.

<Callout type="info">
  Share links created from the result page don't carry these parameters, so a friend's response isn't credited to the original partner or campaign.
</Callout>

## Prefill the lead form from a link

Add `?email=` (and optionally `?name=`) to a quiz link — for example in a newsletter — and the lead form before the report is filled in for the respondent. It only saves typing: the respondent still verifies their email as usual. The values are removed from the address bar as soon as the page loads, before Google Analytics or any ad pixel can see them.

<Callout type="warning">
  The email address travels in the link itself, so it can end up in server logs, browser history and anywhere the link is forwarded. Use prefill links only in one-to-one channels such as an email to that person — never on a public page or in an ad.
</Callout>
