This section is for **developers** — how to reach RooQuiz from your own code or an AI client:

<Cards>
  <Card title="REST API" href="/en/integrations/rest-api" />
  <Card title="MCP Integration" href="/en/integrations/mcp" />
</Cards>

- **REST API** — pull forms and submissions with an account-level API key. Good for your own dashboards or syncing to a warehouse. An OpenAPI spec is included.
- **MCP integration** — connect an AI client like ChatGPT or Claude to your team so it can create, query and modify quizzes, work your leads (status, owner, tags, comments) and handle bookings directly.

<Callout type="info">
  RooQuiz has no built-in AI quiz generator. To build a quiz with AI, connect **your own AI client** over [MCP](/en/integrations/mcp) and ask it to — for example, to start from a template and add questions.
</Callout>

## Integrating without code

If all you want is "tell me when a lead arrives" or "sync leads into my email tool", **you don't need the API**. Use one of the five channels in [Connectors & Automation](/en/connectors): Email, Webhook, Slack, Zapier, Kit.

<Callout type="info">
  The difference is **push versus pull**: connectors push to you when an event happens; the REST API lets you pull on your own schedule.
</Callout>
