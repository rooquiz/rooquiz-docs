title: The Four Quiz Types
description: 'The four RooQuiz quiz types and what each is for — knowledge tests, multi-dimension assessments, outcome quizzes and randomised knowledge quizzes — and why the type is fixed at creation.'
---

RooQuiz offers four quiz types (scenes), each aimed at a different goal.

<Callout type="warning">
  **The type is chosen at creation and cannot be changed afterward.** That's a data-layer constraint, not a missing UI control. Getting it wrong means rebuilding.
</Callout>

## Knowledge Quiz

For knowledge tests, online exams, and scored practice — scenarios that need **right/wrong judgment and scoring**.

- **Fixed order**: All respondents see the same question order.
- **Scoring**: Assign points to questions or correct options; totals are summed automatically.
- **Judgment & feedback**: Mark correct answers, show respondents their score and per-question explanations, and split the total into **levels** by score band (e.g. 0–60 / 60–80 / 80+), each with its own result text.
- **AI Match for fill-in-the-blank**: Besides exact and contains matching, a fill-in-the-blank answer can be graded by **AI Match**, which judges semantic similarity against your answer. AI grading is unlimited.

## Scored Quiz

For personality assessments, ability evaluations, and surveys — scenarios that need **multi-dimensional analysis** rather than simple right/wrong.

- **Multi-dimensional scoring**: Define several dimensions, each scored by **its own formula** over the question scores, and show the results — often as a **radar chart**.
- **Conditional logic**: Show or hide later questions based on previous answers, enabling adaptive surveys.
- **Open-ended context**: Fill-in-the-blank questions only collect text — they are never scored — which suits a closing "anything else we should know?".
- **Report delivery**: Results can be shown on screen, exported to PDF, or sent by email.

## Outcome Quiz

For personality quizzes, "which X are you" fun quizzes, and diagnostic lead magnets — scenarios that produce a **result type** instead of a score.

- **Result types**: Define a set of outcome types up front (e.g. Lion / Owl); each type has its own name, theme color, image, and rich-text result content.
- **Choice voting**: Every choice votes for one or more types; after submission the type with the **most votes wins** (ties resolved by list order).
- **Result-page CTAs**: Each type can carry its own CTA button (book a consultation, view a plan…), turning a fun result into action and shares.
- **Question types**: Voting questions are single choice, multiple choice, dropdown, and true/false, alongside display blocks like Rich Text, Image Carousel and Page Break.

## Random Knowledge Quiz

For practice drills and randomized testing — scenarios where **each respondent should see different questions**.

- **Random sampling**: Draws questions from a linked question bank for each respondent.
- **Draw rules**: For each question type, set how many questions to draw and the points per question.
- **Question lock duration**: Keep the same set for a respondent who refreshes or comes back (from 30 minutes to 24 hours), or re-draw on every refresh.
- **Recorded selection**: The system records the questions actually drawn each time to keep scoring consistent.

## How to choose

| Your goal | Recommended type |
| --- | --- |
| Score respondents and judge right/wrong | **Knowledge Quiz** |
| Run a personality/ability assessment or survey with multi-dimensional analysis | **Scored Quiz** |
| Give each respondent a "which type are you" result | **Outcome Quiz** |
| Show each person a different set of random questions | **Random Knowledge Quiz** |

<Callout type="warning">
  Available settings differ by type (for example, right/wrong scoring exists only in Knowledge Quiz and Random Knowledge Quiz, conditional logic and formula-based dimensions exist only in Scored Quiz, and choice voting exists only in Outcome Quiz). Confirm the capabilities you need before choosing.
</Callout>
