## Steps

<Steps>
### Pick what you want to make

The dashboard opens with **What do you want to make?** Choose by goal, and RooQuiz opens the creation drawer for the matching [quiz type](/en/getting-started/quiz-types):

| Card | What it's for | Quiz type |
| --- | --- | --- |
| **Personality quiz** | "Which one are you?" — made to be shared | Outcome Quiz |
| **Product or course finder** | Match each person to what fits them | Outcome Quiz |
| **Assessment** | Readiness, health check or maturity score | Scored Quiz |
| **Level test** | Placement and skill checks | Knowledge Quiz or Scored Quiz |
| **Trivia challenge** | A fun knowledge quiz people compete on | Knowledge Quiz |
| **AI personal report** | AI writes each person their own report | AI Quiz |

**Level test** asks one more question — **Do the questions have right answers?** Grammar, vocabulary or maths questions marked right or wrong make a Knowledge Quiz; self-ratings like "I can hold a conversation in English", where each choice carries points, make a Scored Quiz.

### Template or blank

The creation drawer opens on **templates** by design: editing a template is much faster than writing from nothing, and its question structure and report configuration are already tuned.

- **Start from a template** — browse templates by category, sort by **Most used** or **Newest**, preview the quiz (and, for AI Quizzes, a **Sample report**), then click **Use This Template**. See the [Template Center](/en/library/templates).
- **Start from blank** — build the whole thing yourself.

### Land in the editor

Creation drops you straight into the [editor](/en/editor) to start adding questions.
</Steps>

<Callout type="warning">
  **The quiz type cannot be changed once chosen.** It isn't hidden somewhere in the UI — the field is read-only after creation at the data layer. Getting it wrong means rebuilding, so decide up front whether you want a score, a dimensional profile, or a type result.
</Callout>

The full comparison and selection advice is in [Choosing a Quiz Type](/en/getting-started/quiz-types).

## Templates

A template is a whole quiz structure — questions, scoring and report configuration. Clone it and edit freely; **your changes never touch the template**.

See [Templates](/en/library).
