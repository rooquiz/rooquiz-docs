# Create Your First Quiz

## Steps

<Steps>
### Pick a creation entry

Three cards sit at the top of the dashboard, one per type:

- **Create Quiz** — answers, scored.
- **Create Scorecard** — insights, by dimension.
- **Create Outcome Quiz** — answers, typed.

The fourth type, **Random Quiz**, is created from the random-draw entry on [Question Banks](/en/library/question-banks).

### Template or blank

The creation drawer opens on **templates** by design: editing a template is much faster than writing from nothing, and its question structure and report configuration are already tuned.

- **Start from a template** — browse the [Template Center](/en/library/templates), filter by category, preview on desktop and mobile, then clone.
- **Start from blank** — build the whole thing yourself.

### Land in the editor

Creation drops you straight into the [editor](/en/editor) to start adding questions.
</Steps>

<Callout type="warning">
  **The quiz type cannot be changed once chosen.** It isn't hidden somewhere in the UI — the field is read-only after creation at the data layer. Getting it wrong means rebuilding, so decide up front whether you want a score, a dimensional profile, or a type result.
</Callout>

## Which type to pick

| What the respondent should get | Choose |
| --- | --- |
| A score, right/wrong judgement | **Quiz** |
| A multi-dimension profile (radar chart) | **Scorecard** |
| A "which type are you" conclusion | **Outcome** |
| Different random questions each time | **Random Quiz** |

The full comparison is in [The four quiz types](/en/getting-started/quiz-types).

## Templates vs. question banks

Both are reuse mechanisms, but they reuse different things:

- **Template** — a whole quiz structure. Clone it and edit freely; **your changes never touch the template**.
- **Question bank** — a pool of questions to draw from, used with Random Quiz.

See [Question Banks & Templates](/en/library).
