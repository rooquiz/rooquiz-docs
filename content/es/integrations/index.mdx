Esta sección es para **desarrolladores**: cómo acceder a RooQuiz desde tu propio código o desde un cliente de AI:

<Cards>
  <Card title="API REST" href="/es/integrations/rest-api" />
  <Card title="Integración MCP" href="/es/integrations/mcp" />
</Cards>

- **API REST**: obtén formularios y respuestas con una clave de API de cuenta. Ideal para tus propios paneles o para sincronizar con un almacén de datos.
- **Integración MCP**: conecta un cliente de AI como Claude a tu equipo para que pueda crear, consultar y modificar quizzes directamente.

## Integrar sin código

Si lo único que quieres es «avísame cuando llegue un lead» o «sincroniza los leads con mi herramienta de email marketing», **no necesitas la API**. Usa uno de los cinco canales de [Conectores y automatización](/es/connectors): Email, Webhook, Slack, Zapier y Kit.

<Callout type="info">
  La diferencia es **enviar frente a obtener**: los conectores te envían los datos cuando ocurre un evento; la API REST te permite obtenerlos según tu propio calendario.
</Callout>
