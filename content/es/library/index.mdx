Ambos son mecanismos de reutilización, pero reutilizan cosas distintas:

| | Banco de preguntas | Plantilla |
| --- | --- | --- |
| Qué reutiliza | Un conjunto de **preguntas del que extraer una y otra vez** | Una **estructura de quiz completa** |
| Cómo se usa | Extraes preguntas aleatorias al crear un quiz | La clonas en un nuevo quiz y luego la editas |
| Ideal para | Evaluar el mismo contenido una y otra vez | Aplicar la misma evaluación a distintos clientes |

<Callout type="info">
  Si tienes dudas: **las preguntas deben cambiar cada vez → banco de preguntas; el quiz es el mismo y solo cambia el público → plantilla.**
</Callout>

## Bancos de preguntas

Un banco de preguntas es el conjunto de preguntas propio de tu equipo, cada una con su respuesta correcta. Elige la extracción aleatoria al crear un quiz y el sistema tomará un conjunto distinto cada vez: ideal para quizzes de práctica y comprobaciones de conocimientos.

Consulta [Bancos de preguntas](/es/library/question-banks).

## Plantillas

El Centro de plantillas contiene quizzes completos que puedes clonar. Empieza rápido a partir de una plantilla oficial o publica como plantilla un quiz del que estés orgulloso para que tu equipo lo reutilice.

Consulta [Centro de plantillas](/es/library/templates).
