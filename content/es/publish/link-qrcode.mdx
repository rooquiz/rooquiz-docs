El enlace público es la forma más habitual de distribuir un quiz. Cualquier persona con el enlace puede abrir la página de respuesta y completarla (que se requiera iniciar sesión o no depende de los ajustes del quiz).

## Obtener y compartir el enlace

<Steps>
### Abre la página de compartir

En el quiz que quieras, abre **Compartir** → **Enlace**.

### Copia el enlace público

El sistema genera un enlace público único para cada quiz. Cópialo y distribúyelo por chat, correo electrónico, comunidades y otros canales.

### Genera un código QR

El mismo enlace puede generar un **código QR**, práctico para carteles, situaciones fuera de línea o para responder escaneando con el móvil.
</Steps>

## Características del enlace

- **Único**: cada quiz tiene su propio enlace público.
- **Si se necesita iniciar sesión**: lo decide el [Acceso al envío](/es/editor/settings); la opción predeterminada "Abierto a todos" no lo requiere, mientras que "Correo obligatorio para ver el informe" permite que cualquiera responda pero restringe el acceso al informe.
- **Origen rastreable**: combínalo con el [seguimiento de origen con UTM](/es/publish/tracking) para distinguir las respuestas por canal.
- **Multilingüe**: un quiz con [versiones de idioma](/es/editor/translations) tiene un enlace distinto para cada idioma.

Los códigos QR son ideales para carteles, material impreso, aplicaciones de chat y presentaciones: en cualquier lugar donde escanear sea más rápido que escribir. La imagen se puede descargar.
