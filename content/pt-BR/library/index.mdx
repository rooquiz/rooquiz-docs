Ambos são mecanismos de reutilização, mas reutilizam coisas diferentes:

| | Banco de questões | Modelo |
| --- | --- | --- |
| Reutiliza | Um conjunto de **questões para sortear várias vezes** | A **estrutura completa de um quiz** |
| Como usar | Sortear questões aleatórias ao montar um quiz | Cloná-lo em um novo quiz e depois editar |
| Ideal para | Testar o mesmo conteúdo repetidas vezes | Aplicar a mesma avaliação para clientes diferentes |

<Callout type="info">
  Se estiver em dúvida: **as questões devem mudar a cada vez → banco de questões; o quiz é o mesmo e só o público muda → modelo.**
</Callout>

## Bancos de questões

Um banco de questões é o conjunto próprio de questões da sua equipe, cada uma com uma resposta correta. Escolha o sorteio aleatório ao montar um quiz e o sistema seleciona um conjunto diferente a cada vez — ótimo para quizzes de prática e verificações de conhecimento.

Veja [Bancos de questões](/pt-BR/library/question-banks).

## Modelos

A Central de modelos reúne quizzes completos que você pode clonar. Comece rapidamente com um modelo oficial ou publique como modelo um quiz do qual você se orgulha para que sua equipe o reutilize.

Veja [Central de modelos](/pt-BR/library/templates).
