- **API REST** — obtenha formulários e respostas com uma chave de API da conta. Ideal para seus próprios painéis ou para sincronizar com um data warehouse.
- **Integração MCP** — conecte um cliente de IA como o Claude à sua equipe para que ele crie, consulte e modifique quizzes diretamente.

## Integração sem código

Se você só quer "me avise quando chegar um lead" ou "sincronize os leads com minha ferramenta de e-mail", **não precisa da API**. Use um dos cinco canais de [Conectores e automação](/pt-BR/connectors): E-mail, Webhook, Slack, Zapier, Kit.

<Callout type="info">
  A diferença é **enviar versus buscar**: os conectores enviam para você quando um evento acontece; a API REST permite que você busque os dados no seu próprio ritmo.
</Callout>
